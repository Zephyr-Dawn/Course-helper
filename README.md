# Course Helper｜课程复习

这是课程复习网站。每门课程放在独立目录，复变函数与积分变换为 `complex-functions/`，并用同名分支独立维护。后续课程可新增同级目录并在首页添加入口。

在线版包括七章讲义、近年真题解析、公式速查及学习记录，标注原材料的文件名与物理页码。原始讲义、试卷 PDF 和原页截图不发布在仓库；本地离线资料包另行保留。

维护时在 `complex-functions/` 安装 `requirements.txt`，运行 `python -X utf8 build.py`，再把生成的 HTML 复制为 `index.html`。

浏览器学习记录保存在本地；迁移离线记录可在“收藏与记录”中导出并导入。
