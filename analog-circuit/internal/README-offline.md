## 使用方式

1. 从左侧九讲目录顺序阅读，或用搜索框检索“超节点”“初始导数”“CMRR”等关键词。`Ctrl/⌘ + K` 聚焦搜索；结果可直接跳到段落或题目。
2. 互动中的滑块与选项会立即更新曲线和数值。先预测变化方向，再操作并核对正文。曲线为对应理想模型的解析结果，适用条件见模块说明。
3. 习题按讲次、来源、难度筛选；提示与解析默认收起。有电路图的 50 个题页会先显示独立题图；仅含函数、数值测量或画图任务的其余 5 页无需电路题图。完整课件原页往往包含参考答案，因此继续单独折叠，建议先尝试题目再打开。
4. 标记掌握、收藏专题、加入错题，以便下一轮复习。记录保存在当前浏览器本地；移动文件、清理浏览器或换设备前，请在“收藏与记录”导出 JSON，再在目标浏览器导入。
5. “公式速查”用于按题型查通用关系：先看使用条件，再选公式。它不作为逐行背诵清单。
6. “打印”展开当前页折叠内容后打印；浏览器原生 `Ctrl/⌘ + P` 也会展开。导览页的“打印全部讲义”输出九讲理论正文，习题训练与互动可从各自页面另行打印。长公式在屏幕上可横向滚动。

## 来源与勘误

页码指 PDF 的物理页序。正文保留讲次、页码标记；习题使用 `L4-P51` 这样的编号。`source-index.json` 列出全部 525 页的章节去向、原页标题预览与练习入口，属于章节级来源索引；正文中的具体引用更细。

本讲义对源答案中发现的单位、计算、图示极性及条件问题作了明确说明。主要条目见 [ERRATA.md](ERRATA.md)；完整复算方程在对应题目中。精选题 CH04-KP2-12 对原图开关闭合时短接理想电源的矛盾作出说明，并明确采用给定初值与换路后拓扑。

本资料用于个人课程复习；原课件、教材及题库图像的权利归原作者。网页题库题面采用选题与改述，注明来源；解析为复算整理。离线数学排版使用 KaTeX 0.16.11，许可证见 `assets/katex/LICENSE`。

## 源文件与重新构建

- `content/ch01.md` 至 `ch09.md`：九讲正文。
- `content/key-formulas.json`：人工维护的重点公式与三类说明，速查不再自动摘取正文 HTML。
- `content/exercises-*.json`、`challenges.json`、`quizzes.json`：课后题、精选题与快测。
- `src/`：页面模板、样式、交互和数学模型。
- `content/figures.json`、`question-figures.json`：图示位置、来源页和裁剪/原图提取记录。
- `assets/`：公式排版资源、76 幅正文插图、50 幅电路题图、55 张课件原页与精选题题图。
- `build.py`：从上述源文件生成单个离线 HTML。

普通使用无需安装任何依赖。修改后重新构建时，在此目录运行：

```powershell
python -m pip install Markdown
python -X utf8 build.py
node tests/models.test.cjs
python -X utf8 tests/content_check.py
python -X utf8 tests/formulas.test.py
```

原题图已经提供，不需重新渲染原 PDF。仅当需要从父目录中的原课件重新生成题图时，安装 PyMuPDF 与 Pillow，并运行 `python -X utf8 build.py --render-pages`。正文与题目插图已随包提供；需要从原课件重新提取时，运行 `python -X utf8 src/render_figures.py`。构建脚本不调用网络。
