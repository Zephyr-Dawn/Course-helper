### 1.2 必须继承的十条要求

1. 范围是 **EC2026 第 1–9 讲**。教材仅补对应内容；新出现的第 10、11 讲、器件教材章节或其他 PDF 不自动纳入。

3. 正文必须足够详细：定义、物理意义、推导、条件、方向、单位、例题、易错点和自检均应真正存在。
4. 电路图和相关图像是讲解组成部分。图要在对应位置直接可见，且与当前题目或推导的拓扑、参数、方向一致。
5. 公式速查只选可复用的重点关系。不得再次自动收集正文所有等式，混入代数中间步骤和代入数值的算例。
6. 公式下方的小字也要正确排版数学符号，不能出现原始 TeX、HTML 属性或图片编码。
7. 课件的 55 个末尾习题页面均有分步解答；较难的网站题按课程相关性筛选，保留原编号和来源，不猜考试年份。

9. 双击一个 HTML 即可离线阅读、做互动和使用学习记录。改动后验证桌面、窄屏、打印与离线，而非只看代码。
10. 已批准的范围和执行授权持续有效。“继续进程”表示继续完成原任务；必要工作应推进到交付，不反复请求开工确认。

### 5.2 组织执行的方法

历史实现按第 1–3、4–6、7–9 讲划分内容文件，主流程负责网页、模型、选题与集成，并有一次独立只读复核。有效之处在于明确输入输出、用相互独立的文件避免覆盖、统一接口后再整合。

复现这一方法不必固定使用多个代理。未来是否并行应服从当次用户要求、工具和环境指令；不要把历史任务文件中允许委派的语句当作新的授权。单个 AI 同样可以按阶段和文件边界完成。

本项目所在目录不是 Git 仓库；历史没有依赖分支、worktree、PR 或线上部署完成交付。不要为了套用通用开发流程而引入与用户目标无关的托管和发布步骤。

## 6 课程材料的阅读与覆盖方法

### 6.1 文字提取和视觉核对同时使用

先提取每页文字并保留页序，再查看低文字量页、公式图、复杂电路、被遮挡答案和关键例题。文字提取便于检索，不能识别全部连接关系、极性、箭头或叠加遮挡。

PDF 为主的原因是用户已提醒 PPT 中存在图片遮挡。同名 PPT 可补读公式对象和文字，但不能因为 PPT 能读就忽略遮挡。PDF 也可能保留遮挡色块；解答不清时应从清楚的题面独立求解，再用对应教材或另一种计算方式复核。

原材料的位图图示应以实际图像核对；准确电路图不适合用生成式插画替代。需要新画简单电路时，可用 SVG 等可控方式，逐项检查节点连接和符号；动态曲线由解析模型生成。

### 6.2 本项目保留的读取结果

本机 `tmp/pdfs/` 保存九讲和教材的 `.txt`、逐页 `.json` 及 `manifest.json`；`tmp/pdfs/visual/` 保存用于视觉阅读的联系图和 `index.json`。网站相关 Markdown 候选材料位于 `tmp/web/`。

这些是阅读与制作过程资料，不是普通用户双击成品的运行依赖，也不全在离线包中。继续维护现有内容通常直接读 `content/` 即可；涉及原始题图或来源争议时，再回到原 PDF 和缓存，不能把提取预览当作原页的完整替代。

### 6.3 逐页来源索引的实际含义

`source-index.json` 的 525 页分类为：

| 分类值 | 页数 | 处理方式 |
|---|---:|---|
| `theory_or_example` | 444 | 概念、推导、例题或复习归入对应章节；同类内容可以合并 |
| `exercise` | 55 | 对应唯一习题记录、原页图及独立解析 |
| `cover` | 9 | 封面，用于材料识别 |

### 6.4 阅读时必须做的判断

逐页问四件事：这一页新增了什么概念或条件；是否属于已讲类型的重复数值；图中是否有只靠文字读不到的信息；应放进正文、例题、习题、图示，还是明确排除。把这一判断记到覆盖表，再写正文，比事后靠章节标题猜遗漏可靠。

## 7 详细正文的写作标准

### 7.1 每个核心专题如何展开

按内容需要组织，至少让读者能回答以下问题：

1. 这一节解决什么问题，与前后章节有什么关系？
2. 概念的物理意义是什么，符号、单位和参考方向怎样定义？
3. 从哪个定律开始，如何推导到目标关系，每个关键变形依据是什么？
4. 关系适用于什么拓扑、激励、状态和工作区；什么情况下会失效？
5. 面对题目如何选择方法、列未知量和约束，而不是只看到答案？
6. 代表例题的已知量、方程、代入、结果和自检分别是什么？
7. 常见错误为何错误，怎样通过量纲、极限、守恒或另一种方法发现？
8. 图示和参数互动能帮助解释哪一个具体难点？
9. 哪些内容来自课件，哪些是补充理解或补足适用条件？
10. 如何回到原讲次与 PDF 页码核对？

历史写作约定为每章至少约 6000 字符、有实质专题和至少 3 个课堂算例，避免只有标题与公式。当前各章为 7390–12865 字符左右。字符数是防止空洞内容的辅助检查，不能代替逐知识点检查，更不能通过填充套话达标。

### 7.2 数学与电路表达必须统一

- 参考电流与电压极性先定义；负数解释实际方向，不能随意翻动原图。
- 受控源写清控制量、输出量和系数量纲；独立源置零时保留受控源。
- 区分端口等效与内部电流、功率；不能把等效电路的内部耗散直接当原网络所有源的效率。
- 区分理想运放的形式方程、负反馈线性工作条件与实际稳定性、饱和。
- 初始状态、初始导数、最终值分别在相应时刻的网络求解，不能混用 `0−` 与 `0+`。
- 连续性须有有限电流/电压等常规换路条件；不能把状态连续推广成所有支路量连续。
- 判断阶数要看独立状态；某个传函的可见极点数或某次响应的模态数不一定等于元件数。
- 相量采用课件的 **峰值、余弦、固定频率** 约定；RMS 另作比较，不混算平均功率。
- 不同频率各自求解，再回到时域相加；相量不能直接跨频率相加。
- 分清 `Hz`、`rad/s`、角度、弧度，分清功率比 `10log` 与幅度比 `20log` 的适用条件。
- 区分固有频率、阻尼振荡频率、输入谐振、传函峰值与截止频率。

### 7.3 补足课件中的过强概括

不要无条件写“有 L/C 就有明显谐振峰”“有共轭极点就一定有幅频峰”“二阶一定出现两个模态”“纯 LC 最后必然达到常数”“临界阻尼在任何意义下都最快”或“二阶以上多项式都无解析根”。

讲义需要给出所需条件和反例边界。例如标准二阶低通的非零频率峰值要求 `Q > 1/√2`；无损 LC 可能有特解却不收敛；某模态系数可以恰为零；“临界最快”需要约定初始状态、输出变量和评价指标。基础复习也应保留这些限定。

## 8 课后题与网站难题的处理

### 8.1 课件题页的组织

以 `L1-P73` 这样的 ID 为主键，一页一条记录，保留所有小问。各讲范围见第 3 节，完整 55 条目录见附录 B。不能把 55 页宣传为恰好 55 个独立小问。

题目应提供完整数值和必要连接描述。复杂网络可明确请读者对照题图，但解析仍必须真正写出节点方程、约束、初末值及数值过程，不能用“根据 KCL 求解即可”代替。

题面、逐级提示、完整解析、最终答案与自检分开。原页通常含参考答案，默认折叠；独立裁出的电路题图直接显示，避免读图时被迫同时看到答案。

### 8.2 网站题目的选择标准

选择与九讲匹配、需要多知识点联用、容易暴露误区且有可靠题面的问题，而不是只挑计算量大或符号多的题。典型组合包括受控源与超节点、Δ–Y 与戴维南、最大功率与效率、多阶段换路、跨频率相量、T 型运放设计、负号与多极点波特图。

完整保留原 ID 和来源页面。采用改述题面、必要题图及独立解析，不长篇复制网站说明；不把补充题称为教师原题，不推断未标明的考试年份。附录 C 列出本次实际采用的 12 道题，候选缓存中的其他题不等于已采用。

### 8.3 独立验题顺序

先读题图，定义未知量和方向；独立列出物理约束；算出符号或数值结果；再与参考答案比较。出现差异时，检查拓扑、源极性、控制量、初值、峰值/RMS、单位和舍入。

结果至少做一种与主推导不同的校验：回代 KCL/KVL、功率平衡、初始导数、初末值、低高频极限、另一种分析方法或独立数值计算。对有争议的源答案，记录依据，而不是只写“原答案错了”。

76 个正文卡片中，**64 个采用 PDF 内完整的嵌入图像**，其余保留必要的组合裁图、标注或照片。这里的 64 是卡片数，不代表恰好 64 个独立 PDF 图像对象；一张卡片可能拼接多个面板。

直接提取源图可以避开覆盖在图上的幻灯片文字或裁断残片。需要保留叠加标签时使用页面渲染裁图；不能一律抽取底图而丢掉关键标注。

`src/render_figures.py` 的记录式流程：

1. 按讲次打开原 PDF，页码减 1 转为程序索引。
2. 对有 `panels` 的记录，在该页图像信息中找最匹配的 bbox；按交集面积除以两框外接矩形面积计算匹配得分，低于 0.8 则报错，不静默选一张图。
3. 提取图像对象，可按横向、纵向或三列网格拼接。
4. 无 `panels` 时按归一化 `crop=[x0,y0,x1,y1]` 渲染区域，当前使用 2.6 倍矩阵。
5. 限制最大尺寸并保存 WebP；保留页码、区域、说明和放置锚点，便于重现。

注意 `crop` 是相对页面宽高的归一化坐标；`panels` 中的 bbox 是 PDF 页面坐标，两者不能混用。构建时只读取已经生成的素材，普通重建无需原 PDF。

### 9.4 放大和打印同属插图交付

正文图、独立题图和原页均可放大。当前用原生 `dialog`，提供加减、适合窗口、放大后滚动、Esc/按钮关闭；支持键盘打开原页图，窄屏不会把整页撑宽。

屏幕图示上限用于控制阅读节奏，原图仍可放大查看。打印时保留图、来源与说明，隐藏缩放按钮；不能只验证屏幕图而让纸上图丢失或被裁掉。

## 10 公式速查怎样减负并正确渲染

### 10.1 两个独立问题需要分别修复

用户截图同时暴露显示问题和信息选择问题。前者是小字出现源码，后者是索引把数值算例、中间推导都列了出来。只修渲染而保留 303 条杂项，或者只减少条目但小字仍乱码，都没有完成用户要求。

### 10.2 原乱码的根因

旧构建器遍历正文的展示公式，从每个公式前截取最多 450 个 HTML 字符，试图得到说明，再取末尾一段作为 `context`。补图后，截断点可能落在 `<img src="data:image/…;base64,…">` 的内部。

这种残缺 HTML 不是完整节点。文本提取会把图片编码尾部、`alt=`、`loading=`、`decoding=` 等当普通文本，最终出现在公式的小字里。旧成品复现了 **76 条**这样的说明。小字中剩余的 TeX 又被当纯文本转义输出，没有进入数学排版。

修复规则：**不要对序列化 HTML，特别是带 data URI 的 HTML，按字符截断生成语义说明。** 确实需要摘要时，应从源内容或完整 DOM 的文本节点取得；本栏目最终采用单独编辑的结构化说明。

### 10.3 重点公式的选取办法

当前 `content/key-formulas.json` 人工维护 39 组，九讲数量为 `4、4、3、5、4、3、4、4、8`。选取原则：

- 保留建模、常用求解、参数判断和结果校验中反复使用的通用关系。
- 将同类式合并，如电阻的不同耗散表达、同一类串并联关系。
- 不列具体电子数计算结果、不列某题正弦求导后的数值表达、不列积分算例的中间计算。
- 主公式必须与明确拓扑、参考方向和变量定义相联系。
- 在卡片中写清 **用途、适用条件、易错点**，并链接主专题及必要相关专题。
- 具体算例、完整推导、一般参数长公式留在正文，通过链接查看。

39 是本次课程的编辑结果，不是未来所有课程的固定配额。若以后增删卡片，必须有知识组织上的理由，并同步更新相关测试和说明，不能只改断言使测试变绿。

### 10.4 卡片数据与排版路径

每条包含 `id、chapter、section、related_sections、title、tex、use、conditions、pitfall`。主公式 `tex` 是原始 TeX；三类说明是 Markdown，可含 `$…$` 行内数学。

`build.py` 对说明走与正文相同的数学保护和 Markdown 转换，生成 `useHtml、conditionsHtml、pitfallHtml`；`app.js` 显示卡片后，对整个列表执行数学渲染，覆盖主公式和小字。标题具体说明公式用途，避免反复显示同一个长节名而无法区分。

新增卡片时特别检查：源专题存在；三类说明都非空；单位、边界和约定写明；HTML 中没有旧 `context`；小字没有图像标签片段或控制字符。Python 生成 TeX 时使用原始字符串或正确转义，避免 `\alpha` 中的 `\a` 变成铃字符。本次实现中已发现并清除了此类控制字符，测试保留检查。

### 10.5 必须保留的条件示例

- Δ–Y 的本卡关系按普通正电阻网络使用，不能把分母为零的扩展网络直接套入。
- 诺顿关系涉及 `VTh/RTh` 时，须有相应非零等效电阻；比值法也要检查适用情形。
- 仪表放大器简式先说明电阻的命名与所对应拓扑。
- 换路连续性需排除理想冲激导致的状态跳变。
- `α=0` 的无损 LC 不应套用“最后达到有限终值”的叙述。
- 峰值相量与 RMS 平均功率写法必须区分。
- `ω0±B/2` 是高 Q 近似，半功率频率的精确中心是几何平均。
- 标准二阶低通有非零频率幅值峰的条件为 `Q>1/√2`，不是仅有共轭极点。
- 等 R、等 C 的 Sallen–Key 简式严格绑定对应拓扑，理想非反相级稳定范围 `1≤K<3`；Butterworth 取 `K=3−√2`。非等值元件回正文用一般式。

### 10.6 修复验收而非只查报错

旧检查仅寻找 KaTeX 错误节点，无法发现根本没有进入 KaTeX 的纯文本源码。本次增加结构与真实可见文本检查，展开全部卡片，确认主公式与小字数学实际生成排版节点，并排除图像属性、原始 TeX 和控制字符。

还检查九讲筛选、条目计数、正文跳转、手机排版、打印展开与溢出。修复前后逐章比较解码后的正文 HTML 的 SHA-256，九章均一致，说明减少的是速查条目，正文中的推导、数值例题和电路图没有被删掉。

## 11 互动模块的设计与验证

### 11.1 每个互动要让读者看出因果

先确定本模块帮助理解的问题，再确定控制量、观察量、数学模型、图形和自检。附录 E 列出全部 18 个模块及关键条件。

好的互动是改变 R 后能看到时间常数和曲线速度变化，或改变电阻失配后能看到共模泄漏。一个只会更新数字、却不说明模型和方向的滑块不足以承担教学。

采用“先预测变化，再调参，再回正文解释”的学习方式，但不把用户先回答问题设为每一步执行的前置关口。

### 11.2 模型与界面分层

`src/models.js` 是纯模型层，负责复数运算、一阶与二阶响应、谐振、滤波、负载功率、运放、DAC、波特图和记录清洗。纯模型尽量采用 SI 单位，便于直接数值复核。

`src/labs.js` 定义 18 个模块的说明、控件、参数转换、SVG 绘图和反馈，`app.js` 负责在专题或互动总页挂载。不要在某个 UI 回调里暗藏另一套与正文不一致的公式。

输入检查、分支和边界要有针对性。现有正参数检查等不能推导为所有底层函数对任何输入都安全，例如复数除法函数对零分母的返回约定不能用于物理奇点分析。新接入自由数值输入时应在调用处明确拒绝无效分母和非有限值，不能因为画面未出现 NaN 就认为模型有效。

### 11.3 已经修复的物理一致性问题

一阶 RL 模块曾画无源闭合 RL，却允许默认从零电流趋于 5 A。无源方程从零初态只能保持零，图与曲线矛盾。

当前 RL 图加入 `VTh=R·xf` 的等效源；默认 `R=10 Ω、xf=5 A`，对应 `VTh=50 V`。RC 对应 `Vs=xf`。既保留可调初终值的三要素教学，也使图示网络能够产生该终值。

这条经验必须继承：**公式算得对，不代表界面所画的电路能实现该响应。** 参数、源、拓扑与初态要一起检查。

### 11.4 单位和曲线解释

- 一阶 RC 控件采用 kΩ、µF、V；RL 控件采用 Ω、mH、A，显示随选择切换，计算转为 SI。
- 一阶图横轴为真实秒数，改变元件值后应看到速度变化，而非总被归一化横轴抵消。
- `5τ` 时误差约为初始误差的 0.674%，是工程近似，不是数学上完全到达终值。
- 二阶模块的初始导数可独立调节用于观察；具体电路须由初始电流、KCL/KVL 求得，不能误当额外自由物理量。
- 波特模块控件使用 Hz，对应 s 平面的实极点是 `−2πfp`；谐振模块显示角频率与 Hz 的换算。
- 储能和滤波模块部分曲线使用归一化幅度或时间，必须明确标轴，不能把它当作真实未归一化量。
- 运放的轨限幅只表示理想饱和现象，不替代真实器件带宽、输出摆幅和恢复模型。

## 13 阅读界面与使用体验

### 13.1 当前界面的有效设计

白底、深蓝正文、青色强调，适合长时间中文阅读。桌面为固定左导航、中央正文和右侧本页目录；右栏在中等宽度收起，手机使用折叠菜单。正文默认约 17 px，可调 15–19 px；长公式与表格在自身容器滚动，整页不应横向溢出。

主要入口为学习导览、完整讲义、互动实验、习题训练、公式速查、收藏与记录。正文按课程顺序阅读，也能搜索知识点、跳到具体专题或题目。搜索支持 `Ctrl/⌘+K` 聚焦；它是现有内容的关键词检索，不应宣传成理解任意数学记号的符号搜索引擎。

同页锚点跳转尽量复用已挂载内容，避免重新渲染时重置滑块。专题附近的互动与总互动页共享同一套模块定义，避免两种入口出现不同公式。

### 13.2 学习记录的边界

当前 `localStorage` 主键为 `ee-circuits-review-v1`，保存章节掌握、错题、专题收藏和字体；另有上次阅读章节。导出 JSON 包含版本、导出时间和上述状态，默认文件名为 `电路复习-学习记录.json`。

导入时限制文件大小、过滤未知 ID、去重、约束字体范围，损坏 JSON 友好拒绝。记录按当前浏览器与本地文件来源保存，不是跨设备云同步；移动文件、换浏览器或清理数据前用导出/导入备份。

不要随意改存储主键或 ID，让用户历史记录失效。若课程重组必须改变 ID，应设计迁移或说明备份方式。

### 13.3 已实现与未宣称的能力

当前有手工解题记录、折叠提示、完整解析、错题和选择题即时解释；没有完整的计算题数值自动判分器、任意单位解析器、自由画电路或 SPICE 求解引擎。

最初大纲中部分条目是功能建议，例如数值输入识别单位与误差，不能全部追认成已实现。现有互动是特定理想模型的解析演示，符合用户“最好可互动”的目标。

### 13.4 打印要正确覆盖折叠内容

“打印当前页”及浏览器原生打印前展开该页所有 `details`，不仅展开内部答案；否则外层习题或公式仍关闭，纸上会只剩标题。

“打印全部讲义”将九章理论正文写入专用容器，不包括动态挂载的全部习题与互动；这些可从对应页面另行打印。打印结束后清理全本容器与状态，打印样式只在 `printing-all` 时显示全本，防止先打印全部后又在当前页重复附带整本。

当前实现打印后会保持当页折叠内容已展开，没有实现恢复每个折叠项原始开闭状态。不要把历史复核中的改进建议写成现有行为。

## 15 必须保留的缺陷经验

| 曾出现的问题 | 根因 | 当前修复或接续规则 |
|---|---|---|
| 公式小字出现 base64 尾部和图片属性 | 对完整 HTML 做字符截断，起点落在图像属性中 | 公式说明独立结构化维护，禁止旧 context 摘录；加可见文本检查 |

| 速查条目过多、含大量算例 | 自动抽全部展示式，把正文完整性误用为速查策略 | 人工精选 39 组，保留用途、条件、易错与正文链接 |
| 正文缺乏直观图示 | 只有文字、公式和分散原页，阅读时看不到对应图 | 76 幅紧邻正文的图与 50 幅直接显示题图 |
| 看似同类的图与例题不符 | 按章节主题选图，没有逐项核对拓扑和参数 | 核对 F7-06、F8-06 等精确来源，不能仅验图片能加载 |

| SVG 网格/轴出现黑填充 | 开放 path 的默认 fill | `.svg-axis,.svg-grid{fill:none}`，实际看图 |
| 打印公式或习题只剩标题 | 只展开内部答案，外层 details 仍关闭 | 打印前展开当前页全部 details，原生打印也处理 |
| 打印全部后打印当前页重复整本 | 全本容器残留，打印 CSS 无条件显示 | 条件显示 + afterprint 清空容器和类 |

| 互动与其他控件 ID 冲突 | 复用过于泛化的 ID | 模块和筛选器分别命名，浏览器检查重复 ID |

调试时先复现失败，再修改最小相关源文件，最后验证原失败场景。不要只换一个截图、删掉有问题的说明或放宽断言，就称问题已解决。

### 18.2 打包脚本示例

在源码根目录执行下面的 PowerShell/Python 代码。它更新同一路径的 ZIP，先检查临时包，成功后再替换。该脚本是可复用操作示例，不是构建器当前会自动执行的步骤。

```powershell
@'
from pathlib import Path
import zipfile

root = Path.cwd().resolve()
assert (root / "build.py").is_file()
assert (root / "content/ch01.md").is_file()
dest = root.parent / "电子电路基础-复习资料包.zip"
temp = dest.with_suffix(".zip.tmp")
root_files = [
    "电子电路基础-互动复习.html", "build.py", "build-manifest.json",
    "README.md", "QA.md", "ERRATA.md", "HANDOFF.md",
    "source-index.json", "verification.json"
]
files = [root / name for name in root_files]
for name in ("content", "src", "tests", "assets"):
    for p in (root / name).rglob("*"):
        rel = p.relative_to(root)
        if not p.is_file():
            continue
        if "__pycache__" in rel.parts or p.suffix == ".pyc":
            continue
        if rel.parts[:2] == ("assets", "design"):
            continue
        if rel.parts[:3] == ("assets", "katex", "contrib"):
            continue
        files.append(p)
assert all(p.is_file() for p in files)
with zipfile.ZipFile(temp, "w", zipfile.ZIP_DEFLATED, compresslevel=9) as z:
    for p in sorted(set(files)):
        z.write(p, "电子电路基础复习/" + p.relative_to(root).as_posix())
with zipfile.ZipFile(temp) as z:
    assert z.testzip() is None
    assert z.read("电子电路基础复习/电子电路基础-互动复习.html") == (
        root / "电子电路基础-互动复习.html"
    ).read_bytes()
temp.replace(dest)
print(dest)
'@ | python -X utf8 -
```

### 18.3 真正证明源包可用

CRC 只能说明压缩内容未损坏，不能说明源码完整。应在独立目录解压包，先记下包内 HTML 哈希，再在解压源码根运行 `python -X utf8 build.py`，确认重建 HTML 与包内交付物一致，并运行必要结构检查。

模块 ID：`common`；第 4 讲；页面锚点：`lab-common`。

差分放大器 R₁=R₃=10 kΩ，R₂=100 kΩ，调整 R₄ 的失配。保持理想运放在线性区，观察输出中共模误差。

模块 ID：`instrument`；第 4 讲；页面锚点：`lab-instrument`。

模块 ID：`dac`；第 4 讲；页面锚点：`lab-dac`。

模块 ID：`storage`；第 5 讲；页面锚点：`lab-storage`。

模块 ID：`integrator`；第 5 讲；页面锚点：`lab-integrator`。

### 用阶跃拼出脉冲，并观察 RC 响应

模块 ID：`singular`；第 6 讲；页面锚点：`lab-singular`。

输入为幅度 A、从 a 到 b 的矩形脉冲，即 A[u(t−a)−u(t−b)]。截止后系统保留已有状态，继续自然衰减。

### RLC 特征根、阻尼与时域曲线

模块 ID：`second`；第 7 讲；页面锚点：`lab-second`。

### 同频相量相加与时域波形

模块 ID：`phasor`；第 8 讲；页面锚点：`lab-phasor`。

两路同频余弦。拖动相位，比较相量之和与两条瞬时波形之和；相量不能用于直接合并不同频率。

H(jf)=K(1+jf/fz)/[(1+jf/fp1)(1+jf/fp2)]。这里所有频率用 Hz；对应 s 平面的实极点是 −2πfp。

### 串并联谐振：Q、带宽与半功率点

模块 ID：`resonance`；第 9 讲；页面锚点：`lab-resonance`。

串联用理想电压源驱动并观察电流，并联用理想电流源驱动并观察电压；图中除以各自峰值。

### 滤波器的幅相与多频输出
