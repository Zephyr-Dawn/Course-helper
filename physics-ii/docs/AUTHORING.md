# 大学物理甲-II 互动复习编写规范 (`docs/AUTHORING.md`)

## 1. 每次写入行数限制（强制要求）
- 每次调用 `write_file` 或 `edit_file` 时，**单次改动必须严格控制在 80～100 行以内**。
- 编写长文件（如 `content/chNN.md` 或 `content/exercises/chNN.json`）时，先用 `write_file(..., Overwrite=True)` 写入前 70～90 行，再用多次 `write_file(..., Append=True)` 分段追加。

## 2. 数学公式规范（零容忍校验）
- 行内公式用 `$...$`，独立公式块用 `$$...$$`（前后空行）。
- **严禁在 `$...$` 或 `$$...$$` 内出现任何中文字符**（`[\u4e00-\u9fff]`）或 `\boxed`。角标请使用罗马体 `\mathrm{}`（如 `U_{\mathrm{ab}}`、`\varepsilon_{\mathrm{r}}`、`B_{\mathrm{max}}`），中文说明一律放在数学环境外。
- Markdown 表格内的绝对值必须写 `\lvert x \rvert`，严禁写 `|x|`（会被当作表格列分隔符）。

## 4. 配图与习题 JSON 规范
- `content/figures-chNN.json`：列表格式 `[{"id": "F9-01", "page": 25, "crop": [x0, y0, x1, y1], "title": "...", "caption": "..."}]`，正文中用 `{{fig:F9-01}}` 引用。所有定义的图必须在正文中引用。
- `content/exercises/chNN.json`：列表格式，每题包含 `id`、`section`、`difficulty` (1~3)、`source`（如 `"课件第1讲 · PDF 第 25 页 · 例9-1"`）、`title`、`problem`、`page`、`crop` (`[x0,y0,x1,y1]`)、`hints`、`steps`、`answer`、`check`、`note`。
- 写完每章后运行：
  `../.venv/bin/python src/render_figures.py chNN --force && ../.venv/bin/python src/lint_content.py chNN`
