# 第 9 章：真空中的静电场

本章是整个电磁学体系的基石（对应王逸璞老师课件第 1～4 讲，PDF 第 12～138 页）。我们从**电荷的基本属性与库仑定律**出发，引入描述静电场性质的两个核心场量——矢量**电场强度 $\vec{E}$**（力的角度）与标量**电势 $U$**（功与能的角度），并建立静电场的两大基本积分定理：**高斯定理**（有源性，$\oint_S \vec{E}\cdot\mathrm{d}\vec{S} = Q_{\mathrm{enc}}/\varepsilon_0$）与**环路定理**（保守性/无旋性，$\oint_L \vec{E}\cdot\mathrm{d}\vec{l} = 0$），最终汇合于求解电场强度的三大支柱方法。

## 9.1 库仑定律与电荷守恒 {#s9-1}

### 一、电荷的三大基本规律
自然界只存在正、负两种电荷。宏观与微观电磁现象均服从以下三条实验规律：
1. **电荷守恒定律**：在与外界没有电荷交换的孤立系统内，正、负电荷的代数和在任何物理过程（包括核反应、正负电子对产生与湮灭）中保持恒定。这是物理学最基本的普适守恒律之一。
2. **电荷量子化**：任何带电体所带电量只能是基本电荷（元电荷）$e$ 的整数倍，即 $q = Ne$（$N \in \mathbb{Z}$），其中密立根油滴实验（1909–1913）首次精确测定了元电荷量值：
$$e = 1.60217733 \times 10^{-19}\,\mathrm{C}$$
3. **电荷的相对论不变性**：同一带电粒子的电量不随其运动速度改变，在不同惯性参考系中观察到的电荷总量完全相同（对比：相对论质量、长度、时间间隔均与参考系有关）。这解释了为何原子内高速运动的电子与低速质子仍能保持精确的整体电中性，并揭示电场与磁场是同一电磁现象在不同参考系下的不同侧面。

### 二、点电荷与库仑定律
当带电体的几何尺寸远小于它们之间的作用距离（$d \ll r$）时，带电体的形状和内部电荷分布细节可忽略，抽象为理想模型——**点电荷**。真空中两个静止点电荷 $q_1, q_2$ 之间的相互作用静电力满足**库仑定律**：

$$\vec{F}_{12} = -\vec{F}_{21} = k\frac{q_1 q_2}{r_{12}^2}\hat{r}_{12} = \frac{1}{4\pi\varepsilon_0}\frac{q_1 q_2}{r_{12}^2}\hat{r}_{12} = \frac{1}{4\pi\varepsilon_0}\frac{q_1 q_2}{r_{12}^3}\vec{r}_{12}$$

其中 $\vec{r}_{12} = \vec{r}_1 - \vec{r}_2$ 是由**施力电荷 $q_2$ 指向受力电荷 $q_1$** 的位矢，$\hat{r}_{12} = \vec{r}_{12}/r_{12}$ 为同向单位矢量；比例系数 $k = 8.9875 \times 10^9\,\mathrm{N\cdot m^2/C^2}$，真空介电常量为：
$$\varepsilon_0 = \frac{1}{4\pi k} \approx 8.854 \times 10^{-12}\,\mathrm{C^2/(N\cdot m^2)}$$

### 三、静电力叠加原理
当空间存在两个以上点电荷 $q_1, q_2, \dots, q_n$ 时，作用在某一点电荷 $q_1$ 上的总静电力，等于其余各点电荷**单独存在时**对 $q_1$ 所施静电力的矢量和：
$$\vec{F}_1 = \sum_{i=2}^{n}\vec{F}_{1i} = \sum_{i=2}^{n}\frac{1}{4\pi\varepsilon_0}\frac{q_1 q_i}{r_{1i}^2}\hat{r}_{1i}$$

## 9.2 电场强度、点电荷场与电偶极子 {#s9-2}

### 一、近距作用场论观点与电场强度定义
法拉第与麦克斯韦提出的**场论观点**指出：电荷之间并非超距作用，而是通过客观存在的特殊物质——**电场**传递相互作用（电荷 $\rightleftarrows$ 电场 $\rightleftarrows$ 电荷）。相对于观察者静止的场源电荷激发的电场称为**静电场**。

为定量描述电场性质，引入**试探电荷 $q_0$**（尺寸足够小以满足点电荷条件，电量足够小以致不改变原有源电荷的分布）。实验表明，试探电荷在场中某点所受静电力 $\vec{F}$ 与 $q_0$ 的比值与 $q_0$ 无关，仅由电场本身在该点的性质决定。据此定义**电场强度**（简称场强）：

$$\vec{E} = \frac{\vec{F}}{q_0}$$

- **单位**：$\mathrm{N/C}$ 或 $\mathrm{V/m}$；若已知空间场强 $\vec{E}$，则任意点电荷 $q$ 在该处受静电力为 $\vec{F} = q\vec{E}$（正电荷受力与 $\vec{E}$ 同向，负电荷受力与 $\vec{E}$ 反向）。
- **点电荷的电场强度**：位于原点的点电荷 $Q$ 在位矢 $\vec{r}$ 处激发的场强为：
$$\vec{E}(\vec{r}) = \frac{1}{4\pi\varepsilon_0}\frac{Q}{r^2}\hat{r}$$
当 $Q > 0$ 时 $\vec{E}$ 沿径向向外（发散）；当 $Q < 0$ 时 $\vec{E}$ 沿径向向内（汇聚）。
- **点电荷系的场强叠加原理**：$n$ 个点电荷同时存在时，空间某点的合场强等于各点电荷单独存在时在该点产生场强的**矢量和**：
$$\vec{E} = \sum_{i=1}^{n}\vec{E}_i = \sum_{i=1}^{n}\frac{1}{4\pi\varepsilon_0}\frac{q_i}{r_i^2}\hat{r}_i$$

### 二、电偶极子的电场强度
相距为 $l$ 的两个等量异号点电荷 $+q$ 与 $-q$ 组成的系统称为**电偶极子**（当场点到偶极子中心的距离 $r \gg l$ 时）。定义由**负电荷 $-q$ 指向正电荷 $+q$** 的有向线段为 $\vec{l}$，则系统的**电偶极矩**定义为：
$$\vec{p}_e = q\vec{l}$$

{{fig:F9-02}}

:::derive 电偶极子轴线延长线与中垂线远场推导（$r \gg l$）
1. **轴线延长线 $P_1$ 点**（距中心 $O$ 为 $r$）：正电荷 $+q$ 距 $P_1$ 为 $r - l/2$（场强沿 $+\vec{p}_e$），负电荷 $-q$ 距 $P_1$ 为 $r + l/2$（场强沿 $-\vec{p}_e$）。矢量合成得：
$$\vec{E}_{P1} = \frac{q}{4\pi\varepsilon_0}\left[\frac{1}{(r-l/2)^2} - \frac{1}{(r+l/2)^2}\right]\frac{\vec{p}_e}{p_e} = \frac{1}{4\pi\varepsilon_0}\frac{2r\,\vec{p}_e}{(r^2 - l^2/4)^2} \xrightarrow{r \gg l} \frac{1}{4\pi\varepsilon_0}\frac{2\vec{p}_e}{r^3}$$
2. **中垂线 $P_2$ 点**（距中心 $O$ 为 $r$）：$\pm q$ 到 $P_2$ 距离相等 $r_\pm = \sqrt{r^2 + l^2/4}$，场强大小相等，垂直于轴线的分量抵消，平行于轴线的分量均沿 $-\vec{p}_e$ 方向（$\cos\theta = \frac{l/2}{\sqrt{r^2+l^2/4}}$）：
$$\vec{E}_{P2} = -2\cdot\frac{q}{4\pi\varepsilon_0(r^2+l^2/4)}\cdot\frac{l/2}{\sqrt{r^2+l^2/4}}\frac{\vec{p}_e}{p_e} = -\frac{1}{4\pi\varepsilon_0}\frac{\vec{p}_e}{(r^2+l^2/4)^{3/2}} \xrightarrow{r \gg l} -\frac{1}{4\pi\varepsilon_0}\frac{\vec{p}_e}{r^3}$$
:::

## 9.3 连续带电体场强叠加计算 {#s9-3}

### 一、三种连续电荷分布与场强矢量积分
宏观带电体通常包含极大量微观电荷，可将电荷分布视为连续函数，把带电体分割为无穷多个无限小的**电荷元 $\mathrm{d}q$**：
1. **线分布电荷**（细棒、细圆环、圆弧）：线电荷密度 $\lambda = \frac{\mathrm{d}q}{\mathrm{d}l} \implies \mathrm{d}q = \lambda\,\mathrm{d}l$，场强 $\vec{E} = \int_L \frac{\lambda\,\mathrm{d}l}{4\pi\varepsilon_0 r^2}\hat{r}$。
2. **面分布电荷**（薄圆盘、薄球壳、带电平面）：面电荷密度 $\sigma = \frac{\mathrm{d}q}{\mathrm{d}S} \implies \mathrm{d}q = \sigma\,\mathrm{d}S$，场强 $\vec{E} = \iint_S \frac{\sigma\,\mathrm{d}S}{4\pi\varepsilon_0 r^2}\hat{r}$。
3. **体分布电荷**（带电球体、厚板）：体电荷密度 $\rho = \frac{\mathrm{d}q}{\mathrm{d}V} \implies \mathrm{d}q = \rho\,\mathrm{d}V$，场强 $\vec{E} = \iiint_V \frac{\rho\,\mathrm{d}V}{4\pi\varepsilon_0 r^2}\hat{r}$。

:::warn 矢量积分的核心禁忌：先正交分解、后标量积分
由于不同位置的电荷元 $\mathrm{d}q$ 指向场点 $P$ 的单位矢量 $\hat{r}$ **方向随积分位置改变**，绝不能直接把标量微元 $\mathrm{d}E = \frac{\mathrm{d}q}{4\pi\varepsilon_0 r^2}$ 积分！必须建立直角坐标系，先将 $\mathrm{d}\vec{E}$ 投影为坐标分量或利用对称性配对抵消：
$$E_x = \int \mathrm{d}E_x, \quad E_y = \int \mathrm{d}E_y, \quad E_z = \int \mathrm{d}E_z \implies \vec{E} = E_x\vec{i} + E_y\vec{j} + E_z\vec{k}$$
:::

### 二、三大基准连续带电模型的场强推导

#### 1. 有限长与无限长均匀带电细棒（例 9-2）
设长为 $l$、线电荷密度为 $\lambda$ 的均匀带电细棒沿 $x$ 轴放置，场点 $P$ 到细棒的垂直距离为 $a$，$P$ 点对细棒左、右两端点连线与 $+x$ 轴的夹角分别为 $\theta_1$ 和 $\theta_2$。

{{fig:F9-03}}

:::derive 角度换元法求细棒场强分量
在坐标 $x$ 处取线元 $\mathrm{d}q = \lambda\,\mathrm{d}x$，利用几何关系 $x = a\cot(\pi - \theta) = -a\cot\theta$，求微分得 $\mathrm{d}x = a\csc^2\theta\,\mathrm{d}\theta$，而距离 $r = a\csc\theta = \frac{a}{\sin\theta}$。代入分量式可消去 $\csc^2\theta$：
$$\mathrm{d}E_x = \frac{\lambda\,\mathrm{d}x}{4\pi\varepsilon_0 r^2}\cos\theta = \frac{\lambda}{4\pi\varepsilon_0 a}\cos\theta\,\mathrm{d}\theta, \quad \mathrm{d}E_y = \frac{\lambda\,\mathrm{d}x}{4\pi\varepsilon_0 r^2}\sin\theta = \frac{\lambda}{4\pi\varepsilon_0 a}\sin\theta\,\mathrm{d}\theta$$
对 $\theta \in [\theta_1, \theta_2]$ 积分，得到**有限长细棒通用场强公式**：
$$E_x = \frac{\lambda}{4\pi\varepsilon_0 a}(\sin\theta_2 - \sin\theta_1), \qquad E_y = \frac{\lambda}{4\pi\varepsilon_0 a}(\cos\theta_1 - \cos\theta_2)$$
- **重要推论（无限长带电直导线）**：当 $l \to \infty$ 时，$\theta_1 \to 0$ 且 $\theta_2 \to \pi$，此时平行于棒的分量 $E_x = 0$，垂直分量给出著名的无限长直导线场强公式：
$$\vec{E} = \frac{\lambda}{2\pi\varepsilon_0 a}\vec{j}$$
:::

#### 2. 均匀带电细圆环轴线上的电场强度（例 9-3）
半径为 $R$、总带电量为 $q$ 的均匀带电细圆环，在过环心且垂直于环面的 $z$ 轴上距环心 $z$ 处激发电场。由轴对称性，各线元 $\mathrm{d}q = \lambda\,\mathrm{d}l$ 产生的垂直分量 $\mathrm{d}\vec{E}_\perp$ 成对抵消，仅轴向分量 $\mathrm{d}E_z = \mathrm{d}E\cos\theta$ 累加（其中 $r = \sqrt{R^2+z^2}$，$\cos\theta = \frac{z}{\sqrt{R^2+z^2}}$）：

$$\vec{E}_{\mathrm{ring}}(z) = \left[\int_0^{2\pi R} \frac{\lambda\,\mathrm{d}l}{4\pi\varepsilon_0(R^2+z^2)}\frac{z}{\sqrt{R^2+z^2}}\right]\vec{k} = \frac{qz}{4\pi\varepsilon_0(R^2+z^2)^{3/2}}\vec{k}$$

#### 3. 均匀带电薄圆盘轴线场强与无限大平面极限（例 9-4）
半径为 $R$、面电荷密度为 $\sigma$ 的均匀带电薄圆盘，可视为无穷多个半径为 $r$、宽为 $\mathrm{d}r$ 的同心细圆环（二级微元 $\mathrm{d}q = \sigma 2\pi r\,\mathrm{d}r$）的叠加。调用圆环轴线公式对 $r \in [0, R]$ 积分（$z > 0$）：

$$\vec{E}_{\mathrm{disk}}(z) = \left[\int_0^R \frac{z(\sigma 2\pi r\,\mathrm{d}r)}{4\pi\varepsilon_0(z^2+r^2)^{3/2}}\right]\vec{k} = \frac{\sigma}{2\varepsilon_0}\left(1 - \frac{z}{\sqrt{z^2+R^2}}\right)\vec{k}$$

- **重要推论（无限大均匀带电平面）**：当场点极靠近盘面（$z \ll R$）或盘半径 $R \to \infty$ 时，$\frac{z}{\sqrt{z^2+R^2}} \to 0$，得到无限大均匀带电平面的匀强电场：
$$E = \frac{\sigma}{2\varepsilon_0}$$

## 9.4 电场线、电通量与静电场高斯定理 {#s9-4}

### 一、电场线（E 线）及其拓扑性质
为了将空间各点的矢量场 $\vec{E}(\vec{r})$ 形象化，引入**电场线**概念：
1. **切线方向**：电场线上每一点的切线方向代表该点场强 $\vec{E}$ 的方向。
2. **疏密程度**：规定通过垂直于场强方向的单位截面积的电场线根数 $\frac{\mathrm{d}N}{\mathrm{d}S_\perp}$ 等于该点场强的大小 $E$（即电场线密集处场强大、稀疏处场强小）。
3. **静电场线的三大特征**：
   - 发自正电荷（或无穷远），终止于负电荷（或无穷远）；
   - 在无电荷处**不会中断**，在任何点**不会相交**（场强方向的唯一性）；
   - 静电场线**绝对不会形成闭合曲线**（由静电场保守性/无旋性决定）。

### 二、面元矢量与电通量
设曲面微元面积为 $\mathrm{d}S$，单位法向量为 $\hat{n}$，定义**面元矢量** $\mathrm{d}\vec{S} = \mathrm{d}S\,\hat{n}$。穿过面元 $\mathrm{d}\vec{S}$ 的**电通量**定义为：

$$\mathrm{d}\Phi_e = \vec{E}\cdot\mathrm{d}\vec{S} = E\,\mathrm{d}S\cos\theta = E\,\mathrm{d}S_\perp$$

对于任意有限曲面 $S$ 和**闭合曲面 $S$**（闭合曲面统一规定**自内向外**的外法线方向为 $\hat{n}$ 正方向，故电场线穿出为正 $\Phi_e > 0$、穿入为负 $\Phi_e < 0$）：

$$\Phi_e = \iint_S \vec{E}\cdot\mathrm{d}\vec{S}, \qquad \Phi_{e,\mathrm{closed}} = \oint_S \vec{E}\cdot\mathrm{d}\vec{S}$$

### 三、真空静电场的高斯定理
**高斯定理表述**：在真空静电场中，通过任意闭合曲面 $S$（称为**高斯面**）的电通量，恒等于该闭合曲面内部所包围的所有电荷代数和的 $\varepsilon_0$ 分之一，而与闭合曲面外部的电荷无关：

$$\Phi_e = \oint_S \vec{E}\cdot\mathrm{d}\vec{S} = \frac{1}{\varepsilon_0}\sum_{i \in S} q_i = \frac{1}{\varepsilon_0}\iiint_V \rho\,\mathrm{d}V$$

{{fig:F9-07}}

:::derive 利用有向立体角与库仑定律严格证明高斯定理
1. **单个点电荷 $q$ 位于任意闭合曲面 $S$ 内部**：面元 $\mathrm{d}\vec{S}$ 对点电荷张开的**有向立体角**定义为 $\mathrm{d}\Omega = \frac{\mathrm{d}S\cos\theta}{r^2}$。由库仑定律得该面元的电通量：
$$\mathrm{d}\Phi_e = \vec{E}\cdot\mathrm{d}\vec{S} = \frac{q}{4\pi\varepsilon_0 r^2}\mathrm{d}S\cos\theta = \frac{q}{4\pi\varepsilon_0}\mathrm{d}\Omega$$
对包围点电荷的任意分片光滑闭合曲面，总立体角恒为 $\oint_S \mathrm{d}\Omega = 4\pi$，故 $\Phi_e = \frac{q}{4\pi\varepsilon_0}\cdot 4\pi = \frac{q}{\varepsilon_0}$。
2. **单个点电荷 $q$ 位于闭合曲面 $S$ 外部**：从点电荷发出的任意立体角锥穿过闭合面时必成对穿入（$\mathrm{d}\Omega_2 < 0$）与穿出（$\mathrm{d}\Omega_1 = -\mathrm{d}\Omega_2 > 0$），成对通量相消 $\mathrm{d}\Phi_{e1} + \mathrm{d}\Phi_{e2} = 0$，故 $\oint_S \vec{E}\cdot\mathrm{d}\vec{S} = 0$。
3. **点电荷系或连续带电体**：由场强叠加原理 $\vec{E} = \sum \vec{E}_i$，只有位于 $S$ 内部的电荷贡献 $q_i/\varepsilon_0$，外部电荷贡献全为 $0$，定理得证。
:::

{{fig:F9-08}}

:::warn 高斯定理三大高频概念辨析
1. **静电场是有源场**：高斯定理表明正电荷是静电场的“源”（发散源），负电荷是“尾”（汇聚源）。
2. **$\Phi_e$ 仅取决于面内净电荷，但面上的 $\vec{E}$ 由面内外全部电荷共同决定**：移动高斯面外的电荷或改变面内电荷的分布位置，穿过高斯面的总电通量 $\Phi_e$ **不变**，但高斯面上各点的场强 $\vec{E}$ **会发生改变**。
3. **$\Phi_e = 0 \nRightarrow \vec{E} = 0$**：例如电偶极子被包在高斯面内或匀强电场穿过闭合面时，$\Phi_e = 0$，但高斯面上的 $\vec{E}$ 并不处处为零。
:::

## 9.5 高斯定理求对称分布电场 {#s9-5}

### 一、利用高斯定理脱去积分号求场强的条件与步骤
高斯定理本身对任意静电场均普遍成立，但**只有当场源电荷分布具有高度几何对称性**时，才能构造一个使 $\vec{E}\cdot\mathrm{d}\vec{S} = E\,\mathrm{d}S$（且 $E$ 在面上为常数）或 $\vec{E}\perp\mathrm{d}\vec{S}$ 的闭合高斯面，将曲面积分简化为初等代数方程求解 $E$。

| 对称类型 | 典型带电体模型 | 高斯面选取与通量展开 $\Phi_e$ | 场强分布核心结论 |
| :--- | :--- | :--- | :--- |
| **球对称分布** | 均匀带电球壳、实心球、径向非均匀球 $\rho(r)$ | 过场点的**同心球面**：$\Phi_e = E(r)\cdot 4\pi r^2$ | 薄球壳：壳内 $r<R$ 处 $E=0$；壳外 $r>R$ 处 $E=\dfrac{q}{4\pi\varepsilon_0 r^2}$ |
| **轴对称分布** | 无限长均匀带电直线、圆柱壳、实心圆柱 $\rho(r)$ | 长为 $l$ 的**同轴封闭圆柱面**：两底面通量为 $0$，$\Phi_e = E(r)\cdot 2\pi r l$ | 圆柱壳：壳内 $r<R$ 处 $E=0$；壳外 $r>R$ 处 $E=\dfrac{\lambda}{2\pi\varepsilon_0 r}$ |
| **平面对称分布** | 无限大均匀带电平面、厚度为 $d$ 的无限大平板 | 轴线垂直于板面的**对称封闭柱面**：侧面通量为 $0$，$\Phi_e = 2 E S$ | 单块无限大薄平面：两侧匀强电场 $E = \dfrac{\sigma}{2\varepsilon_0}$ |

### 二、三种对称分布的典型解析

#### 1. 球对称分布：带电薄球壳、多同心球壳与径向非均匀球体
对于半径为 $R$、带电量为 $q$ 的均匀带电薄球壳，过场点作半径为 $r$ 的同心球面：
- 当 $r > R$ 时，包围电量 $Q_{\mathrm{enc}} = q$，由 $E\cdot 4\pi r^2 = \frac{q}{\varepsilon_0}$ 得 $\vec{E} = \frac{q}{4\pi\varepsilon_0 r^2}\hat{r}$（等效于全部电量集中于球心）；
- 当 $r < R$ 时，高斯面内无电荷 $Q_{\mathrm{enc}} = 0$，由对称性立即得出球壳内部场强处处为零：$\vec{E} = 0$。
- 若为**均匀带电实心球体**（总电量 $Q$，体密度 $\rho = \frac{Q}{\frac{4}{3}\pi R^3}$），则球内 $r < R$ 包围电量 $Q_{\mathrm{enc}}(r) = Q\frac{r^3}{R^3}$，内部场强按正比于 $r$ 线性增长：
$$\vec{E}_{\mathrm{solid}}(r) = \frac{Qr}{4\pi\varepsilon_0 R^3}\hat{r} = \frac{\rho r}{3\varepsilon_0}\hat{r} \quad (r \le R)$$

#### 2. 轴对称分布：无限长带电圆柱面与圆柱体
对于半径为 $R$、沿轴向每单位长度带电量为 $\lambda$ 的无限长均匀带电圆柱壳，由轴对称与镜面对称可知场强沿垂直于轴线的径向 $\hat{r}$。作高为 $l$、半径为 $r$ 的同轴圆柱高斯面，上下两底面法线与 $\vec{E}$ 垂直（通量为零），仅侧面有通量 $\Phi_e = E\cdot 2\pi r l$：
$$E(r) = \begin{cases} 0, & r < R \\[6pt] \dfrac{\lambda}{2\pi\varepsilon_0 r}, & r > R \end{cases}$$

{{fig:F9-10}}

#### 3. 平面对称分布与“高斯定理 + 叠加原理（补偿法）”
对于厚度为 $d$、体电荷密度为 $\rho$ 的无限大均匀带电厚平板（中心对称面为 $x=0$），既可用对称柱状高斯面直接求得板内线性场强与板外匀强场强，也可将厚板切分为厚度 $\mathrm{d}x'$、面电荷密度 $\mathrm{d}\sigma = \rho\,\mathrm{d}x'$ 的无穷多个薄平面进行叠加：
$$\vec{E}(x) = \begin{cases} \dfrac{\rho x}{\varepsilon_0}\vec{i}, & \lvert x \rvert \le \dfrac{d}{2} \\[8pt] \pm\dfrac{\rho d}{2\varepsilon_0}\vec{i}, & \lvert x \rvert > \dfrac{d}{2} \end{cases}$$

## 9.6 静电场环路定理与电势能、电势 {#s9-6}

### 一、静电场力做功与环路定理
在点电荷 $+q$（位于原点 $O$）激发的电场中，将试探电荷 $q_0$ 沿任意曲线路径从 $a$ 点（位矢 $\vec{r}_a$）移至 $b$ 点（位矢 $\vec{r}_b$）。位移微元 $\mathrm{d}\vec{l}$ 在径向上的投影恰为径向距离增量 $\mathrm{d}l\cos\theta = \mathrm{d}r$，故元功与总功为：

$$\mathrm{d}A = \vec{F}\cdot\mathrm{d}\vec{l} = q_0 E\cos\theta\,\mathrm{d}l = \frac{q_0 q}{4\pi\varepsilon_0 r^2}\mathrm{d}r \implies A_{ab} = \int_{r_a}^{r_b}\frac{q_0 q}{4\pi\varepsilon_0 r^2}\mathrm{d}r = \frac{q_0 q}{4\pi\varepsilon_0}\left(\frac{1}{r_a} - \frac{1}{r_b}\right)$$

{{fig:F9-12}}

由场强叠加原理，在**任意静止带电体**激发的静电场中，静电场力对试探电荷所做的功 $A_{ab} = q_0\int_a^b \vec{E}\cdot\mathrm{d}\vec{l}$ **仅取决于起止位置 $a, b$，而与移动所经过的路径无关**。这表明静电场力是**保守力**，静电场是**保守场**。

若令积分路径为任意闭合回路 $L$（从 $a$ 经路径 $c$ 到 $b$，再经路径 $d$ 返回 $a$），由于 $\int_{a(c)}^b \vec{E}\cdot\mathrm{d}\vec{l} = \int_{a(d)}^b \vec{E}\cdot\mathrm{d}\vec{l} = -\int_{b(d)}^a \vec{E}\cdot\mathrm{d}\vec{l}$，消去 $q_0 \neq 0$ 即得**静电场的环路定理**：

$$\oint_L \vec{E}\cdot\mathrm{d}\vec{l} = 0$$

- **物理意义**：静电场的环流恒为零，表明静电场是**无旋场**（$\nabla \times \vec{E} = 0$）。这从理论上严格证明了**静电场线永远不会形成闭合曲线**（否则沿闭合电场线环路积分必大于零，违背环路定理）。

### 二、电势能、电势与电势差
既然静电场力是保守力，便可引入**静电势能 $W$**：试探电荷 $q_0$ 从 $a$ 移到 $b$ 时，静电场力所做的功等于其电势能的减少量：
$$A_{ab} = q_0\int_a^b \vec{E}\cdot\mathrm{d}\vec{l} = W_a - W_b$$

选定参考点 $P_0$ 为电势能零点（$W_{P0} = 0$），则 $q_0$ 在空间 $P$ 点的电势能为 $W_P = A_{P P_0} = q_0\int_P^{P_0}\vec{E}\cdot\mathrm{d}\vec{l}$。虽然 $W_P$ 与试探电荷 $q_0$ 成正比，但比值 $W_P / q_0$ 与 $q_0$ 无关，仅反映静电场本身在 $P$ 点的性质，定义为该点的**电势 $U_P$**：

$$U_P = \frac{W_P}{q_0} = \int_P^{P_0} \vec{E}\cdot\mathrm{d}\vec{l}$$

任意两点 $a, b$ 之间的**电势差**（又称**电压**）定义为：
$$U_{ab} = U_a - U_b = \int_a^b \vec{E}\cdot\mathrm{d}\vec{l}, \qquad A_{ab} = q_0(U_a - U_b) = q_0 U_{ab}$$

:::tip 电势的相对性与电势零点的选取准则
1. **电势 $U_P$ 是相对量**（与参考零点 $P_0$ 有关），而**电势差 $U_{ab}$ 和静电力做功 $A_{ab}$ 是绝对量**（与参考零点及积分路径均无关）。
2. **有限带电体**：当场源电荷分布在有限空间区域内时，理论计算通常取**无穷远处为电势零点**（$U_\infty = 0$），此时 $U_P = \int_P^\infty \vec{E}\cdot\mathrm{d}\vec{l}$；工程实践中常取**大地或仪器外壳**为电势零点。
3. **延伸至无穷远的理想带电体**（如无限长带电直线、无限长圆柱面、无限大带电平面）：由于无穷远处仍有电荷或场强按 $1/r$ 衰减导致积分 $\int_r^\infty \vec{E}\cdot\mathrm{d}\vec{l}$ 发散，**绝不能选无穷远为电势零点**，必须选有限位置 $r_0$ 为电势零点；同时**不能把电势零点选在点电荷所在位置**（否则出现 $1/0 \to \infty$ 奇点）。
:::

## 9.7 电势叠加原理与典型带电体电势 {#s9-7}

### 一、电势叠加原理（标量代数和与标量积分）
对有限范围分布的场源电荷，统一选无穷远处为电势零点（$U_\infty = 0$）。单个点电荷 $q$ 在距其 $r$ 处的电势为 $U = \frac{q}{4\pi\varepsilon_0 r}$。由场强叠加原理与线积分线性性质，点电荷系与连续分布带电体在空间 $P$ 点激发的总电势等于各电荷元单独激发电势的**标量代数和（标量积分）**：

$$U_P = \sum_{i=1}^{n} U_{Pi} = \sum_{i=1}^{n}\frac{q_i}{4\pi\varepsilon_0 r_i}, \qquad U_P = \int \mathrm{d}U_P = \int \frac{\mathrm{d}q}{4\pi\varepsilon_0 r}$$

:::note 求电势的两条核心路径对比
1. **场强线积分法**（$U_P = \int_P^{P_0}\vec{E}\cdot\mathrm{d}\vec{l}$）：适用于具有球对称、轴对称或平面对称的带电系统——先用高斯定理求出全空间的 $\vec{E}(r)$，再分段积分求电势（注意跨过分界面时积分需分段）。
2. **电势叠加原理**（$U_P = \int \frac{\mathrm{d}q}{4\pi\varepsilon_0 r}$）：适用于离散点电荷系、电偶极子、带电圆环、圆弧、圆盘等不具备高斯定理对称性但易求距离 $r$ 的系统。由于电势是标量，无需分解方向，积分往往比求场强简单得多。
:::

### 二、典型带电体的电势公式汇总（除注明外均取 $U_\infty = 0$）

| 带电体模型 | 电势分布公式 $U$ | 关键推导要点与特征说明 |
| :--- | :--- | :--- |
| **电偶极子远场**（$r \gg l$） | $U(r,\theta) \approx \dfrac{q l\cos\theta}{4\pi\varepsilon_0 r^2} = \dfrac{\vec{p}_e\cdot\hat{r}}{4\pi\varepsilon_0 r^2}$ | 波程差近似 $r_- - r_+ \approx l\cos\theta$；中垂面 $\theta = \pi/2$ 上 $U = 0$ |
| **均匀/非均匀带电圆环或圆弧** | 轴线：$U(z) = \dfrac{Q}{4\pi\varepsilon_0\sqrt{R^2+z^2}}$；环心：$U_O = \dfrac{Q}{4\pi\varepsilon_0 R}$ | 所有电荷元 $\mathrm{d}q$ 到轴线上同一点的距离恒为 $\sqrt{R^2+z^2}$，即使电荷沿环非均匀分布亦成立 |
| **均匀带电薄圆盘**（半径 $R$，面密度 $\sigma$） | 轴线：$U(z) = \dfrac{\sigma}{2\varepsilon_0}\left(\sqrt{R^2+z^2} - \lvert z \rvert\right)$；盘心：$U_O = \dfrac{\sigma R}{2\varepsilon_0}$；边缘：$U_{\mathrm{edge}} = \dfrac{\sigma R}{\pi\varepsilon_0}$ | 轴线用同心细环微元 $\mathrm{d}q = \sigma 2\pi r\,\mathrm{d}r$ 积分；边缘以边缘点为极点、$r \in [0, 2R\cos\theta]$ 积分 |

| **无限长均匀带电直线**（线密度 $\lambda$） | $U(r) = \dfrac{\lambda}{2\pi\varepsilon_0}\ln\dfrac{r_0}{r}$（选距轴线 $r_0$ 处为电势零点） | 不能选无穷远为电势零点；当 $r_0 = 1\,\mathrm{m}$ 时简记为 $U(r) = -\dfrac{\lambda}{2\pi\varepsilon_0}\ln r$ |

## 9.8 等势面与电势梯度 {#s9-8}

### 一、等势面及其三大几何性质
静电场中电势数值相等的各点连接而成的曲面 $U(x, y, z) = C$ 称为**等势面**。在等势面上移动任意试探电荷 $q_0$，由于 $\mathrm{d}U = 0$，电场力元功恒为零：$\mathrm{d}A = q_0\vec{E}\cdot\mathrm{d}\vec{l} = -q_0\,\mathrm{d}U = 0$。由此推出等势面的三条基本性质：
1. **等势面与电场线处处正交**（当 $\vec{E} \neq 0$ 时，$\vec{E} \perp \mathrm{d}\vec{l}$）；
2. **等势面密集处场强大，等势面稀疏处场强小**（若规定相邻等势面间电势差 $\lvert\Delta U\rvert$ 相等，则由 $E = \lvert\Delta U / \Delta n\rvert$ 知法向间距 $\Delta n$ 越小处 $E$ 越大）；
3. **电场线永远指向电势降低的方向**（不同等势面绝不相交）。

{{fig:F9-14}}

### 二、电场强度与电势梯度的关系
在电势分别为 $U$ 和 $U + \mathrm{d}U$ 的两个相邻等势面之间，将试探电荷 $q_0$ 沿任意位移微元 $\mathrm{d}\vec{l}$（与等势面外法线 $\hat{n}$ 夹角为 $\theta$）移动，则 $\mathrm{d}l\cos\theta = \mathrm{d}n$ 为两等势面间的法向垂直距离。由功与电势差关系：
$$q_0\vec{E}\cdot\mathrm{d}\vec{l} = q_0 E_l\,\mathrm{d}l = q_0\left[U - (U + \mathrm{d}U)\right] = -q_0\,\mathrm{d}U \implies E_l = -\frac{\mathrm{d}U}{\mathrm{d}l}, \quad E = -\frac{\mathrm{d}U}{\mathrm{d}n}$$

定义标量场 $U$ 沿法向升高的最大空间变化率矢量为**电势梯度** $\mathrm{grad}\,U = \nabla U = \frac{\mathrm{d}U}{\mathrm{d}n}\hat{n}$，则在直角坐标系中，**电场强度等于电势梯度的负值**：

$$\vec{E} = -\mathrm{grad}\,U = -\nabla U = -\frac{\mathrm{d}U}{\mathrm{d}n}\hat{n} = -\left(\frac{\partial U}{\partial x}\vec{i} + \frac{\partial U}{\partial y}\vec{j} + \frac{\partial U}{\partial z}\vec{k}\right)$$

{{fig:F9-15}}

:::check 求电场强度的三大支柱方法对比与自检
1. **场强叠加法**（$\vec{E} = \int \mathrm{d}\vec{E}$）：矢量积分，需正交分解与角度换元，普适但计算较繁；
2. **高斯定理法**（$\oint_S \vec{E}\cdot\mathrm{d}\vec{S} = Q_{\mathrm{enc}}/\varepsilon_0$）：仅适用于球对称、无限长轴对称、无限大平面对称（或挖空补偿法），一步脱去积分号，最为简捷；
3. **电势梯度法**（$\vec{E} = -\nabla U$）：先由标量积分 $U = \int \frac{\mathrm{d}q}{4\pi\varepsilon_0 r}$ 求出空间电势函数 $U(x,y,z)$，再对坐标求偏导数。**严防误区**：必须先求出待求点邻域的坐标函数 $U(x,y,z)$ 才能求导，绝不能对仅在单点成立的常数表达式（如圆心点 $U_O = \frac{q}{4\pi\varepsilon_0 R}$ 中的固定半径 $R$）求导！
:::
