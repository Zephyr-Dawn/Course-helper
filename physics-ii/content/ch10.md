# 第 10 章：静电场中的导体和电介质

在第 9 章中，我们把激发静电场的带电体抽象为电荷分布已知的理想模型（如点电荷、均匀带电细棒、圆环、圆盘与球体），置于真空中应用库仑定律、高斯定理与环路定理求解场强和电势。然而在实际工程与物理问题中，承载电荷和浸没于电场中的是各种各样的实物介质——**金属导体**与**电介质（绝缘体）**。当静电场中放入导体或电介质时，外电场会引起导体内自由电荷的宏观重新分布（**静电感应**）或电介质内分子电偶极矩的微观有序化（**电极化**）；反过来，这些感应电荷和极化（束缚）电荷又会激发附加电场，改变空间原有的电场与电势分布。本章将系统阐述**导体静电平衡与静电屏蔽**、**电容与电容器**、**电介质极化与有介质高斯定理（$\vec{D},\vec{E},\vec{P}$ 三矢量关系）**以及**静电场的能量与能量密度**。

## 10.1 导体的静电平衡条件与电荷分布 {#s10-1}

### 一、固体导电性的微观起源与静电感应

从凝聚态物质的原子结合方式（课件 PDF 第 141–142 页）来看，固体材料按导电性可分为三类：
1. **导体（以金属为代表）**：如金属钠（$\mathrm{Na}$）、铜、银等，依靠**金属性结合**形成晶格。价电子摆脱单个原子核的束缚成为可在整个晶格间自由游弋的**自由电子气**（电子浓度高达 $10^{28}\sim 10^{29}\,\mathrm{m^{-3}}$），外加电场下能迅速发生宏观定向移动。
2. **绝缘体（电介质）**：如氯化钠（离子键结合）、金刚石（共价键结合）、固态氩（范德瓦尔斯结合）等，电子被紧紧束缚在离子实或共价键周围，几乎不存在可自由移动的载流子，电荷无法在其中宏观传导。
3. **半导体**：具有一定浓度的电子和空穴载流子，导电能力介于导体与绝缘体之间，且对温度、光照和掺杂极为敏感。

当把一块金属导体放入外电场 $\vec{E}_0$ 中时，导体内的自由电子在电场力 $\vec{F} = -e\vec{E}_0$ 驱动下逆着外电场方向高速漂移（金属中的电荷弛豫时间极短，仅为 $\tau \sim 10^{-15}\sim 10^{-19}\,\mathrm{s}$，这也是金属能强烈反射频率约 $10^{15}\,\mathrm{Hz}$ 可见光的原因）。结果在迎着电场线的一端积累负电荷，顺着电场线的一端出现未被中和的正离子实（正电荷）——这种在外电场作用下导体两端出现等量异号电荷的现象称为**静电感应**。

{{fig:F10-01}}

随着导体表面感应电荷的积累，感应电荷在导体内部激发出与外电场反向的附加电场 $\vec{E}'$。只要内部合场强 $\vec{E}_{\mathrm{i}} = \vec{E}_0 + \vec{E}' \neq 0$，自由电子就会继续定向移动；直至附加电场与外电场在导体内部处处完全抵消（$\vec{E}_{\mathrm{i}} = 0$），自由电荷不再作任何宏观定向运动，此时导体达到**静电平衡状态**。

### 二、导体静电平衡的三大基本性质

:::tip 静电平衡的充要条件与推论（PDF p144–145）
1. **内部场强处处为零（充要条件）**：导体内部任意一点的宏观合电场强度恒等于零：
   $$\vec{E}_{\mathrm{in}} = \vec{E}_0 + \vec{E}' = 0$$
2. **导体是等势体，导体表面是等势面**：在导体内部任取两点 $p, q$，因 $\vec{E}_{\mathrm{in}} = 0$，电势差为
   $$U_{pq} = \int_p^q \vec{E}\cdot\mathrm{d}\vec{l} = 0 \implies U_p = U_q = \mathrm{const}$$
3. **表面外侧紧邻处的场强处处垂直于导体表面**：在导体表面紧邻处场强可以不为零，但其切向分量必为零（$E_t = 0$），否则表面自由电荷将在切向力作用下继续沿表面作宏观定向移动。即导体表面场强平行于外法线方向：
   $$\vec{E}_{\mathrm{surf}} \parallel \vec{e}_n,\qquad E_t = 0$$
:::

### 三、实心导体静电平衡时的电荷分布规律

1. **导体内部处处无净电荷（$\rho_{\mathrm{in}} = 0$）**：在导体内部任意体积元外包裹一闭合高斯面 $S$（完全位于导体内部，见 PDF 第 147 页）。由于高斯面上处处有 $\vec{E} = 0$，由静电场高斯定理：
   $$\oint_S \vec{E}\cdot\mathrm{d}\vec{S} = \frac{1}{\varepsilon_0}\sum_{S\mathrm{in}} q = 0 \implies \sum_{S\mathrm{in}} q = 0$$
   因为高斯面 $S$ 可以任意缩小至包围任意内点，故**处于静电平衡的导体内部任何位置都没有净电荷（$\rho_{\mathrm{in}} = 0$），电荷只能分布在导体的表面上**。

2. **导体表面紧邻处的场强与表面电荷面密度 $\sigma$ 的关系**：在导体表面附近作一个极扁的圆柱形高斯面（底面积为 $\Delta S$，见下图 `F10-02`）：内底面在导体内部（$\vec{E} = 0$，无电通量），圆柱侧面极薄且与垂直于表面的场强 $\vec{E}$ 平行（无电通量），唯有位于导体外部紧邻处的外底面有电通量 $E\Delta S$。由高斯定理得：
   $$\oint_S \vec{E}\cdot\mathrm{d}\vec{S} = E\,\Delta S = \frac{\sigma\,\Delta S}{\varepsilon_0} \implies \vec{E}_{\mathrm{surf}} = \frac{\sigma}{\varepsilon_0}\vec{e}_n$$
   其中 $\vec{e}_n$ 为导体表面指向外部空间的外法线单位矢量。当 $\sigma > 0$ 时电场线垂直表面向外发出；当 $\sigma < 0$ 时电场线垂直终止于导体表面。

{{fig:F10-02}}

:::warn 高频易错辨析：$E = \sigma/\varepsilon_0$ 与 $E = \sigma/(2\varepsilon_0)$ 的本质区别
- **导体表面紧邻处的合场强 $E = \sigma/\varepsilon_0$（无分母 $2$）**：这是由**空间所有电荷**（包括紧邻面元 $\sigma\Delta S$ 本身以及导体其余表面电荷、甚至周围外部带电体）在该点共同激发的**总场强**！其中紧邻面元 $\sigma\Delta S$（可视为局部无限大平面）在导体内外两侧各贡献 $\dfrac{\sigma}{2\varepsilon_0}$，而空间其余所有电荷在该处激发的场强也恰好等于 $\dfrac{\sigma}{2\varepsilon_0}$：在导体内侧两者反向相消为 $0$，在导体外侧两者同向叠加为 $\dfrac{\sigma}{2\varepsilon_0} + \dfrac{\sigma}{2\varepsilon_0} = \dfrac{\sigma}{\varepsilon_0}$。
- **孤立无限大均匀带电薄平面的场强 $E = \sigma/(2\varepsilon_0)$（有分母 $2$）**：这是单层电荷平面独自在两侧激发的对称场强。
:::

{{ex:EX10-01}}

3. **孤立导体表面电荷面密度与表面曲率的关系（尖端放电）**：对于周围无其他带电体的孤立带电导体，表面电荷分布与局部几何曲率密切相关——**表面越凸出（曲率越大、曲率半径越小）的位置，电荷面密度 $\lvert\sigma\rvert$ 越大，邻近等势面越密集，表面场强 $E = \lvert\sigma\rvert/\varepsilon_0$ 越强**；反之，平坦处 $\lvert\sigma\rvert$ 较小，凹陷处 $\lvert\sigma\rvert$ 最小。

{{fig:F10-03}}

当带电导体具有极尖锐的尖端时，尖端附近极强的电场会将周围空气分子中的电子撕裂出来，形成大量正负离子。与尖端异号的离子被吸引到尖端中和电荷，同号离子被强场排斥向外飞散并形成“电风”和蓝紫色光晕——这就是**尖端放电（电晕放电）**。工程上既利用这一原理制造**避雷针**（将雷云电荷提前引流泄入大地），也在高压输电金具、范德格拉夫起电机球壳设计中尽量采用大曲率半径的光滑球面以消除尖端放电损耗。

## 10.2 空腔导体、静电屏蔽与平行金属板系统 {#s10-2}

### 一、空腔导体上的电荷分布与证明

当导体内部包含一个空腔时，空腔内表面与外表面的电荷分布取决于**空腔内是否有带电体**以及**空腔导体是否接地**。

#### 1. 腔内无带电体的空腔导体（B1 情形，PDF p155–157）
若空腔内部没有任何带电体（$q_{\mathrm{cav}} = 0$），无论空腔导体本身是否带电、也无论导体外部是否存在其他带电体，达到静电平衡时：
- **结论**：**空腔内表面处处没有电荷（$\sigma_{\mathrm{in}} = 0$），空腔内部场强处处为零（$\vec{E}_{\mathrm{cav}} = 0$），电荷只能分布在导体的外表面上**。
- **严谨证明（高斯定理 + 环路定理反证法）**：
  1. 首先在导体肉内紧贴空腔内表面作一包围整个空腔的高斯面 $S$。因为导体内 $\vec{E} = 0$，由高斯定理 $\oint_S \vec{E}\cdot\mathrm{d}\vec{S} = \sum q/\varepsilon_0 = 0$，可知**空腔内表面上的净电荷代数和必为零**（$q_{\mathrm{in}} = 0$）。
  2. 但是，仅凭高斯定理无法排除“空腔内表面局部带 $+q$、另一处带 $-q$（等量异号电荷）”的可能性！为此必须联立**静电场环路定理**作反证法（见图 `F10-04`）：假设空腔内表面存在等量异号电荷，则空腔内必有从内表面正电荷区发出、终止于内表面负电荷区的电场线。取一条闭合回路 $L$，使其一部分沿空腔内的某条电场线从正电荷端走向负电荷端，另一部分在导体内部（$\vec{E} = 0$）闭合回到起点，则环路积分为：
     $$\oint_L \vec{E}\cdot\mathrm{d}\vec{l} = \int_{\mathrm{cav}} \vec{E}\cdot\mathrm{d}\vec{l} + \int_{\mathrm{metal}} 0\cdot\mathrm{d}\vec{l} = \int_{\mathrm{cav}} E\,\mathrm{d}l > 0$$
     这与静电场环路定理 $\oint_L \vec{E}\cdot\mathrm{d}\vec{l} = 0$ 产生尖锐矛盾！因此假设不成立，空腔内必有 $\vec{E}_{\mathrm{cav}} = 0$，内表面任何位置都不可能存在净电荷（$\sigma_{\mathrm{in}} = 0$）。

{{fig:F10-04}}

#### 2. 腔内有带电体的空腔导体（B2 情形，PDF p158–160）
设空腔导体原本所带总电量为 $Q_0$，空腔内部放有电荷量为 $+q$ 的带电体 $A$。在导体肉内作包围空腔的高斯面 $S$，由导体内 $\vec{E} = 0$ 及高斯定理得：
$$q + q_{\\mathrm{in}} = 0 \implies q_{\\mathrm{in}} = -q$$
再由空腔导体的电荷守恒定律：
- **若空腔导体不接地**：导体外表面带电量为 $q_{\mathrm{out}} = Q_0 - q_{\mathrm{in}} = Q_0 + q$（若壳原本不带电 $Q_0=0$，则内表面带 $-q$、外表面带 $+q$）。
- **若空腔导体接地（且外部无其他电荷）**：大地与导体外壳构成等势零点（$U = 0$），外表面电荷全部被大地中和，即 $q_{\mathrm{out}} = 0$，腔外场强处处为零。

### 三、平行金属板系统的电荷分布与接地计算

在期中考试中，**两块（或多块）平行无限大金属板的四个（或多个）表面电荷面密度求解**是出现频率最高的核心题型（见课件 PDF 第 163–170 页例 10.4）。设两块面积均为 $S$ 的平行金属板 $A$ 和 $B$ 分别带总电量 $Q_1$ 和 $Q_2$，从左到右四个表面的电荷面密度依次设为 $\sigma_1, \sigma_2, \sigma_3, \sigma_4$。

{{fig:F10-07}}

:::derive 平行金属板四表面电荷面密度的两种标准推导（叠加法 vs 高斯面法）
1. **方法一（无限大平面场强叠加 + 导体内部场强为零）**：
   每个表面可视为无限大均匀带电平面，在两侧空间激发大小均为 $\dfrac{\sigma_i}{2\varepsilon_0}$ 的匀强电场。取向右为正方向，在板 $A$ 内部点 $a$ 和板 $B$ 内部点 $b$ 分别列出合场强为零的方程：
   $$E_a = \frac{\sigma_1 - \sigma_2 - \sigma_3 - \sigma_4}{2\varepsilon_0} = 0,\qquad E_b = \frac{\sigma_1 + \sigma_2 + \sigma_3 - \sigma_4}{2\varepsilon_0} = 0$$
   两式相加立即得出**外侧两表面面密度相等**：$\sigma_1 = \sigma_4$；两式相减立即得出**内侧相对两表面面密度等量异号**：$\sigma_2 + \sigma_3 = 0 \implies \sigma_3 = -\sigma_2$。
2. **方法二（跨板间高斯柱面 + 电荷守恒）**：
   直接取一个左底面在板 $A$ 内部（$E_a=0$）、右底面在板 $B$ 内部（$E_b=0$）、侧面垂直于极板的圆柱形高斯面，由高斯定理知柱面内包含的净电荷必为零：$(\sigma_2 + \sigma_3)\Delta S = 0 \implies \sigma_3 = -\sigma_2$。再结合两板的电荷守恒定律：
   $$\sigma_1 S + \sigma_2 S = Q_1,\qquad \sigma_3 S + \sigma_4 S = Q_2$$
   联立解得普适公式：
   $$\sigma_1 = \sigma_4 = \frac{Q_1 + Q_2}{2S},\qquad \sigma_2 = -\sigma_3 = \frac{Q_1 - Q_2}{2S}$$
:::

:::warn 导体接地的核心判据：接地 $\iff U = 0$（绝不等于 $Q = 0$！）
- 当**最外侧表面面向无穷远零电势环境**的平行板（如例 10.4 中的 $B$ 板）接地时，右侧 $\mathrm{III}$ 区电势差为零、场强 $E_{\mathrm{III}} = 0$，从而最外侧表面 $\sigma_1' = \sigma_4' = 0$，内侧相对表面 $\sigma_2' = -\sigma_3' = Q_1/S$，此时 $B$ 板总感应电荷为 $Q_B' = -Q_1 \neq 0$！
- 当**同心球壳系统的内球接地**（如例 10.5，外球壳带 $+Q$、内球半径 $R_1$ 接地）时，内球电势 $U_O = \dfrac{Q_x}{4\pi\varepsilon_0 R_1} + \dfrac{Q}{4\pi\varepsilon_0 R_2} = 0$，内球必带上感应电荷 $Q_x = -\dfrac{R_1}{R_2}Q \neq 0$。
:::

## 10.3 电容与电容器的串联、并联计算 {#s10-3}

### 一、孤立导体的电容与电容器的定义

1. **孤立导体的电容（PDF p175）**：当周围没有任何其他带电体和导体时，一个孤立导体所带电荷量 $q$ 与其电势 $U$（以无穷远处为电势零点）成正比，其比值定义为该孤立导体的**电容**：
   $$C = \frac{q}{U}$$
   例如，真空中半径为 $R$ 的孤立球形导体电势为 $U = \dfrac{q}{4\pi\varepsilon_0 R}$，故其电容为：
   $$C_{\mathrm{sphere}} = 4\pi\varepsilon_0 R$$
   电容的大小**与导体是否带电、带多少电荷无关**，仅由导体自身的几何形状、尺寸及周围介质决定，表征导体每升高单位电势所能容纳电荷量的本领。国际单位制中电容单位为**法拉（$\mathrm{F}$）**，$1\,\mathrm{F} = 1\,\mathrm{C/V} = 10^6\,\mu\mathrm{F} = 10^{12}\,\mathrm{pF}$。

2. **电容器及其电容定义（PDF p176）**：为了不受周围环境干扰并大幅提高储存电荷与电能的能力，工程上采用由电介质（或真空）隔开的两个导体极板 $A, B$ 组成**电容器**。当两极板分别带上等量异号电荷 $+Q$ 和 $-Q$ 时，极板电量大小 $Q$ 与两极板间电势差 $U_A - U_B$ 之比定义为电容器的电容：
   $$C = \frac{Q}{U_A - U_B}$$

:::tip 求解任意电容器电容的标准四步法（PDF p187）
1. **假想设电**：假设电容器两极板分别带有等量异号电荷 $+Q$ 和 $-Q$（或设线密度 $\pm\lambda$、面密度 $\pm\sigma$）；
2. **求板间场强 $\vec{E}$**：利用高斯定理或场强叠加原理求出两极板之间区域的电场强度分布 $\vec{E}(r)$；
3. **积分求电势差 $U_{AB}$**：沿板间任意方便路径积分计算电势差 $U_A - U_B = \int_A^B \vec{E}\cdot\mathrm{d}\vec{l}$；
4. **比值消 $Q$ 得 $C$**：代入定义式 $C = \dfrac{Q}{U_A - U_B}$ 消去假设的 $Q$，得到仅含几何参数与介电常数的表达式。
:::

### 三、电容器的串联与并联

1. **电容器串联（等电量、分电压，PDF p182–183）**：
   将 $n$ 个电容器首尾相连，中间相连的极板靠静电感应带上等量异号电荷，故**每个电容器所带电荷量相等**：$Q_1 = Q_2 = \cdots = Q_n = Q$；总电势差等于各电容器电势差之和 $U_{AB} = \sum_{i=1}^n U_i = \sum_{i=1}^n \dfrac{Q}{C_i}$，等效电容 $C$ 满足：
   $$\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots + \frac{1}{C_n}$$
   **物理特征**：串联相当于等效增大了极板间距 $d$，总电容比最小的一个分电容还要小，但系统的总耐压值提高（注意各电容分担电压 $U_i = \dfrac{Q}{C_i}$ 与电容成反比，需校核每个单元均有 $U_i \le U_{i,\max}$）。

2. **电容器并联（等电势差、分电量，PDF p184）**：
   所有电容器正极板相连、负极板相连，各电容器两端电势差相同：$U_1 = U_2 = \cdots = U_n = U_{AB}$；总电量等于各电容器电量之和 $Q = \sum_{i=1}^n q_i = \left(\sum_{i=1}^n C_i\right)U_{AB}$，等效电容为：
   $$C = C_1 + C_2 + \cdots + C_n$$
   **物理特征**：并联相当于增大了极板有效面积 $S$，总电容增大，但并联组的最大安全耐压等于各单元中最低的耐压值 $\min(U_{i,\max})$。

## 10.4 电介质的极化机制、极化强度与束缚电荷 {#s10-4}

### 一、电介质对电场的宏观实验规律（法拉第实验，PDF p190）

平行板空气电容器（原始电容 $C_0$）充电至带电量 $Q_0$、两板电势差为 $U_0 = Q_0/C_0$ 后**断开电源**（保持极板自由电荷 $Q_0$ 不变）。实验发现，当在两极板间充满某种各向同性均匀绝缘电介质时，静电计测得两极板间的电势差显著下降为原来的 $\dfrac{1}{\varepsilon_{\mathrm{r}}}$（其中无量纲常数 $\varepsilon_{\mathrm{r}} > 1$ 称为电介质的**相对介电常数**或**相对电容率**，真空中定义 $\varepsilon_{\mathrm{r}} = 1$）：
$$U = \frac{U_0}{\varepsilon_{\mathrm{r}}},\qquad E = \frac{U}{d} = \frac{E_0}{\varepsilon_{\mathrm{r}}},\qquad C = \frac{Q_0}{U} = \varepsilon_{\mathrm{r}}C_0$$
为什么没有自由电荷的绝缘电介质能够削弱板间电场并成倍提升电容？其微观根源在于**电介质的极化**。

### 二、无极分子与有极分子的两类极化机制（PDF p191–193）

1. **无极分子（Non-polar molecules）与位移极化**：
   如 $\mathrm{H_2}$、$\mathrm{N_2}$、$\mathrm{CH_4}$（甲烷）、$\mathrm{CCl_4}$ 等对称分子，无外电场时分子的正电荷中心与负电荷中心重合，固有分子电偶极矩 $\vec{p} = 0$。当置于外电场 $\vec{E}$ 中时，正电荷中心顺场微移、负电荷电子云逆场微移，形成平行于外场的**感生电偶极矩** $\vec{p} = q\vec{l}$。这种极化称为**位移极化（电子云畸变极化）**。
2. **有极分子（Polar molecules）与取向极化**：
   如 $\mathrm{H_2O}$（水分子，正负电荷中心张角 $104.5^\circ$）、$\mathrm{HCl}$、$\mathrm{CO}$ 等非对称分子，无外电场时每个分子本身就具有永存的**固有电偶极矩** $\vec{p} \neq 0$，但因热运动取向杂乱无章，宏观统计总电偶极矩 $\sum\vec{p}_i = 0$。当施加外电场 $\vec{E}$ 时，各分子偶极子受到力矩 $\vec{M} = \vec{p}\times\vec{E}$ 的作用而趋向于沿外电场方向转向排列；外场越强、温度越低，取向越整齐。这种极化称为**取向极化**。

{{fig:F10-10}}

:::note 极化（束缚）电荷的物理特征
- 无论位移极化还是取向极化，对于**均匀电介质**，其内部相邻分子的正负电荷彼此中和抵消，**介质内部体束缚电荷密度恒为零（$\rho' = 0$）**；
- 唯有在电介质的**表面（或不同电介质的分界面）**上，出现一层无法脱离分子束缚、也不能被导体导出到外界的宏观净电荷，称为**极化电荷**或**束缚电荷**（面密度记为 $\sigma'$）。
- 在静电场或低频场中，有极分子同时存在取向极化与位移极化；而在光频等极高频交变场中，分子整体转动惯量太大跟不上场频，取向极化消失，仅存电子位移极化。
:::

### 三、电极化强度矢量 $\vec{P}$ 与极化电荷面密度 $\sigma'$

1. **电极化强度矢量 $\vec{P}$ 的定义（PDF p194）**：
   为了从宏观上定量刻画电介质极化的强弱与方向，定义**单位体积内所有分子电偶极矩的矢量和**为**电极化强度矢量** $\vec{P}$（国际单位为 $\mathrm{C\cdot m^{-2}}$）：
   $$\vec{P} = \frac{\sum \vec{p}_i}{\Delta V}$$
   其中宏观体积元 $\Delta V$ 在物理上无穷小，但在微观上仍包含海量分子。

2. **电介质的极化规律（本构关系，PDF p194–195）**：
   对于**各向同性线性电介质**，实验证实某点的电极化强度矢量 $\vec{P}$ 与该点的**宏观合电场强度 $\vec{E}$** 成正比且同向：
   $$\vec{P} = \chi_{\mathrm{e}}\varepsilon_0\vec{E}$$
   式中无量纲比例系数 $\chi_{\mathrm{e}} > 0$ 称为电介质的**电极化率**（真空中 $\chi_{\mathrm{e}} = 0$）。
   - *拓展*：对于晶体等**各向异性线性介质**，$\chi_{\mathrm{e}}$ 推广为二阶极化率张量 $\boldsymbol{\chi}$（$3\times 3$ 矩阵），$\vec{P} = \varepsilon_0\boldsymbol{\chi}\cdot\vec{E}$，此时 $\vec{P}$ 与 $\vec{E}$ 一般不再同向；在强激光场下还会激发二阶、三阶非线性极化项 $\boldsymbol{\chi}^{(2)}:\vec{E}\vec{E} + \boldsymbol{\chi}^{(3)}\vdots\vec{E}\vec{E}\vec{E}$。

3. **极化强度 $\vec{P}$ 与极化电荷面密度 $\sigma'$ 的定量关系（PDF p196–197）**：
   在均匀电介质的边界面上任取面元 $\mathrm{d}S$，设该处介质指向外部空间的外法线单位矢量为 $\vec{e}_n$，介质内极化强度 $\vec{P}$ 与 $\vec{e}_n$ 的夹角为 $\theta$（见下图 `F10-11`）。

{{fig:F10-11}}

   以 $\mathrm{d}S$ 为底面、顺着 $\vec{P}$ 的方向在介质内截取一段母线长为 $L$（分子偶极子等效正负电荷间距）的斜柱体体积元：
   - 斜柱体的体积为 $\mathrm{d}V = L\,\mathrm{d}S\cos\theta$；
   - 斜柱体两个端面分别聚集了极化电荷 $+\sigma'\mathrm{d}S$ 和 $-\sigma'\mathrm{d}S$，它们构成的宏观总电偶极矩大小为 $\lvert\mathrm{d}\sum\vec{p}_i\rvert = (\sigma'\mathrm{d}S)L$；
   - 代入电极化强度定义式 $P = \dfrac{\lvert\mathrm{d}\sum\vec{p}_i\rvert}{\mathrm{d}V}$：
     $$P = \frac{\sigma'\,\mathrm{d}S\cdot L}{L\,\mathrm{d}S\cos\theta} = \frac{\sigma'}{\cos\theta} \implies \sigma' = P\cos\theta = P_n = \vec{P}\cdot\vec{e}_n$$
   **物理判据**：當 $0 \le \theta < \pi/2$（$\vec{P}$ 从介质内部穿出边界面）时，$\sigma' > 0$（出现正束缚电荷）；当 $\pi/2 < \theta \le \pi$（$\vec{P}$ 从外部穿入介质）时，$\sigma' < 0$（出现负束缚电荷）；当 $\theta = \pi/2$（$\vec{P}$ 与边界面平行）时，$\sigma' = 0$。

## 10.5 电位移矢量 $\vec{D}$ 与有电介质的高斯定理 {#s10-5}

### 一、电介质内部的宏观合场强与退极化场（PDF p198–204）

束缚电荷虽然不能自由移动，但它同样是静止电荷，遵循库仑定律、静电场高斯定理与环路定理。因此，电介质内部任一点的宏观合电场强度 $\vec{E}$ 等于**自由电荷激发的外电场 $\vec{E}_0$** 与**束缚电荷激发的附加退极化场 $\vec{E}'$** 的矢量和：
$$\vec{E} = \vec{E}_0 + \vec{E}'$$
以充满极化率为 $\chi_{\mathrm{e}}$ 的均匀电介质的无限大平行板电容器为例（极板自由电荷面密度为 $\pm\sigma_0$，见课件 PDF 第 200–202 页）：
- 自由电荷激发的原场强为 $E_0 = \dfrac{\sigma_0}{\varepsilon_0}$，方向由正极板指向负极板；
- 紧贴正极板的电介质上表面出现负束缚电荷 $-\sigma'$（因为 $\theta = \pi$，$\sigma_{\mathrm{up}}' = P\cos\pi = -P$），紧贴负极板的介质下表面出现正束缚电荷 $+\sigma'$（$\theta = 0$，$\sigma_{\mathrm{down}}' = +P$），它们在介质内激发与 $\vec{E}_0$ 反向的匀强退极化场 $E' = \dfrac{\sigma'}{\varepsilon_0} = \dfrac{P}{\varepsilon_0}$；
- 将本构关系 $P = \chi_{\mathrm{e}}\varepsilon_0 E$ 代入合场强方程：
  $$E = E_0 - E' = E_0 - \frac{\sigma'}{\varepsilon_0} = E_0 - \frac{P}{\varepsilon_0} = E_0 - \chi_{\mathrm{e}}E \implies E = \frac{E_0}{1 + \chi_{\mathrm{e}}} = \frac{E_0}{\varepsilon_{\mathrm{r}}}$$
由此立即导出**相对介电常数 $\varepsilon_{\mathrm{r}}$ 与电极化率 $\chi_{\mathrm{e}}$ 的普遍微观-宏观桥梁关系**：
$$\varepsilon_{\mathrm{r}} = 1 + \chi_{\mathrm{e}},\qquad \varepsilon = \varepsilon_0\varepsilon_{\mathrm{r}} = \varepsilon_0(1 + \chi_{\mathrm{e}})$$
式中 $\varepsilon = \varepsilon_0\varepsilon_{\mathrm{r}}$ 称为电介质的**绝对介电常数（电容率）**。

{{ex:EX10-07}}

### 二、电位移矢量 $\vec{D}$ 与有电介质的高斯定理推导（PDF p205–212）

在存在电介质的空间中，真空中的高斯定理包含**所有电荷**（自由电荷 $q_0$ 与束缚电荷 $q'$）：
$$\oint_S \vec{E}\cdot\mathrm{d}\vec{S} = \frac{1}{\varepsilon_0}\left(\sum_{S\mathrm{in}} q_0 + \sum_{S\mathrm{in}} q'\right)$$
然而在实际问题中，我们往往只知道自由电荷 $q_0$，而束缚电荷 $q'$ 依赖于待求的合场强 $\vec{E}$，形成“求 $\vec{E}$ 需要先知 $q'$、求 $q'$ 又需要先知 $\vec{E}$”的循环困境。为了消去未知的束缚电荷 $\sum q'$，考察图 `F10-12` 中跨越金属上极板与电介质的圆柱形高斯面 $S$：

{{fig:F10-12}}

:::derive 电位移矢量 $\vec{D}$ 与有电介质高斯定理的完整推导（PDF p208–210）
1. 在图 `F10-12` 所示高斯面 $S$ 中，上底面位于金属极板内部（$\vec{E}=0, \vec{P}=0$），下底面面积为 $S_2$ 位于电介质内。高斯面内包围的自由电荷为 $\sum q_0 = \sigma_0 S_1$，包围的束缚电荷为 $\sum q' = -\sigma' S_2$。
2. 注意到在电介质上表面有 $-\sigma' = \vec{P}\cdot\vec{e}_{n,\mathrm{media}}$，而高斯面下底面的外法线方向向下（与 $\vec{P}$ 同向），因此电极化强度 $\vec{P}$ 穿过闭合高斯面 $S$ 的通量恰好等于高斯面内束缚电荷的负值（此结论对任意闭合曲面普遍成立）：
   $$\oint_S \vec{P}\cdot\mathrm{d}\vec{S} = -\sum_{S\mathrm{in}} q'$$
3. 将 $\sum_{S\mathrm{in}} q' = -\oint_S \vec{P}\cdot\mathrm{d}\vec{S}$ 代入总电荷高斯定理并移项合并：
   $$\oint_S \varepsilon_0\vec{E}\cdot\mathrm{d}\vec{S} = \sum_{S\mathrm{in}} q_0 - \oint_S \vec{P}\cdot\mathrm{d}\vec{S} \implies \oint_S (\varepsilon_0\vec{E} + \vec{P})\cdot\mathrm{d}\vec{S} = \sum_{S\mathrm{in}} q_0$$
4. 引入辅助矢量场——**电位移矢量（Electric Displacement Vector）** $\vec{D}$（国际单位为 $\mathrm{C\cdot m^{-2}}$）：
   $$\vec{D} = \varepsilon_0\vec{E} + \vec{P}$$
   对于各向同性线性电介质，将 $\vec{P} = \varepsilon_0(\varepsilon_{\mathrm{r}}-1)\vec{E}$ 代入得：
   $$\vec{D} = \varepsilon_0\vec{E} + \varepsilon_0(\varepsilon_{\mathrm{r}} - 1)\vec{E} = \varepsilon_0\varepsilon_{\mathrm{r}}\vec{E} = \varepsilon\vec{E}$$
   于是得到**有电介质时的静电场高斯定理**：
   $$\oint_S \vec{D}\cdot\mathrm{d}\vec{S} = \sum_{S\mathrm{in}} q_0$$
   即：**通过任意闭合曲面的电位移通量，恒等于该闭合曲面所包围的自由电荷量的代数和**。
:::

## 10.6 含电介质电容器综合分析：分层串联与并排并联 {#s10-6}

在应用有电介质的高斯定理 $\oint_S \vec{D}\cdot\mathrm{d}\vec{S} = \sum q_0$ 求解含多层或多区电介质的电容器问题时，**最核心的判据是分析电介质分界面与等势面（导体极板）的几何关系**（见课件 PDF 第 213–224 页）：

### 一、第一类模型：电介质沿等势面分层填充（串联型，$\vec{D}$ 连续）

当两层（或多层）均匀电介质 $\varepsilon_{\mathrm{r1}}, \varepsilon_{\mathrm{r2}}$ 的**分界面平行于金属极板等势面**（如平行板上下分层填充 $d_1, d_2$、同轴圆柱内外分层、同心球壳内外分层，见例 10.8 及图 `F10-13`）时：
1. **自由电荷对称性保持不变**：极板上的自由电荷分布仍然完全均匀（平面 $\sigma_0 = Q/S$、柱面 $\lambda_0 = Q/l$、球面 $\sigma_0 = Q/(4\pi R_1^2)$）；
2. **电位移矢量跨界面连续**：在两层电介质中分别作高斯面，包围的自由电荷相同（均为 $Q$），故电位移线直接穿过分界面而不中断（左侧为平板分层，右侧为同心球分层）：
   $$D_{\mathrm{plate,1}} = D_{\mathrm{plate,2}} = \sigma_0 = \frac{Q}{S},\qquad D_{\mathrm{sph,1}}(r) = D_{\mathrm{sph,2}}(r) = \frac{Q}{4\pi r^2}$$
3. **场强按介电常数成反比分配（$E \propto 1/\varepsilon_{\mathrm{r}}$）**：
   $$E_1 = \frac{D_1}{\varepsilon_0\varepsilon_{\mathrm{r1}}},\qquad E_2 = \frac{D_2}{\varepsilon_0\varepsilon_{\mathrm{r2}}} \implies \frac{E_1}{E_2} = \frac{\varepsilon_{\mathrm{r2}}}{\varepsilon_{\mathrm{r1}}}$$
   介电常数**较小**的那一层电介质承受**更高**的电场强度，在提升外加电压时往往先达到击穿场强 $E_{\mathrm{bd}}$！
4. **交界面极化电荷面密度**：在分界面上，内侧介质 1 的外法线 $\vec{e}_{n1}$ 与外侧介质 2 的外法线 $\vec{e}_{n2} = -\vec{e}_{n1}$ 方向相反，故总束缚电荷面密度为：
   $$\sigma_{\mathrm{jj}}' = \sigma_1' + \sigma_2' = P_1 - P_2 = D_n\left(\frac{1}{\varepsilon_{\mathrm{r2}}} - \frac{1}{\varepsilon_{\mathrm{r1}}}\right)$$

## 10.7 静电场的能量与能量密度 {#s10-7}

### 一、点电荷系统与连续带电体的静电能（相互作用能，PDF p225–228）

把原本相距无穷远（相互作用能为零）的若干电荷逐个搬运到现存位置的过程，外力克服静电力所做的总功全部转化为带电系统的**静电能** $W$：
1. **两个点电荷系统**：先将 $q_1$ 从无穷远移到 $A$ 点（无外场，做功 $A_1 = 0$）；再将 $q_2$ 从无穷远移到距 $A$ 为 $r$ 的 $B$ 点，外力克服 $q_1$ 的电场力做功 $A_2 = q_2 U_{2} = \dfrac{q_1 q_2}{4\pi\varepsilon_0 r}$。利用对称性可改写为：
   $$W = \frac{1}{4\pi\varepsilon_0}\frac{q_1 q_2}{r} = \frac{1}{2}q_1 U_1 + \frac{1}{2}q_2 U_2$$
   其中 $U_1 = \dfrac{q_2}{4\pi\varepsilon_0 r}$ 是 $q_2$ 在 $q_1$ 处激发的电势，$U_2 = \dfrac{q_1}{4\pi\varepsilon_0 r}$ 是 $q_1$ 在 $q_2$ 处激发的电势（系数 $\dfrac{1}{2}$ 是为了避免把每对电荷 $(i,j)$ 的相互作用能重复计算两次）。
2. **$n$ 个点电荷系统与连续分布带电体**：
   推广至 $n$ 个点电荷系统及电荷连续分布的带电体（体密度 $\rho$、面密度 $\sigma$）：
   $$W = \frac{1}{2}\sum_{i=1}^n q_i U_i,\qquad W = \frac{1}{2}\int_q U\,\mathrm{d}q = \frac{1}{2}\iiint_V \rho U\,\mathrm{d}V + \frac{1}{2}\iint_S \sigma U\,\mathrm{d}S$$
   - **重要物理说明（PDF p228）**：在点电荷系求和式 $\frac{1}{2}\sum q_i U_i$ 中，$U_i$ 是**除 $q_i$ 自身以外**其余所有点电荷在 $q_i$ 处产生的电势（点电荷自能发散，不可计入）；而在连续带电体积分式 $\frac{1}{2}\int U\,\mathrm{d}q$ 中，无穷小电荷元 $\mathrm{d}q = \rho\,\mathrm{d}V$ 自身激发的电势为高阶无穷小（$r\to 0$ 时 $\rho r^3/r \sim r^2 \to 0$），故积分式中的 $U$ 直接取**空间所有电荷在该点共同激发的总电势**即可！

### 二、电容器的静电能与拉板/插介质做功分析（PDF p229）

对电容为 $C$ 的电容器充电：设中间某时刻两极板带电量为 $\pm q$，极板间电势差为 $u = q/C$。外力将无穷小正电荷 $+\mathrm{d}q$ 从负极板移送到正极板需做元功 $\mathrm{d}A = u\,\mathrm{d}q = \dfrac{q}{C}\mathrm{d}q$。从 $q = 0$ 积分至最终带电量 $Q$（最终电压 $U = U_A - U_B = Q/C$），得电容器储存的静电能三等价公式：
$$W_e = \int_0^Q \frac{q}{C}\,\mathrm{d}q = \frac{Q^2}{2C} = \frac{1}{2}CU^2 = \frac{1}{2}QU$$

:::tip 电容器机械做功与能量转换黄金法则（断电恒 $Q$ vs 接电源恒 $U$）
| 物理操作与约束条件 | 推荐能量公式 | 电容 $C$ 变化 | 静电能变化 $\Delta W_e$ | 电源做功 $A_{\mathrm{batt}}$ | 外力机械功 $A_{\mathrm{ext}}$（或静电力功 $A_{\mathrm{elec}} = -A_{\mathrm{ext}}$） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **断电恒 $Q$** 拉开极板（$d_1 \to d_2$） | $W_e = \dfrac{Q^2}{2C}$ | $C$ 减小 | $\Delta W_e = \dfrac{Q^2}{2\varepsilon_0 S}(d_2 - d_1) > 0$ | $0$ | $A_{\mathrm{ext}} = \Delta W_e > 0$（两板相互吸引，大小 $F = \dfrac{Q^2}{2\varepsilon_0 S} = \dfrac{1}{2}\sigma E_0 S$） |
| **断电恒 $Q$** 插入电介质（$C_0 \to \varepsilon_{\mathrm{r}}C_0$） | $W_e = \dfrac{Q^2}{2C}$ | $C$ 增大为 $\varepsilon_{\mathrm{r}}C_0$ | $\Delta W_e = \left(\dfrac{1}{\varepsilon_{\mathrm{r}}} - 1\right)W_{e0} < 0$ | $0$ | 电场力对介质做正功 $A_{\mathrm{elec}} = -\Delta W_e > 0$（**电介质被边缘场吸入板间**） |

### 三、静电场的能量密度与非匀强场总能量积分（PDF p230–236）

电容器储存的能量究竟定域在极板电荷上，还是定域在极板间的**电场空间**中？将平行板电容器的 $C = \dfrac{\varepsilon S}{d}$ 与 $U = Ed$ 代入 $W_e = \dfrac{1}{2}CU^2$（其中板间电场体积为 $V = Sd$）：
$$W_e = \frac{1}{2}\left(\frac{\varepsilon S}{d}\right)(Ed)^2 = \left(\frac{1}{2}\varepsilon E^2\right)(Sd) = \frac{1}{2}\varepsilon E^2 V$$
由此得出现代场论的核心图像：**静电场的能量定域在存在电场的一切空间中**，单位体积内储存的静电场能量——**静电场能量密度** $w_e$（国际单位为 $\mathrm{J\cdot m^{-3}}$）为：
$$w_e = \frac{\mathrm{d}W_e}{\mathrm{d}V} = \frac{1}{2}\varepsilon E^2 = \frac{1}{2}\varepsilon_0\varepsilon_{\mathrm{r}}E^2 = \frac{D^2}{2\varepsilon} = \frac{1}{2}\vec{E}\cdot\vec{D}$$
对于任意非匀强静电场，只需求出空间各区域的 $E(\vec{r})$ 与 $\varepsilon(\vec{r})$，再对**所有存在电场的空间体积 $V$** 积分，即可求得系统的总静电能：
$$W_e = \iiint_V w_e\,\mathrm{d}V = \iiint_V \frac{1}{2}\vec{E}\cdot\vec{D}\,\mathrm{d}V = \iiint_V \frac{1}{2}\varepsilon_0\varepsilon_{\mathrm{r}}E^2\,\mathrm{d}V$$
