# 第 13 章：磁场中的磁介质

本章探讨实物物质（**磁介质，Magnetic Media**）在磁场中的响应规律（对应课件第 11～12 讲，PDF p366–404）。与第 10 章静电场中的电介质相平行，本章的核心脉络是：从电子轨道磁矩与自旋磁矩出发，阐明**顺磁质、抗磁质与铁磁质**的微观机制；引入宏观**磁化强度矢量 $\vec{M}$** 与表面**磁化（束缚）电流 $\vec{j}_m = \vec{M}\times\hat{n}_e$**；进而构造辅助物理量**磁场强度 $\vec{H} = \vec{B}/\mu_0 - \vec{M}$**，建立只包含自由（传导）电流 $I_0$ 的**有磁介质安培环路定理**，并深入分析铁磁质的**非线性起始磁化曲线、磁滞回线与磁畴机制**。

## §13.1 顺磁质与抗磁质的微观磁化机制 {#s13-1}

### 1. 磁介质的实验分类与相对磁导率 $\mu_r$（PDF p367–368）
当磁介质放入外磁场 $\vec{B}_0$（由传导电流 $I_0$ 单独产生）中时，介质被**磁化（Magnetization）**并产生附加磁场 $\vec{B}'$，空间任一点的总磁感应强度为：

$$\vec{B} = \vec{B}_0 + \vec{B}'$$

对于均匀充满磁场空间的各向同性磁介质，定义总磁感应强度 $B$ 与真空场 $B_0$ 的比值为**相对磁导率 $\mu_r$**（即 $B = \mu_r B_0$），按 $\mu_r$ 的特征可将磁介质分为三大类：

| 磁介质类别 | 相对磁导率 $\mu_r$ 特征 | 附加场 $\vec{B}'$ 与外场 $\vec{B}_0$ 关系 | 典型代表物质（PDF p368） |
| :--- | :--- | :--- | :--- |
| **顺磁质（Paramagnet）** | $\mu_r > 1$（$\mu_r - 1 \sim 10^{-5}\text{–}10^{-3}$） | $\vec{B}'$ 与 $\vec{B}_0$ **同向**（弱增强，$B > B_0$） | 锰、铬、铂、铝、液氧 $\mathrm{O}_2$、氮氧化物 |
| **抗磁质（Diamagnet）** | $\mu_r < 1$（$1 - \mu_r \sim 10^{-9}\text{–}10^{-5}$） | $\vec{B}'$ 与 $\vec{B}_0$ **反向**（微弱减弱，$B < B_0$） | 铋、铜、银、金、水 $\mathrm{H}_2\mathrm{O}$、惰性气体、绝大多数有机物 |
| **铁磁质（Ferromagnet）** | $\mu_r \gg 1$（可达 $10^2\text{–}10^5$，且为 $H$ 的非线性函数） | $\vec{B}'$ 与 $\vec{B}_0$ **同向且极强**（$B \gg B_0$） | 铁（Fe）、钴（Co）、镍（Ni）及其合金、铁氧体 |

*(注：第一类超导体在临界温度以下处于迈斯纳态时具有 $\mu_r = 0$、$\vec{B}' = -\vec{B}_0$、体内总磁场 $\vec{B}=\vec{0}$，称为**完全抗磁体**。)*

### 2. 原子中电子的轨道磁矩、自旋磁矩与分子固有磁矩（PDF p369–371）
物质的宏观磁性源于原子内部电子的**轨道运动**与**自旋运动**（原子核质量比电子大三千倍以上，核磁矩远小于电子磁矩，可忽略）：
1. **电子轨道磁矩 $\vec{\mu}_L$**：设电子（电量 $-e$、质量 $m_e$）以速率 $v$ 沿半径为 $r$ 的圆轨道运动，等效环形电流为 $I = \dfrac{e}{T} = \dfrac{ev}{2\pi r}$。其轨道磁矩大小为 $\mu_L = I S = \dfrac{ev}{2\pi r}\cdot\pi r^2 = \dfrac{1}{2}evr$。由于电子带负电，电流方向与电子运动方向相反，故轨道磁矩矢量 $\vec{\mu}_L$ 与电子轨道角动量 $\vec{L} = \vec{r}\times m_e\vec{v}$ **方向严格相反**：
   $$\vec{\mu}_L = -\frac{e}{2m_e}\vec{L}$$
2. **电子自旋磁矩 $\vec{\mu}_S$**：量子力学表明电子具有内禀自旋角动量 $\vec{S}$，其自旋磁矩与自旋角动量的旋磁比约为轨道运动的两倍：
   $$\vec{\mu}_S = -\frac{e}{m_e}\vec{S}$$
3. **分子固有磁矩 $\vec{p}_m$（等效分子电流）**：原子或分子中全部电子的轨道磁矩与自旋磁矩的矢量和定义为**分子固有磁矩**（安培分子电流假说将其等效为一个微型圆电流 $I_{\mathrm{mol}}$）：
   $$\vec{p}_m = \sum_i \left(\vec{\mu}_{Li} + \vec{\mu}_{Si}\right)$$

### 3. 拉莫尔进动与顺磁/抗磁的微观解释（PDF p371–373）
当原子置于外磁场 $\vec{B}_0$ 中时，电子轨道磁矩受到磁力矩 $\vec{\tau} = \vec{\mu}_L\times\vec{B}_0$ 的作用。由于 $\mathrm{d}\vec{L}/\mathrm{d}t = \vec{\tau}$ 垂直于 $\vec{L}$ 和 $\vec{B}_0$，电子轨道角动量 $\vec{L}$ 绕外磁场 $\vec{B}_0$ 轴线发生**拉莫尔进动（Larmor Precession）**。无论原轨道磁矩 $\vec{\mu}_L$ 与 $\vec{B}_0$ 夹角是锐角还是钝角（见下图 F13-02），进动角速度方向总是与 $\vec{B}_0$ 成右手螺旋关系；由于电子带负电，进动对应的附加环形电流 $\Delta I_m$ 总是与 $\vec{B}_0$ 成左手螺旋关系，从而产生**方向恒与外磁场 $\vec{B}_0$ 相反的附加（抗）磁矩 $\Delta\vec{p}_m$**！

{{fig:F13-02}}

由此可清晰解释顺磁质与抗磁质的微观区别（PDF p372–373）：
- **顺磁质（$\vec{p}_m \ne \vec{0}$，取向磁化占主导）**：分子自身具有非零固有磁矩 $\vec{p}_m \ne \vec{0}$。无外磁场时因热运动取向杂乱，$\sum\vec{p}_m = \vec{0}$，不显宏观磁性；施加外磁场 $\vec{B}_0$ 后，各分子固有磁矩受磁力矩作用倾向于转向 $\vec{B}_0$ 方向，且这种同向取向磁化效应远强于微弱的反向拉莫尔附加磁矩（$\lvert\sum\vec{p}_m\rvert \gg \lvert\sum\Delta\vec{p}_m\rvert$），故产生与 $\vec{B}_0$ 同向的附加场 $\vec{B}'$。
- **抗磁质（$\vec{p}_m = \vec{0}$，拉莫尔附加磁矩单独显现）**：分子内各电子的轨道与自旋磁矩完全配对抵消，固有磁矩 $\vec{p}_m = \vec{0}$。施加外磁场 $\vec{B}_0$ 后，唯有拉莫尔进动诱导出的反向附加磁矩 $\Delta\vec{p}_m$ 起作用，故产生与 $\vec{B}_0$ 反向的微弱附加场 $\vec{B}'$。

## §13.2 磁化强度矢量与磁化面电流 {#s13-2}

### 1. 磁化强度矢量 $\vec{M}$ 的定义（PDF p374）
为了从宏观上定量刻画磁介质在某一点处的磁化程度与磁化方向，定义**单位体积内全部分子磁矩（包含分子固有磁矩 $\vec{p}_{mi}$ 与附加磁矩 $\Delta\vec{p}_{mi}$）的矢量和**为**磁化强度矢量 $\vec{M}$**：

$$\vec{M} = \frac{\sum_i \vec{P}_{mi}}{\Delta V} = \frac{\sum_i \vec{p}_{mi} + \sum_i \Delta\vec{p}_{mi}}{\Delta V}$$

- **单位**：安培每米（$\mathrm{A/m}$，因为磁矩除以体积的量纲为 $(\mathrm{A\cdot m^2})/\mathrm{m^3} = \mathrm{A/m}$）。
- **物理方向**：在顺磁质中 $\vec{M}$ 与外场 $\vec{B}_0$ 同向；在抗磁质中 $\vec{M}$ 与 $\vec{B}_0$ 反向；在真空中 $\vec{M} = \vec{0}$。若介质内各点 $\vec{M}$ 的大小和方向处处相同，称为**均匀磁化**。

### 2. 磁化电流（束缚电流）与面电流线密度 $\vec{j}_m$（PDF p375–377）
当均匀磁介质（如通电螺线管内的圆柱介质，图 F13-04）被均匀磁化时，各个分子电流的环绕方向趋于一致：在介质**内部**任意相邻两个分子电流交界处，两侧电流方向相反、大小相等，宏观上相互抵消；但在磁介质的**外侧表面**上，各分子电流的外侧边缘同向串联而无人抵消，从而在介质表面形成宏观等效的环形**磁化面电流（亦称束缚电流 $I_m$）**。

{{fig:F13-04}}

:::derive 推导：磁化强度 $\vec{M}$ 与磁化面电流线密度 $\vec{j}_m$ 及环流的关系（PDF p376–378）
1. **轴向均匀磁化圆柱侧面的 $j_m = M$**：在圆柱磁介质上截取底面积为 $S$、轴向长度为 $\mathrm{d}l$ 的薄圆柱段（体积 $\Delta V = S\,\mathrm{d}l$）。设该段侧面环绕的磁化电流为 $\mathrm{d}I_m$，则该段的总磁矩大小为 $\lvert\sum\vec{P}_{mi}\rvert = \mathrm{d}I_m\cdot S$。代入磁化强度定义式：
   $$M = \frac{\lvert\sum\vec{P}_{mi}\rvert}{S\,\mathrm{d}l} = \frac{\mathrm{d}I_m S}{S\,\mathrm{d}l} = \frac{\mathrm{d}I_m}{\mathrm{d}l} = j_m$$
   其中 $j_m = \mathrm{d}I_m/\mathrm{d}l$ 即为沿 $\vec{M}$ 方向**单位长度上的磁化面电流（线密度）**。
2. **一般表面方向公式 $\vec{j}_m = \vec{M}\times\hat{n}_e$**：设磁介质表面的**外法线单位矢量**为 $\hat{n}_e$，$\vec{M}$ 与 $\hat{n}_e$ 的夹角为 $\theta$，则磁化面电流线密度矢量为：
   $$\vec{j}_m = \vec{M}\times\hat{n}_e, \qquad j_m = M\sin\theta$$
   在轴向磁化圆柱的**两个端面**上，$\hat{n}_e$ 与 $\vec{M}$ 平行或反平行（$\sin\theta = 0$），故端面上 $\vec{j}_m = \vec{0}$；在**圆柱侧面**上，$\hat{n}_e \perp \vec{M}$（$\sin\theta = 1$），故 $j_m = M$。
3. **磁化强度 $\vec{M}$ 的环流定理**：沿跨过圆柱侧面的矩形闭合回路 $ABCD$（图 F13-05，其中 $AB$ 在介质内长 $\overline{AB}$、$CD$ 在真空外 $\vec{M}=\vec{0}$、$BC$ 和 $DA$ 垂直于 $\vec{M}$）求线积分：
   $$\oint_L \vec{M}\cdot\mathrm{d}\vec{l} = \int_A^B \vec{M}\cdot\mathrm{d}\vec{l} = M\cdot\overline{AB} = j_m\cdot\overline{AB} = \sum_{L\mathrm{in}} I_m$$
   此结论可推广至任意非均匀磁化介质：**磁化强度 $\vec{M}$ 沿任意闭合回路 $L$ 的线积分（环流），等于穿过该回路所围曲面的总磁化电流的代数和**（正负号服从右手螺旋法则）。

## §13.3 磁场强度 H 与有磁介质的安培环路定理 {#s13-3}

### 1. 存在磁介质时的磁场高斯定理（PDF p379）
当空间同时存在传导电流 $I_0$（导体中的自由电流）和磁介质的磁化电流 $I_m$ 时，无论 $I_0$ 产生的真空场 $\vec{B}_0$ 还是闭环分子磁化电流 $I_m$ 产生的附加场 $\vec{B}'$，它们的磁感应线都是**无头无尾的闭合曲线**。因此，总磁感应强度 $\vec{B} = \vec{B}_0 + \vec{B}'$ 穿过任意闭合曲面 $S$ 的磁通量依然恒等于零：

$$\oiint_S \vec{B}\cdot\mathrm{d}\vec{S} = \oiint_S (\vec{B}_0 + \vec{B}')\cdot\mathrm{d}\vec{S} = 0$$

### 2. 磁场强度 $\vec{H}$ 的引入与有磁介质的安培环路定理（PDF p380–383）
在稳恒电流条件下，总磁场 $\vec{B}$ 由传导电流 $I_0$ 与磁化电流 $I_m$ 共同激发。由真空中的安培环路定理，将两类电流一并计入回路右侧：

$$\oint_L \vec{B}\cdot\mathrm{d}\vec{l} = \mu_0\left(\sum_{L\mathrm{in}} I_0 + \sum_{L\mathrm{in}} I_m\right)$$

由于磁化电流 $\sum I_m$ 本身依赖于待求的磁场，上式无法直接求解 $\vec{B}$。为此代入磁化强度环流关系 $\sum_{L\mathrm{in}} I_m = \oint_L \vec{M}\cdot\mathrm{d}\vec{l}$，将含有 $\vec{M}$ 的环流移至等号左端：

$$\oint_L \left(\frac{\vec{B}}{\mu_0} - \vec{M}\right)\cdot\mathrm{d}\vec{l} = \sum_{L\mathrm{in}} I_0$$

定义括号内的辅助矢量场为**磁场强度（Magnetic Field Intensity）$\vec{H}$**：

$$\vec{H} = \frac{\vec{B}}{\mu_0} - \vec{M} \quad \Longleftrightarrow \quad \vec{B} = \mu_0(\vec{H} + \vec{M})$$

从而得到稳恒磁场下普遍成立的**有磁介质时的安培环路定理**：

$$\oint_L \vec{H}\cdot\mathrm{d}\vec{l} = \sum_{L\mathrm{in}} I_0$$

即：**磁场强度 $\vec{H}$ 沿任意闭合路径 $L$ 的环流，等于穿过该闭合路径所围曲面的传导（自由）电流的代数和（不包含磁化电流 $I_m$）**。$\vec{H}$ 的 SI 单位与 $\vec{M}$ 相同，均为安培每米（$\mathrm{A/m}$）。

### 3. 线性各向同性磁介质中的本构关系（PDF p382–383）
在**线性、各向同性**的磁介质（顺磁质和抗磁质）中，磁化强度 $\vec{M}$ 与磁场强度 $\vec{H}$ 成正比：

$$\vec{M} = \chi_m\vec{H}$$

其中无量纲比例系数 $\chi_m$ 称为介质的**磁化率（Magnetic Susceptibility）**：
- **顺磁质**：$\chi_m > 0$，$\vec{M}$ 与 $\vec{H}$ 同向；
- **抗磁质**：$\chi_m < 0$（但 $\lvert\chi_m\rvert \ll 1$），$\vec{M}$ 与 $\vec{H}$ 反向；
- **真空**：$\chi_m = 0$。

将 $\vec{M} = \chi_m\vec{H}$ 代入 $\vec{B} = \mu_0(\vec{H} + \vec{M})$，并令**相对磁导率** $\mu_r = 1 + \chi_m$、**绝对磁导率** $\mu = \mu_0\mu_r$（单位 $\mathrm{H/m}$ 或 $\mathrm{T\cdot m/A}$），得到线性磁介质的核心本构关系：

$$\vec{B} = \mu_0(1 + \chi_m)\vec{H} = \mu_0\mu_r\vec{H} = \mu\vec{H}$$

:::example 例13.1 & 例13.2：有磁介质安培环路定理的标准四步求解法（PDF p384–392）
在具有对称性的磁介质问题中，标准解题四步法为：
1. **第一步（由对称性与 $I_0$ 求 $H$）**：选对称闭合路径 $L$ 应用 $\oint_L \vec{H}\cdot\mathrm{d}\vec{l} = \sum I_0$。
   - 对充满介质的长直螺线管（例13.1，图 F13-06）：$H\Delta l = n\Delta l\,I \implies H = nI$；
   - 对无限长载流圆柱外包介质（例13.2，图 F13-07）：$H\cdot 2\pi r = I \implies H(r) = \dfrac{I}{2\pi r}$。
2. **第二步（由本构关系求总磁场 $B$）**：$B = \mu_0\mu_r H$（例13.1 得 $B = \mu_0\mu_r nI$；例13.2 得 $B(r) = \dfrac{\mu_0\mu_r I}{2\pi r}$）。
3. **第三步（求磁化强度 $M$ 与附加场 $B'$）**：$M = (\mu_r - 1)H$，磁化电流产生的附加场为 $B' = \mu_0 M = \mu_0(\mu_r - 1)H = B - B_0$。
4. **第四步（求界面磁化面电流线密度 $\vec{j}_m$）**：由 $\vec{j}_m = \vec{M}\times\hat{n}_e$，在例13.1 螺线管外侧面上 $j_m = M = (\mu_r - 1)nI$（与线圈电流同向环绕）；在例13.2 圆柱界面 $r=R$ 处，因外侧磁介质的外法线 $\hat{n}_e$ 指向轴线，故 $j_m = M(R) = (\mu_r - 1)\dfrac{I}{2\pi R}$，方向沿轴线与传导电流 $I$ 同向！
:::

## §13.4 铁磁质的磁化特性、磁滞回线、磁畴与磁屏蔽 {#s13-4}

### 1. 铁磁质的四大宏观特征（PDF p394）
铁、钴、镍及其合金和铁氧体属于**铁磁质（Ferromagnetic Materials）**，具有显著区别于顺磁质的四大宏观特性：
1. **高磁导率与强磁化**：在居里温度 $T_C$ 以下具有自发磁化，外场作用下能产生极强的磁化强度，相对磁导率 $\mu_r$ 高达 $10^2\sim 10^5$；
2. **高度非线性与历史依赖**：$B\text{–}H$ 关系为非线性曲线，磁导率 $\mu = B/H$ 不是常数，且 $B$ 依赖于此前的磁化历史；
3. **磁滞与剩磁**：撤去外磁场（$H = 0$）后，样品仍能保留相当强的剩余磁化强度；
4. **存在居里温度 $T_C$**：当温度高于临界温度 $T_C$（铁 $T_C \approx 1040\,\mathrm{K}$，钴 $T_C \approx 1388\,\mathrm{K}$，镍 $T_C \approx 631\,\mathrm{K}$）时，铁磁性完全消失，材料相变为普通**顺磁质**。

### 2. 罗兰环实验、起始磁化曲线与磁饱和（PDF p395–396）
利用密绕环形铁芯（罗兰环，图 F13-08 右），调节励磁电流 $I$ 改变磁场强度 $H = \dfrac{NI}{2\pi r}$，并用磁通计测量铁芯内 $B$ 的变化。从完全退磁状态（$H=0, B=0$ 的原点 $O$）出发缓慢增大 $H$，得到的 $B(H)$ 曲线称为**起始磁化曲线**：
- **$OA$ 段（起始可逆区）**：$H$ 很小时，$B$ 随 $H$ 缓慢增加；
- **$AD$ 段（陡峭不可逆区）**：$B$ 随 $H$ 急剧上升，微分磁导率 $\mathrm{d}B/\mathrm{d}H$ 达到极大；
- **趋近饱和段（$H \ge H_s$）**：强场下磁化强度 $M$ 趋近于恒定的**饱和磁化强度 $M_s$**。此后继续增大 $H$，$M \approx M_s$ 不再增加，但总磁感应强度 $B = \mu_0(H + M_s)$ 仍以真空斜率 $\mathrm{d}B/\mathrm{d}H \approx \mu_0$ 极其缓慢地线性上升！

### 3. 磁滞回线、剩磁 $B_r$、矫顽力 $H_c$ 与磁滞损耗（PDF p397–400）
当铁磁质磁化至正向饱和状态 $S$（$H_s, B_s$）后，若将磁场强度 $H$ 减小，磁感应强度 $B$ 并不沿起始磁化曲线原路返回，而是高于原曲线（即 $B$ 的变化滞后于 $H$ 的变化，称为**磁滞现象**）：
1. **剩余磁感应强度（剩磁 $B_r$）**：当外加磁场减小到 $H = 0$ 时，铁芯中保留的磁感应强度值 $B = B_r$（图 F13-09 中的 $b$ 点）。
2. **矫顽力（Coercivity $H_c$）**：要消除剩磁使 $B$ 降为零，必须施加反向磁场 $H = -H_c$（图中 $c$ 点），反向场强的大小 $H_c$ 表征材料保持磁化状态、抵抗退磁的能力。
3. **磁滞回线与磁滞损耗 $w_h$**：当 $H$ 在 $+H_s$ 与 $-H_s$ 之间周期性往复变化时，$B\text{–}H$ 轨迹形成闭合的对称回线——**磁滞回线（Hysteresis Loop）**。在准静态反复磁化循环中，单位体积铁磁质每经历一个周期所消耗并转化为热能的能量（**磁滞损耗密度**，单位 $\mathrm{J/m^3}$）等于 $B\text{–}H$ 磁滞回线所包围的面积：

$$w_h = \left\lvert \oint H\,\mathrm{d}B \right\rvert$$

### 4. 铁磁质的微观结构：自发磁化磁畴（Magnetic Domains，PDF p402–403）
量子力学表明，铁磁材料中相邻原子的未配对电子自旋磁矩之间存在强烈的量子**交换耦合作用（Exchange Coupling）**，使它们在无外磁场时即自发地平行排列，形成一个个自发磁化达到饱和的微米级小区域——**磁畴（Magnetic Domains）**（图 F13-10）。
- **退磁态**：各磁畴的磁化方向彼此不同，宏观矢量和相互抵消，整体不显磁性；
- **外场磁化过程**：随外加磁场 $H$ 增强，首先是与外场方向夹角较小的有利磁畴通过**畴壁移动（Domain Wall Motion）**吞并周围磁畴而扩大；随后在强场下各磁畴的磁矩整体**转向外场方向（Domain Rotation）**，直至整块样品合一为单畴饱和态；
- **磁滞与发热的微观起源**：晶体中的杂质、位错等晶格缺陷会对畴壁移动产生『钉扎阻碍』，且磁矩转动需克服磁晶各向异性能垒（类似摩擦不可逆过程），撤去外场后畴壁无法完全退回原位（产生剩磁与磁滞），克服摩擦所做的功即转化为晶格热能（磁滞损耗）。
