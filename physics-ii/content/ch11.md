# 第 11 章：稳恒电流

本章从静电场过渡到电荷定向运动形成的**稳恒电流场（Steady Current Field）**（对应课件第 7～8 讲，PDF p239–271）。核心主线是：从宏观标量**电流强度 $I$** 深入到微观矢量**电流密度 $\vec{j}$**，利用电荷守恒定律建立**电流连续性方程**，导出**欧姆定律与焦耳定律的微分形式**；进而引入**非静电力与电源电动势 $\mathcal{E}$**，掌握复杂直流网络的**基尔霍夫定律（KCL/KVL）**、**惠斯通电桥（平衡测量与电子秤非平衡测量）**以及 **RC 充放电暂态响应**。

## §11.1 电流强度、电流密度矢量与连续性方程 {#s11-1}

### 1. 导电机制与电流强度 $I$（PDF p240–241）
导体内存在大量可自由移动的**载流子（Charge Carriers）**（金属中为自由电子，电解液中为正负离子，半导体中为电子与空穴）。无外电场时，载流子仅做剧烈的无规则热运动（速率约 $10^5\,\mathrm{m/s}$），宏观净电流为零；施加电场后，载流子在热运动基础上叠加缓慢的**定向漂移运动**（金属中电子漂移速率 $v_d$ 仅约 $10^{-4}\sim 10^{-3}\,\mathrm{m/s}$），形成宏观电流。

单位时间内通过导体任一横截面的电荷量定义为**电流强度**（简称电流）：

$$I = \frac{\mathrm{d}q}{\mathrm{d}t}$$

- **方向规定**：规定正电荷定向移动的方向（或负电荷定向移动的反方向）为电流正方向。
- **物理属性**：电流强度 $I$ 是具有方向规定的**代数标量**，不服从矢量平行四边形法则，SI 单位为安培（$\mathrm{A} = \mathrm{C/s}$）。由于不同粗细的串联导体流过相同的总电流 $I$，单凭标量 $I$ 无法刻画导体内部各点载流子流动的空间分布。

### 2. 电流密度矢量 $\vec{j}$ 与电流通量（PDF p242–243）
为精细描述导体内各点的电流分布，定义**电流密度矢量 $\vec{j}$**：其方向取该点正电荷定向移动方向（单位矢量 $\hat{n}_e$），大小等于垂直穿过单位面积的电流强度：

$$\vec{j} = \frac{\mathrm{d}I}{\mathrm{d}S_\perp}\hat{n}_e$$

若导体单位体积内的载流子数（数密度）为 $n$，每个载流子带电量为 $q$，平均定向漂移速度为 $\vec{v}_d$，则在 $\mathrm{d}t$ 时间内穿过垂直微元面积 $\mathrm{d}S_\perp$ 的载流子位于长度为 $v_d\,\mathrm{d}t$ 的斜柱体内，电荷量 $\mathrm{d}q = n q v_d\,\mathrm{d}t\,\mathrm{d}S_\perp$，从而得到电流密度的微观表达式：

$$\vec{j} = n q \vec{v}_d$$

对于导体内任意取向的有向曲面 $S$（面元矢量 $\mathrm{d}\vec{S} = \hat{n}\,\mathrm{d}S$，与 $\vec{j}$ 夹角为 $\theta$），通过面元 $\mathrm{d}S$ 的微元电流为 $\mathrm{d}I = j\,\mathrm{d}S\cos\theta = \vec{j}\cdot\mathrm{d}\vec{S}$。因此，通过有限曲面 $S$ 的总电流强度等于**电流密度矢量 $\vec{j}$ 穿过曲面 $S$ 的通量**：

$$I = \iint_S \vec{j}\cdot\mathrm{d}\vec{S} = \iint_S j\cos\theta\,\mathrm{d}S$$

{{fig:F11-01}}

### 3. 电流连续性方程与稳恒条件（PDF p244–245）
在导体内任取一闭合曲面 $S$（约定外法线方向为 $\mathrm{d}\vec{S}$ 正方向），设 $S$ 包围体积内的净电荷量为 $q_{\mathrm{in}}$。在 $\mathrm{d}t$ 时间内从闭合曲面 $S$ 净流出的电荷量为 $\mathrm{d}q_{\mathrm{out}} = I_{\mathrm{out}}\,\mathrm{d}t = \left(\oiint_S \vec{j}\cdot\mathrm{d}\vec{S}\right)\mathrm{d}t$。由**电荷守恒定律**，净流出的电荷量必等于内部净电荷量的减少量 $-\mathrm{d}q_{\mathrm{in}}$，由此得到普遍成立的**电流连续性方程**：

$$\oiint_S \vec{j}\cdot\mathrm{d}\vec{S} = -\frac{\mathrm{d}q_{\mathrm{in}}}{\mathrm{d}t}$$

{{fig:F11-02}}

- **稳恒电流（Steady Current）**：若导体内各处的电流密度矢量 $\vec{j}$ 和电荷分布均不随时间改变（$\mathrm{d}q_{\mathrm{in}}/\mathrm{d}t = 0$），则通过任意闭合曲面的电流密度通量恒为零：

$$\oiint_S \vec{j}\cdot\mathrm{d}\vec{S} = 0$$

:::note 稳恒电流场与静电场的本质区别與联系
1. **闭合性**：稳恒电流的 $\vec{j}$ 线是无头无尾的闭合曲线（任意闭合曲面流入电流等于流出电流），故稳恒导电导体内各处不会发生随时间累积的电荷变化。
2. **稳恒电场**：维持稳恒电流的电场称为**稳恒电场**。由于电荷分布不随时间变化，稳恒电场同静电场一样具有保守性（$\oint_L \vec{E}\cdot\mathrm{d}\vec{l} = 0$），依然可以引入电势 $V$ 与电势差 $U_{ab} = V_a - V_b$；但此时导体内部**不是等势体**，内部电场 $\vec{E} = \vec{j}/\gamma \ne \vec{0}$！
:::

## §11.2 欧姆定律的积分与微分形式、焦耳定律 {#s11-2}

### 1. 宏观电阻定律与欧姆定律积分形式
对一段不含电源的均匀线性导体，流过的电流 $I$ 与两端电势差 $U$ 成正比，即 $I = U/R$；长度为 $l$、横截面积为 $S$ 的均匀柱体电阻为：

$$R = \rho\frac{l}{S} = \frac{l}{\gamma S}$$

其中 $\rho$ 为材料的**电阻率**（单位 $\Omega\cdot\mathrm{m}$），其倒数 $\gamma = 1/\rho$ 为**电导率**（单位 $\mathrm{S/m} = \Omega^{-1}\cdot\mathrm{m}^{-1}$）。

### 2. 欧姆定律的微分形式（PDF p246）
宏观公式 $I = U/R$ 只描述整段导体的整体关系。为了刻画非均匀导体内每一点的导电规律，在导体内某点沿电场 $\vec{E}$（亦即 $\vec{j}$）方向取截面积为 $\mathrm{d}S$、长度为 $\mathrm{d}l$ 的微元柱体 $\mathrm{d}V$。微元两端电势差为 $\mathrm{d}U = E\,\mathrm{d}l$，微元电阻为 $\mathrm{d}R = \rho\,\mathrm{d}l/\mathrm{d}S$，通过微元的电流为 $\mathrm{d}I = j\,\mathrm{d}S$。代入欧姆定律：

$$\mathrm{d}I = \frac{\mathrm{d}U}{\mathrm{d}R} \implies j\,\mathrm{d}S = \frac{E\,\mathrm{d}l}{\rho\,\mathrm{d}l/\mathrm{d}S} = \frac{E}{\rho}\,\mathrm{d}S = \gamma E\,\mathrm{d}S$$

消去 $\mathrm{d}S$ 并顾及 $\vec{j}$ 与 $\vec{E}$ 同向，即得**欧姆定律的微分形式**：

$$\vec{j} = \gamma\vec{E} = \frac{1}{\rho}\vec{E}$$

{{fig:F11-03}}

### 3. 焦耳定律的积分与微分形式
电流通过纯电阻导体时，静电力对载流子做正功，载流子在定向加速过程中不断与晶格原子（离子实）碰撞，将获得的定向动能转化为晶格热振动内能（焦耳热）。在时间 $t$ 内整段电阻 $R$ 的发热功率与发热功率密度（单位体积热功率 $p_J = \mathrm{d}P/\mathrm{d}V$）分别为：

$$P = I U = I^2 R = \frac{U^2}{R}, \qquad p_J = \frac{\mathrm{d}P}{\mathrm{d}S\,\mathrm{d}l} = \frac{(j\,\mathrm{d}S)(E\,\mathrm{d}l)}{\mathrm{d}S\,\mathrm{d}l} = \vec{j}\cdot\vec{E} = \gamma E^2 = \rho j^2$$

:::warn 串联变截面导体的局部过热效应
在粗细不均匀的同种金属导线串联电路中（见 PDF p241 图），各截面总电流 $I$ 处处相同，因此在截面积 $S$ 极小的狭窄瓶颈处，电流密度 $j = I/S$ 与内部场强 $E = \rho I/S$ 均反比于 $S$ 增大，而**单位体积发热功率密度 $p_J = \rho j^2 = \rho I^2 / S^2$ 反比于截面积的平方 $S^2$ 急剧升高**！这正是电路接触不良处（接触面积极小）或保险丝细颈处极易局部高温熔断的物理原因。
:::

## §11.3 电源、非静电力与闭合/含源电路欧姆定律 {#s11-3}

### 1. 为什么稳恒电流必须有非静电力？（PDF p247–248）
静电场（稳恒电场）是保守场，其环流恒为零：$\oint_L \vec{E}\cdot\mathrm{d}\vec{l} = 0$。若闭合电路中只有静电力，正电荷在外电路由高电势正极流向低电势负极后，在电源内部静电场 $\vec{E}$ 同样由正极指向负极，静电力绝不可能把正电荷从低电势负极逆着电场推回高电势正极，极板电荷瞬间中和后电流即归零。

因此，要维持稳恒电流，电路中必须包含能够提供**非静电力 $\vec{F}_k$** 的装置——**电源（Source of EMF）**（如化学电池中的化学扩散作用、发电机中的洛伦兹动生作用、光电池中的光伏效应等）。定义单位正电荷所受的非静电力为**非静电场强 $\vec{E}_k$**：

$$\vec{E}_k = \frac{\vec{F}_k}{q}$$

{{fig:F11-04}}

### 2. 电源电动势 $\mathcal{E}$ 的严格定义（PDF p248–250）
将单位正电荷从电源负极 $(-)$ **经电源内部路径**移送到正极 $(+)$ 的过程中，非静电力所做的功定义为**电源的电动势 $\mathcal{E}$**：

$$\mathcal{E} = \frac{A_k}{q} = \int_{(-)}^{(+)} \vec{E}_k\cdot\mathrm{d}\vec{l}$$

由于非静电力仅存在于电源内部（外电路中 $\vec{E}_k = \vec{0}$），而静电场沿整个闭合回路的环流 $\oint \vec{E}\cdot\mathrm{d}\vec{l} = 0$，电动势也可等价地写成非静电场强（或总场强 $\vec{E} + \vec{E}_k$）沿整个闭合回路的环流：

$$\mathcal{E} = \oint_L \vec{E}_k\cdot\mathrm{d}\vec{l} = \oint_L (\vec{E} + \vec{E}_k)\cdot\mathrm{d}\vec{l}$$

- **电动势的方向**：规定在电源内部由负极 $(-)$ 指向正极 $(+)$（即电源内部电势升高的方向）为电动势正方向。
- **电动势与电势差的区别**：电动势 $\mathcal{E}$ 描述非静电力把其他形式能量转化为电能的本领，由电源本身性质决定；电势差 $U_{ab} = \int_a^b \vec{E}\cdot\mathrm{d}\vec{l}$ 描述静电力做功本领，与外电路负载状态有关。

### 3. 闭合电路与一段含源电路的欧姆定律（PDF p251–252）
设电源电动势为 $\mathcal{E}$、内阻为 $r$，外电路纯电阻为 $R$。在 $\mathrm{d}t$ 时间内流过電荷 $\mathrm{d}q = I\,\mathrm{d}t$，由能量守恒定律，非静电力做功 $\mathcal{E}\,\mathrm{d}q$ 等于内外电阻产生的总焦耳热 $I^2(R+r)\,\mathrm{d}t$，即得**全电路（闭合电路）欧姆定律**：

$$I = \frac{\mathcal{E}}{R + r}$$

对于**一段含源电路 $ab$**，电源端电压 $U = V_+ - V_-$ 取决于电流方向：
1. **电源放电**（电流 $I$ 从正极流出）：$U = \mathcal{E} - Ir = IR < \mathcal{E}$；
2. **电源开路**（断路 $I = 0$）：$U = \mathcal{E}$（开路端电压等于电动势）；
3. **电源短路**（外阻 $R = 0$）：$U = 0$，短路电流 $I_{\mathrm{sc}} = \mathcal{E}/r$（极大，易烧毁电源）；
4. **电源被充电**（外电路强迫电流 $I$ 从正极流入、负极流出，如课件 p258 例11.2 中的 $4\,\mathrm{V}$ 电池）：非静电力做负功（电能转化为化学能储存在电池中），此时端电压满足：

$$U = \mathcal{E} + Ir > \mathcal{E}$$

## §11.4 基尔霍夫第一、第二定律与多回路求解 {#s11-4}

对于包含多个电源或桥式交叉支路的复杂电路网络，无法仅靠串并联等效化简，必须使用**基尔霍夫电路定律（Kirchhoff's Circuit Laws）**求解（PDF p253–262）。

### 1. 电路拓扑术语与独立方程数（PDF p253）
- **支路（Branch）**：由一个或多个元件串联组成、流过同一电流的无分支导电路径（设总支路数为 $b$）。
- **节点（Node）**：**三条或三条以上**支路的交汇点（设总节点数为 $n$；注意仅两条元件相连的拐角如课件 p253 左图中的 $c, d$ 点**不是节点**）。
- **回路（Loop）**：电路中任一闭合的导电通道。

{{fig:F11-05}}

### 2. 基尔霍夫第一定律（节点电流方程 KCL，PDF p254–255）
在稳恒电流下，任何节点上都不会有净电荷的堆积或亏损。由电流连续性方程 $\oiint_S \vec{j}\cdot\mathrm{d}\vec{S} = 0$，**流入任意节点的电流代数和恒等于零**（或流入电流之和等于流出电流之和）：

$$\sum_{k} I_k = 0 \quad \Longleftrightarrow \quad \sum I_{\mathrm{in}} = \sum I_{\mathrm{out}}$$

- **独立方程个数**：对于具有 $n$ 个节点的连通电路，任意 $n-1$ 个节点的 KCL 方程相加即自动导出第 $n$ 个节点的方程，因此**独立 KCL 方程共有 $n - 1$ 个**。

### 3. 基尔霍夫第二定律（回路电压方程 KVL，PDF p256–257）
由于稳恒电场是保守场，沿任一闭合回路绕行一周，电势回升到出发点的原值，故**沿任意闭合回路绕行一周，所有元件上的电势变化量 $\Delta V_k$ 的代数和恒为零**：

$$\sum_{k} \Delta V_k = 0$$

{{fig:F11-06}}

:::tip 课件标准 KVL 符号约定（Travel 绕行升降法，PDF p257）
1. **先标各支路电流参考方向**：在图上为每条支路假定一个电流参考箭头 $I_k$（若解出 $I_k < 0$，说明实际方向与假定箭头相反）。
2. **再选闭合回路绕行方向（Travel）**：从某点出发绕回路一周：
   - **经过电源（电动势 $\mathcal{E}$）**：若绕行方向在电源内**由负极 $(-)$ 穿向正极 $(+)$**（电势升高），记 $+\mathcal{E}$；若**由正极 $(+)$ 穿向负极 $(-)$**（电势降低），记 $-\mathcal{E}$（与该支路电流方向无关！）。
   - **经过电阻 $R$**：若绕行方向与支路参考电流 $I$ **同向**（顺流电势降低），记 $-IR$；若与参考电流 $I$ **反向**（逆流电势升高），记 $+IR$。
3. **独立 KVL 方程个数**：共有 $b - (n - 1)$ 个（平面电路直接取全部最内层网孔即可保证线性独立）。
:::

## §11.5 惠斯通电桥平衡与非平衡分析 {#s11-5}

### 1. 平衡电桥（零示法测电阻，PDF p263 左）
在惠斯通电桥（图 F11-09 左）中，闭合开关 $K_1, K_2$，调节标准电阻使桥支路检流计 $G$ 中电流严格为零（$I_g = 0$），称为**电桥平衡**。此时：
1. 桥两端等电势（$V_b = V_c$），故上侧两臂压降相等：$I_N N = I_P P$；
2. 检流计不分流，故左、右同侧上下两臂电流分别相等：$I_N = I_M$，$I_P = I_X$，从而下侧两臂压降亦相等：$I_N M = I_P X$。

两式相除消去电流，即得**电桥平衡条件**（对角桥臂电阻乘积相等 $NX = MP$）：

$$X = \frac{M}{N}P$$

{{fig:F11-09}}

### 2. 非平衡电桥与电子秤应变传感器原理（PDF p263 右–265）
在现代电子测量（如数字电子秤、压力传感器）中，无需人工调平电桥，而是在桥端 $a,b$ 间直接接入**理想高输入阻抗电压表**（$R_V \to \infty$，桥支路电流为零），工作于**非平衡测量模式**。此时左支路（$N$ 与 $M$ 串联）和右支路（$P$ 与 $X$ 串联）各自独立对电源电动势 $\mathcal{E}$ 分压，故 $a,b$ 两点间的开路输出电压为：

$$V_{ab} = V_a - V_b = \mathcal{E}\left(\frac{M}{M + N} - \frac{X}{X + P}\right)$$

:::tip 为什么电子秤采用四臂全桥应变片结构？（PDF p264–265）
1. **差分倍增灵敏度**：无重物时 $M=N=P=X=R_0$，输出零点 $V_{ab} = 0$。放上重物后，弹性梁变形使左侧两个应变片（$M, N$ 之一或对角臂）受拉变长（$R = \rho L/A$ 增大 $+\Delta R$），右侧应变片受压变短（电阻减小 $-\Delta R$），从而使 $V_{ab}$ 线性正比于微小形变 $\Delta R/R_0$，经校准即可直接换算为重量读数。
2. **抑制环境温度漂移**：金属电阻率 $\rho(T)$ 随环境温度变化显著。若四个桥臂采用同材质应变片且处于同一温度场中，温度变化会使 $M, N, P, X$ 按相同比例系数同增同减，分式 $M/(M+N)$ 与 $X/(X+P)$ 完全不变，从而**自动消除环境温度变化引起的零点漂移**！
:::

## §11.6 RC 电路的充放电暂态过程 {#s11-6}

当电路中含有电容器 $C$ 与电阻 $R$ 时，开关切换瞬间极板电荷不能突变，电路经历从初始状态指数弛豫到新稳态的**暂态过程（Transient Process）**（PDF p266–270）。

### 1. RC 电容器充电过程（PDF p266–268）
设初始未充电（$t=0$ 时 $q(0)=0$）的电容器 $C$ 与电阻 $R$、直流电源 $\mathcal{E}$ 串联。闭合开关后，取充电方向为电流与绕行正方向，任意时刻 $t$ 极板电量为 $q(t)$，电容电压为 $U_C = q/C$，充电电流为 $I = +\mathrm{d}q/\mathrm{d}t$。由 KVL 回路方程：

$$\mathcal{E} - IR - \frac{q}{C} = 0 \implies R\frac{\mathrm{d}q}{\mathrm{d}t} + \frac{q}{C} - \mathcal{E} = 0$$

分离变量积分并代入初值 $q(0) = 0$，解得极板电荷 $q(t)$ 与充电电流 $I(t)$ 随时间的演化规律：

$$q(t) = C\mathcal{E}\left(1 - \mathrm{e}^{-t/(RC)}\right) = Q_f\left(1 - \mathrm{e}^{-t/\tau}\right)$$

$$I(t) = \frac{\mathrm{d}q}{\mathrm{d}t} = \frac{\mathcal{E}}{R}\mathrm{e}^{-t/(RC)} = I_0\mathrm{e}^{-t/\tau}$$

其中 $Q_f = C\mathcal{E}$ 为稳态最终电荷量，$I_0 = \mathcal{E}/R$ 为闭合瞬间（电容相当于短路，$U_C(0)=0$）的初始最大电流。

### 2. RC 电容器放电过程（PDF p269–270）
设初始带电量为 $Q_0$ 的电容器在 $t=0$ 时通过电阻 $R$ 构成闭合回路放电。由于放电时极板电量随时间减少（$\mathrm{d}q/\mathrm{d}t < 0$），若取放电电流实际方向为正方向，则**电流与电荷变化率的关系必须添负号**：

$$I = -\frac{\mathrm{d}q}{\mathrm{d}t}$$

代入回路方程 $\dfrac{q}{C} - IR = 0$，得齐次一阶线性微分方程：

$$R\frac{\mathrm{d}q}{\mathrm{d}t} + \frac{q}{C} = 0$$

结合初值 $q(0) = Q_0$ 积分，得放电电量与放电电流随指数衰减的规律：

$$q(t) = Q_0\mathrm{e}^{-t/(RC)} = Q_0\mathrm{e}^{-t/\tau}, \qquad I(t) = -\frac{\mathrm{d}q}{\mathrm{d}t} = \frac{Q_0}{RC}\mathrm{e}^{-t/\tau} = I_0\mathrm{e}^{-t/\tau}$$

### 3. 时间常数 $\tau = RC$ 的物理意义
乘积 $\tau = RC$ 具有时间的量纲（$1\,\Omega\times 1\,\mathrm{F} = 1\,\mathrm{s}$），称为 RC 电路的**时间常数（Time Constant / 弛豫时间）**：
- 当 $t = \tau = RC$ 时，充电电量达到最终值 $Q_f$ 的 $1 - \mathrm{e}^{-1} \approx 63.2\%$，放电电量衰减至初值 $Q_0$ 的 $\mathrm{e}^{-1} \approx 36.8\%$；
- 当 $t = 5\tau = 5RC$ 时，$1 - \mathrm{e}^{-5} \approx 99.3\%$（课件 p268），工程上认为充放电暂态过程已基本完成，直流稳态下的电容器支路可视为**开路（$I \to 0$）**。
