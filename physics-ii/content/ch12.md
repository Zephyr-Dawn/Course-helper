# 第 12 章：稳恒磁场

本章由静电场与稳恒电流过渡到**稳恒磁场（Magnetostatics）**。1820 年奥斯特（H. C. Ørsted）发现电流的磁效应，安培（A.-M. Ampère）进而提出“一切磁现象的本质均源于运动电荷（电流）之间的相互作用”。围绕“**如何由已知电流分布求解空间磁场 $\vec{B}$**”与“**磁场如何对运动电荷及载流导体施加力与力矩**”两大核心问题，本章建立起与静电场既高度对偶又本质迥异（有源无旋场 vs. 无源涡旋场）的理论体系。

:::tip 本章核心知识架构与静电场对偶路线图
- **场的激发（微元叠加法）**：电流元 $I\mathrm{d}\vec{l}$ 的毕奥-萨伐尔定律 $\mathrm{d}\vec{B} = \frac{\mu_0}{4\pi}\frac{I\mathrm{d}\vec{l}\times\hat{r}}{r^2}$ $\longleftrightarrow$ 点电荷库仑定律（注意叉积带来的右手螺旋垂直性）。
- **场的基本性质（通量与环流）**：磁场高斯定理 $\oiint_S \vec{B}\cdot\mathrm{d}\vec{S} = 0$（无源场）与安培环路定理 $\oint_L \vec{B}\cdot\mathrm{d}\vec{l} = \mu_0\sum_{\mathrm{in}} I_i$（非保守涡旋场）。
- **场的力学效应（力与力矩）**：宏观导体的安培力 $\vec{F} = \int_L I\mathrm{d}\vec{l}\times\vec{B}$、平面载流线圈的磁力矩 $\vec{M} = \vec{p}_m\times\vec{B}$ 与磁力做功 $A = I\Delta\Phi_B$，以及微观带电粒子的洛伦兹力 $\vec{F} = q\vec{E} + q\vec{v}\times\vec{B}$ 与霍尔效应。
:::

## 12.1 磁现象本质与毕奥-萨伐尔定律 {#s12-1}

### 1. 磁现象的电本质与磁感应强度 $\vec{B}$ 的定义

自然界中的磁体与载流导体周围均存在磁场。实验表明，当带正电的试探点电荷 $q$ 以速度 $\vec{v}$ 经过磁场中某点时：
1. 若速度 $\vec{v}$ 沿某一特定直线方向（记为磁场方向），电荷不受磁力（$F = 0$）；
2. 若速度 $\vec{v}$ 沿其他方向，所受磁力 $\vec{F}$ 的方向总是同时垂直于速度 $\vec{v}$ 与该特定方向，且大小与 $q$、$v$ 及夹角 $\theta$ 的正弦 $\sin\theta$ 成正比；
3. 当 $\vec{v}$ 与该特定方向垂直（$\theta = 90^\circ$）时，电荷所受磁力达到最大值 $F_{\mathrm{m}}$。

据此定义描述磁场强弱和方向的基本物理量——**磁感应强度（Magnetic Induction）** $\vec{B}$：其大小等于单位正电荷以单位速率垂直磁场方向运动时所受的最大磁力，方向沿 $\vec{F}_{\mathrm{m}}\times\vec{v}$ 所指的特定方向：

$$B = \frac{F_{\mathrm{m}}}{q v} = \frac{F}{q v \sin\theta}$$

在国际单位制（SI）中，$\vec{B}$ 的单位是**特斯拉（$\mathrm{T}$）**，$1\,\mathrm{T} = 1\,\mathrm{N/(A\cdot m)} = 1\,\mathrm{Wb/m^2}$；常用非国际单位高斯（$\mathrm{Gs}$）满足 $1\,\mathrm{T} = 10^4\,\mathrm{Gs}$（地球表面地磁场约为 $5\times 10^{-5}\,\mathrm{T} = 0.5\,\mathrm{Gs}$，医用核磁共振仪约为 $1.5\sim 3\,\mathrm{T}$）。任意入射方向下，运动电荷所受磁洛伦兹力矢量式及电磁场共存时的**洛伦兹关系式**为：

$$\vec{F}_B = q\vec{v}\times\vec{B}, \qquad \vec{F} = q\vec{E} + q\vec{v}\times\vec{B}$$

{{fig:F12-01}}

### 2. 磁感应线（磁力线）的四大特征

为形象描绘空间磁场分布，法拉第引入了**磁感应线（磁力线）**的概念：

{{fig:F12-02}}

- **闭合无头尾（涡旋场特征）**：每一条磁感应线都是闭合曲线，既无起点也无终点（不存在孤立磁荷/磁单极子），这与起于正电荷、止于负电荷的静电线截然不同。
- **切向定方向、疏密定强弱**：磁感应线上任一点的切线方向即为该点 $\vec{B}$ 的方向；垂直穿过单位面积的磁感线条数（疏密程度）等于该处 $\lvert\vec{B}\rvert$ 的大小。
- **右手螺旋法则**：磁感应线围绕电流的环绕方向与电流方向严格服从**右手螺旋法则**（大拇指指向电流方向或磁矩方向，四指弯曲方向即为磁感线环绕方向）。
- **空间不相交**：稳恒磁场中任一点的 $\vec{B}$ 方向唯一，故任意两条磁感线在无奇点区域绝不相交。

### 3. 毕奥-萨伐尔定律与磁场叠加原理

1820 年毕奥（J.-B. Biot）和萨伐尔（F. Savart）通过实验测定长直载流导线对磁针的作用力，经拉普拉斯（P.-S. Laplace）数学提炼，给出**电流元 $I\mathrm{d}\vec{l}$ 在真空中激发元磁场 $\mathrm{d}\vec{B}$ 的毕奥-萨伐尔定律**：

$$\mathrm{d}\vec{B} = \frac{\mu_0}{4\pi}\frac{I\mathrm{d}\vec{l}\times\hat{r}}{r^2} = \frac{\mu_0}{4\pi}\frac{I\mathrm{d}\vec{l}\times\vec{r}}{r^3}, \qquad \mathrm{d}B = \frac{\mu_0}{4\pi}\frac{I\,\mathrm{d}l\sin\theta}{r^2}$$

其中 $\vec{r}$ 是**从电流元 $I\mathrm{d}\vec{l}$（源点）指向待求场点 $P$** 的位矢，$\hat{r} = \vec{r}/r$ 为单位位矢，$\theta$ 为 $\mathrm{d}\vec{l}$ 与 $\vec{r}$ 的夹角；比例系数 $\frac{\mu_0}{4\pi} = 10^{-7}\,\mathrm{T\cdot m/A}$，$\mu_0 = 4\pi\times 10^{-7}\,\mathrm{N/A^2}$（或 $\mathrm{H/m}$）称为**真空磁导率**。由磁场叠加原理，任意闭合或有限长载流导线 $L$ 激发的总磁感应强度为：

$$\vec{B} = \int_L \mathrm{d}\vec{B} = \frac{\mu_0}{4\pi}\int_L \frac{I\mathrm{d}\vec{l}\times\hat{r}}{r^2}$$

{{fig:F12-03}}

:::warn 毕奥-萨伐尔定律的三个关键细节
1. **叉积方向与零场区**：$\mathrm{d}\vec{B}$ 垂直于 $\mathrm{d}\vec{l}$ 与 $\vec{r}$ 构成的平面，遵循右手螺旋定则；在电流元自身所在的直线上（正向或反向延长线，$\theta = 0$ 或 $\pi$），$\sin\theta = 0 \implies \mathrm{d}\vec{B} = \vec{0}$。
2. **源点到场点的位矢方向**：$\vec{r} = \vec{r}_P - \vec{r}_{\mathrm{source}}$ 必须从电流元指向场点 $P$；若反向则会相差一个负号。
3. **矢量积分必须先分解后积分**：除直线电流或圆心处各微元 $\mathrm{d}\vec{B}$ 方向处处相同外，一般曲线电流（如圆线圈轴线）各微元 $\mathrm{d}\vec{B}$ 方向不同，必须建立坐标系分解为 $\mathrm{d}B_x, \mathrm{d}B_y, \mathrm{d}B_z$ 并利用对称性消去零分量后再积分。
:::

## 12.2 毕-萨定律典型应用：直导线、圆线圈、螺线管与运动电荷 {#s12-2}

利用毕奥-萨伐尔定律求解载流导体磁场的标准五步法為：**（1）建系选微元 $I\mathrm{d}\vec{l}$ $\to$ （2）写元场 $\mathrm{d}\vec{B}$ 并判向 $\to$ （3）对称性分析与正交分解 $\to$ （4）统一积分变量（常换元为角度 $\theta$ 或 $\beta$）$\to$ （5）定积分并讨论极限特例**。

### 1. 载流直导线的磁场（有限长、无限长与半无限长）

设长直导线 $MN$ 通有稳恒电流 $I$，场点 $P$ 到直导线的垂直距离为 $a$。取垂足 $O$ 为原点，沿电流方向距离为 $l$ 处取电流元 $I\mathrm{d}l$，设 $\mathrm{d}\vec{l}$ 与位矢 $\vec{r}$ 的夹角为 $\theta$。由右手定则知，直导线上所有电流元在点 $P$ 激发的 $\mathrm{d}\vec{B}$ 方向完全相同（图中均垂直纸面向内），可直接对标量大小积分。利用几何换元：

$$r = \frac{a}{\sin(\pi - \theta)} = \frac{a}{\sin\theta}, \qquad l = -a\cot\theta \implies \mathrm{d}l = a\csc^2\theta\,\mathrm{d}\theta$$

代入毕奥-萨伐尔定律积分（设起点 $N$、终点 $M$ 对应的夹角分别为 $\theta_1$、$\theta_2$）：

$$B = \int_L \frac{\mu_0 I\,\mathrm{d}l\sin\theta}{4\pi r^2} = \int_{\theta_1}^{\theta_2} \frac{\mu_0 I (a\csc^2\theta)\sin\theta}{4\pi (a/\sin\theta)^2}\,\mathrm{d}\theta = \frac{\mu_0 I}{4\pi a}\int_{\theta_1}^{\theta_2}\sin\theta\,\mathrm{d}\theta = \frac{\mu_0 I}{4\pi a}(\cos\theta_1 - \cos\theta_2)$$

{{fig:F12-04}}

- **（1）无限长载流直导线**（$\theta_1 \to 0,\; \theta_2 \to \pi$）：$\cos 0 - \cos\pi = 2 \implies B = \dfrac{\mu_0 I}{2\pi a}$。
- **（2）半无限长载流直导线端点垂面**（$\theta_1 = \frac{\pi}{2},\; \theta_2 \to \pi$）：$\cos\frac{\pi}{2} - \cos\pi = 1 \implies B = \dfrac{\mu_0 I}{4\pi a}$（恰为无限长的一半）。
- **（3）直导线的正向或反向延长线上**（$\theta_1 = \theta_2 = 0$ 或 $\pi$）：$B = 0$。

### 2. 载流圆线圈轴线上的磁场与磁偶极矩 $\vec{p}_m$

设半径为 $R$ 的圆形线圈通有电流 $I$，求其轴线上距圆心 $O$ 为 $x$ 的场点 $P$ 处的磁感应强度。任取电流元 $I\mathrm{d}\vec{l}$，由于圆周切线总是垂直于母线位矢 $\vec{r}$（即 $\mathrm{d}\vec{l}\perp\vec{r}$，夹角恒为 $90^\circ$，且 $r = \sqrt{R^2 + x^2}$），元磁场大小为 $\mathrm{d}B = \frac{\mu_0 I\,\mathrm{d}l}{4\pi (R^2 + x^2)}$。将 $\mathrm{d}\vec{B}$ 分解为垂直轴线的分量 $\mathrm{d}B_\perp = \mathrm{d}B\sin\theta$ 与平行轴线的分量 $\mathrm{d}B_\parallel = \mathrm{d}B\cos\theta$（其中 $\cos\theta = \frac{R}{r}$）：
- 由圆环关于轴线的旋转对称性，各电流元的垂直分量 $\mathrm{d}B_\perp$ 成对抵消（$\int \mathrm{d}B_\perp = 0$）；
- 轴向分量 $\mathrm{d}B_\parallel$ 同向叠加，沿圆周长 $\oint \mathrm{d}l = 2\pi R$ 积分得（若有密绕 $N$ 匝则乘以 $N$）：

$$B = \int_0^{2\pi R} \frac{\mu_0 I R}{4\pi (R^2 + x^2)^{3/2}}\,\mathrm{d}l = \frac{\mu_0 N I R^2}{2(R^2 + x^2)^{3/2}}$$

{{fig:F12-05}}

**特殊位置与圆弧推广**：
- **圆心处（$x = 0$）**：$B_O = \dfrac{\mu_0 N I}{2R}$；
- **张角为 $\varphi$（弧度）的圆弧段在圆心处**：按弧长占整圆周比例，有 $B_O = \dfrac{\varphi}{2\pi}\dfrac{\mu_0 I}{2R} = \dfrac{\mu_0 I \varphi}{4\pi R}$（课件 p285 中若缺口角为 $\theta$，则圆弧张角为 $\varphi = 2\pi - \theta$）。
- **磁矩（磁偶极矩）与远场近似**：定义 $N$ 匝平面载流线圈（面积 $S = \pi R^2$）的**磁矩**为 $\vec{p}_m = N I S \hat{n}_e$（单位：$\mathrm{A\cdot m^2}$ 或 $\mathrm{J/T}$），法向单位矢量 $\hat{n}_e$ 与电流环绕方向服从右手螺旋关系。于是圆线圈轴线磁场可统一写为：

$$\vec{B}_{\mathrm{axis}} = \frac{\mu_0 \vec{p}_m}{2\pi (R^2 + x^2)^{3/2}} \xrightarrow{\lvert x\rvert \gg R} \frac{\mu_0 \vec{p}_m}{2\pi \lvert x\rvert^3}$$

这与电偶极子在延长线上的远场电场 $\vec{E} = \frac{1}{4\pi\varepsilon_0}\frac{2\vec{p}_e}{\lvert x\rvert^3}$ 形式完全对偶，故小载流线圈又称**磁偶极子**。

{{fig:F12-06}}

### 3. 载流直螺线管轴线上的磁场

设半径为 $R$、单位长度密绕匝数为 $n$ 的直螺线管通有电流 $I$。在距场点 $P$ 轴向距离为 $l$ 处截取宽为 $\mathrm{d}l$ 的薄圆环微元，它包含 $\mathrm{d}N = n\,\mathrm{d}l$ 匝线圈，等效环电流为 $\mathrm{d}I = n I\,\mathrm{d}l$（这里 $n I = \mathrm{d}I/\mathrm{d}l$ 即为单位轴向长度的安匝数/面电流密度）。由圆线圈轴线公式并作角度换元 $l = R\cot\beta,\; \mathrm{d}l = -R\csc^2\beta\,\mathrm{d}\beta,\; R^2 + l^2 = R^2\csc^2\beta$，可得：

$$\mathrm{d}B = \frac{\mu_0 R^2 (n I\,\mathrm{d}l)}{2(R^2 + l^2)^{3/2}} = -\frac{1}{2}\mu_0 n I \sin\beta\,\mathrm{d}\beta \implies B = \int_{\beta_1}^{\beta_2}\left(-\frac{1}{2}\mu_0 n I \sin\beta\right)\mathrm{d}\beta = \frac{1}{2}\mu_0 n I (\cos\beta_2 - \cos\beta_1)$$

- **无限长直螺线管内部**（$\beta_1 \to \pi,\; \beta_2 \to 0$）：$\cos 0 - \cos\pi = 2 \implies B = \mu_0 n I$。
- **半无限长螺线管端点（管口中心）**（$\beta_1 = \frac{\pi}{2},\; \beta_2 \to 0$ 或 $\beta_1 \to \pi,\; \beta_2 = \frac{\pi}{2}$）：$B_{\mathrm{end}} = \dfrac{1}{2}\mu_0 n I$，即**长直螺线管两端管口处的磁感应强度恰为管内中心匀强场的一半**！

{{fig:F12-07}}

### 4. “无限长”均匀载流薄导体片与运动电荷的磁场

**（1）宽为 $a$ 的无限长均匀载流薄导体片（课件 p292–293）**：设薄片位于 $xz$ 平面（$x \in [-a/2, a/2]$），沿 $-z$（或 $+z$）方向通有均匀分布的总电流 $I$，求中垂面上距薄片为 $y$ 的场点 $P(0, y)$ 处的磁场。将薄片分割为无数根宽为 $\mathrm{d}x$、电流为 $\mathrm{d}I = \frac{I}{a}\,\mathrm{d}x$ 的无限长直导线微元，每根微元在 $P$ 点产生 $\mathrm{d}B = \frac{\mu_0\,\mathrm{d}I}{2\pi r}$（其中 $r = \sqrt{x^2 + y^2}$）。由左右对称性知 $B_y = 0$，水平分量 $\mathrm{d}B_x = \mathrm{d}B\cos\theta = \mathrm{d}B\frac{y}{r}$，积分得：

$$B = B_x = \int_{-a/2}^{a/2} \frac{\mu_0 I}{2\pi a}\frac{y}{x^2 + y^2}\,\mathrm{d}x = \frac{\mu_0 I}{2\pi a}\left[\arctan\frac{x}{y}\right]_{-a/2}^{a/2} = \frac{\mu_0 I}{\pi a}\arctan\frac{a}{2y}$$

- **远场近似（$y \gg a$）**：一阶泰勒展开 $\arctan\frac{a}{2y} \approx \frac{a}{2y} \implies B \approx \dfrac{\mu_0 I}{2\pi y}$，退化为无限长直导线磁场！
- **无限宽载流平面极限（$a \to \infty$，保持线电流密度 $i = I/a$ 不变）**：$\arctan\frac{a}{2y} \to \frac{\pi}{2} \implies B = \dfrac{\mu_0 I}{2a} = \dfrac{1}{2}\mu_0 i$（两侧为大小恒定、方向相反且平行于平面的匀强磁场）。

{{fig:F12-08}}

**（2）运动点电荷激发的磁场与旋转带电体（课件 p295–299）**：设导体内载流子数密度为 $n$、每个载流子电量为 $q$、定向漂移速度为 $\vec{v}$，则电流强度 $I = n q S v$。长度为 $\mathrm{d}l$、截面积为 $S$ 的电流元 $I\mathrm{d}\vec{l} = n q S \vec{v}\,\mathrm{d}l$ 内共有 $\mathrm{d}N = n S\,\mathrm{d}l$ 个载流子。将电流元磁场 $\mathrm{d}\vec{B}$ 除以载流子数 $\mathrm{d}N$，即得**单个非相对论（$v \ll c$）运动点电荷激发的磁感应强度公式**：

$$\vec{B} = \frac{\mathrm{d}\vec{B}}{\mathrm{d}N} = \frac{\mu_0}{4\pi}\frac{q\vec{v}\times\hat{r}}{r^2} = \frac{\mu_0}{4\pi}\frac{q\vec{v}\times\vec{r}}{r^3}$$

{{fig:F12-09}}

## 12.3 磁感应线、磁通量与磁场高斯定理 {#s12-3}

### 1. 磁通量（Magnetic Flux）的定义与计算

将磁感应强度 $\vec{B}$ 与面元矢量 $\mathrm{d}\vec{S} = \hat{n}\,\mathrm{d}S$ 的标量积定义为穿过该面元的**元磁通量** $\mathrm{d}\Phi_B$；穿过任意有限曲面 $S$ 的**磁通量**为曲面积分：

$$\mathrm{d}\Phi_B = \vec{B}\cdot\mathrm{d}\vec{S} = B\cos\theta\,\mathrm{d}S = B\,\mathrm{d}S_\perp, \qquad \Phi_B = \iint_S \vec{B}\cdot\mathrm{d}\vec{S}$$

- **单位**：韦伯（$\mathrm{Wb}$），$1\,\mathrm{Wb} = 1\,\mathrm{T\cdot m^2} = 1\,\mathrm{V\cdot s}$；因此磁感应强度 $\vec{B}$ 又称为**磁通量密度**（$\mathrm{Wb/m^2}$）。
- **正负号规定**：对非闭合曲面，法向 $\hat{n}$ 的正侧可人为选定（一旦选定，整张曲面必须在同一侧）；对**闭合曲面**，统一规定**外法线方向（由内向外）为正**，因此磁感线穿出闭合面时 $\mathrm{d}\Phi_B > 0$，穿入时 $\mathrm{d}\Phi_B < 0$。

### 2. 磁场中的高斯定理（Gauss's Law for Magnetism）

由于磁感应线是无头无尾的闭合曲线，任何一条从闭合曲面 $S$ 一侧穿入内部的磁感线，必定从该闭合曲面的另一处穿出。因此穿过任意闭合曲面的穿入磁通量与穿出磁通量代数和恒为零：

$$\oint_S \vec{B}\cdot\mathrm{d}\vec{S} = 0, \qquad \nabla\cdot\vec{B} = 0$$

{{fig:F12-10}}

这就是电磁学麦克斯韦方程组四大基本方程之一的**磁场高斯定理**。它深刻揭示了：**稳恒磁场（乃至一切客观电磁场）是无源场（涡旋场），自然界中不存在孤立的磁荷（磁单极子）**。

## 12.4 安培环路定理及其对称性磁场求解 {#s12-4}

### 1. 稳恒磁场的安培环路定理（Ampère's Circuital Law）

在静电场中，环路定理 $\oint_L \vec{E}\cdot\mathrm{d}\vec{l} = 0$ 表明静电场是保守场（有势场）。而在稳恒磁场中，由于磁感线是围绕电流闭合的涡旋线，$\vec{B}$ 沿闭合回路的线积分（环流）一般不为零。以无限长直载流导线 $I$ 为例，在垂直于导线的平面内任取闭合曲线 $L$，利用微元投影 $\mathrm{d}l\cos\theta = r\,\mathrm{d}\varphi$ 及 $B = \frac{\mu_0 I}{2\pi r}$：
- **当闭合回路 $L$ 包围电流 $I$ 时**（绕行方向与电流成右手螺旋关系）：$\oint_L \vec{B}\cdot\mathrm{d}\vec{l} = \int_0^{2\pi} \frac{\mu_0 I}{2\pi r}\cdot r\,\mathrm{d}\varphi = \mu_0 I$（若反右手螺旋绕行，则 $\mathrm{d}l\cos\theta = -r\,\mathrm{d}\varphi$，积分为 $-\mu_0 I$）。
- **当闭合回路 $L$ 不包围电流 $I$ 时**：张角从 $\varphi_1$ 积到 $\varphi_2$ 再从 $\varphi_2$ 积回 $\varphi_1$，正负抵消，$\oint_L \vec{B}\cdot\mathrm{d}\vec{l} = 0$。
- **当闭合回路不在垂直平面内或包围多根任意稳恒电流时**：将 $\mathrm{d}\vec{l}$ 分解为平行与垂直分量并应用磁场叠加原理，即得普适的**稳恒磁场安培环路定理**：

$$\oint_L \vec{B}\cdot\mathrm{d}\vec{l} = \mu_0 \sum_{\mathrm{in}} I_i, \qquad \nabla\times\vec{B} = \mu_0\vec{j}$$

即：**在真空稳恒磁场中，磁感应强度 $\vec{B}$ 沿任意闭合曲线 $L$ 的线积分（环流），等于真空磁导率 $\mu_0$ 乘以穿过以该闭合曲线为边界的任意曲面的各恒定电流的代数和**。

{{fig:F12-11}}

:::warn 安培环路定理的四条核心辨析
1. **电流正负号的右手螺旋判定**：右手四指沿闭合回路 $L$ 的绕行方向弯曲，大拇指所指方向为正方向；若穿过回路的电流 $I_i$ 与大拇指同向（成右手螺旋关系）取正号 $+I_i$，反向则取负号 $-I_i$。
2. **“环流来源”与“场强来源”的区别**：定理右端 $\sum_{\mathrm{in}} I_i$ **只包含穿过环路内部的电流**；但定理左端积分号内的 $\vec{B}$ 是**环路内外所有电流共同激发的合磁场**（环路外电流在环路上各点产生的 $\vec{B}_{\mathrm{out}} \neq \vec{0}$，只是其沿整个闭合回路的环流 $\oint_L \vec{B}_{\mathrm{out}}\cdot\mathrm{d}\vec{l} = 0$）。
3. **非保守场特性**：$\oint_L \vec{B}\cdot\mathrm{d}\vec{l} \neq 0$ 说明稳恒磁场是非保守场（非有势场），在含电流的单连通区域内不能定义单值标量磁势。
4. **能用安培环路定理直接求 $\vec{B}$ 的对称性前提**：唯有当电流分布具备高度对称性（轴对称、面对称、螺线管平移对称），使得所选安培环路上 $\lvert\vec{B}\rvert$ 处处相等且 $\vec{B}$ 与 $\mathrm{d}\vec{l}$ 夹角恒为 $0$（或 $\pi/2$）时，才能把 $B$ 提出积分号直接解出 $B$。因此**有限长直导线、圆电流线圈、任意不规则弯曲导线均不能用安培环路定理求 $\vec{B}$，必须用毕奥-萨伐尔定律**！
:::

## 12.5 安培力、平行电流相互作用与载流线圈磁力矩 {#s12-5}

### 1. 安培定律（Ampère's Force Law）与等效弦长定理

从微观上看，载流导线中的每个自由载流子（电量 $q$，数密度 $n$，漂移速度 $\vec{v}$）在外磁场 $\vec{B}$ 中受洛伦兹力 $\vec{f}_L = q\vec{v}\times\vec{B}$，并通过与晶格离子的碰撞把力传递给导体骨架。截面积为 $S$、长度为 $\mathrm{d}l$ 的电流元内含有 $\mathrm{d}N = n S\,\mathrm{d}l$ 个载流子，结合 $I\mathrm{d}\vec{l} = n q S \vec{v}\,\mathrm{d}l$，得到**电流元所受安培力公式（安培定律）**及任意载流导线 $L$ 的总安培力：

$$\mathrm{d}\vec{F} = \mathrm{d}N\,\vec{f}_L = I\mathrm{d}\vec{l}\times\vec{B}, \qquad \vec{F} = \int_L I\mathrm{d}\vec{l}\times\vec{B}$$

- **匀强磁场中的长直导线与弯曲导线（等效弦长定理）**：若外磁场 $\vec{B}$ 为**匀强磁场**，可将常矢量 $\vec{B}$ 提出积分号：$\vec{F} = I\left(\int_a^c \mathrm{d}\vec{l}\right)\times\vec{B} = I\vec{L}_{ac}\times\vec{B}$，即**匀强磁场中任意形状弯曲导线所受的合安培力，恒等于从起点 $a$ 指向终点 $c$ 的等效直导线（弦 $ac$）所受的安培力**；若导线闭合（$\oint \mathrm{d}\vec{l} = \vec{0}$），则在匀强磁场中所受合磁力恒为零！

### 2. 平行长直载流导线间的相互作用力与“安培”定义

### 3. 磁场对载流线圈的作用：磁力矩与磁势能

设匀强磁场 $\vec{B}$ 中有一边长为 $l_1, l_2$（面积 $S = l_1 l_2$）、匝数为 $N$、通有电流 $I$ 的刚性矩形线圈，其平面正法线 $\hat{n}$（与电流成右手螺旋关系）与 $\vec{B}$ 的夹角为 $\theta$：
1. **合安培力为零**：上下两边 $bc$、$da$ 所受安培力大小均为 $I l_2 B \cos\theta$，共线反向相互抵消；左右两边 $ab$、$cd$ 所受安培力大小均为 $F_{ab} = F_{cd} = I l_1 B$，平行反向，故总合力 $\sum \vec{F} = \vec{0}$，质心无平动加速。
2. **形成力偶与磁力矩公式**：$ab$ 与 $cd$ 两边受力不在同一直线上，构成力臂为 $l_2\sin\theta$ 的力偶，其磁力矩大小为 $M = N I l_1 B (l_2\sin\theta) = N I S B \sin\theta = p_m B \sin\theta$。写成普适于**任意平面形状刚性载流线圈**的矢量式及磁偶极子在外场中的**磁势能** $U_B$：

$$\vec{M} = \vec{p}_m\times\vec{B}, \qquad U_B = -\vec{p}_m\cdot\vec{B} = -p_m B \cos\theta \qquad (\vec{p}_m = N I S \hat{n})$$

{{fig:F12-14}}

- **三种典型取向状态**：
  - $\theta = \frac{\pi}{2}$（线圈平面平行于 $\vec{B}$，$\Phi_B = 0$）：**磁力矩最大** $M_{\max} = p_m B$，磁势能 $U_B = 0$；
  - $\theta = 0$（磁矩 $\vec{p}_m$ 与 $\vec{B}$ 同向，$\Phi_B = +BS$ 最大）：$M = 0$，磁势能最低 $U_{B,\min} = -p_m B$，线圈处于**稳定平衡状态**（受扰偏离后磁力矩总是将其拉回 $\theta = 0$）；
  - $\theta = \pi$（磁矩 $\vec{p}_m$ 与 $\vec{B}$ 反向，$\Phi_B = -BS$）：$M = 0$，但磁势能最高 $U_{B,\max} = +p_m B$，线圈处于**不稳定平衡状态**。
- **非均匀磁场中的载流线圈（课件 p350–353）**：在非均匀磁场中，闭合线圈一般既受合力矩又受净合力（例如磁矩与径向辐射磁场同向的圆线圈会被拉向磁场更强的区域），此时必须回归微元定义 $\vec{F} = \int_L I\mathrm{d}\vec{l}\times\vec{B}$ 与 $\vec{M} = \int_L \vec{r}\times(I\mathrm{d}\vec{l}\times\vec{B})$ 积分求解：

### 4. 磁力（或磁力矩）对载流回路所做的功

无论是闭合回路中的可动导轨 $ab$ 在匀强磁场中平移 $\Delta x = \overline{aa'}$［此时 $A = F\Delta x = B I l \overline{aa'} = I (B\Delta S) = I\Delta\Phi_B$］，还是平面载流线圈在匀强磁场中绕轴从 $\theta_1$ 转到 $\theta_2$［此时 $\mathrm{d}A = -M\,\mathrm{d}\theta = -I B S \sin\theta\,\mathrm{d}\theta = I\,\mathrm{d}(B S \cos\theta) = I\,\mathrm{d}\Phi_B$］，**只要回路中的稳恒电流 $I$ 保持不变，磁力（或磁力矩）对载流回路所做的元功与有限功恒等于电流强度乘以穿过回路的磁通量增量**：

$$\mathrm{d}A = I\,\mathrm{d}\Phi_B, \qquad A = \int_{\Phi_{B1}}^{\Phi_{B2}} I\,\mathrm{d}\Phi_B = I(\Phi_{B2} - \Phi_{B1}) = I\Delta\Phi_B$$

## 12.6 洛伦兹力、带电粒子在磁场中的运动与霍尔效应 {#s12-6}

### 1. 带电粒子在匀强磁场中的三种运动形态

质量为 $m$、电量为 $q$ 的带电粒子在电场 $\vec{E}$ 与磁场 $\vec{B}$ 共存空间中的非相对论运动方程为 $m\frac{\mathrm{d}\vec{v}}{\mathrm{d}t} = q\vec{E} + q\vec{v}\times\vec{B}$（相对论情形下替换左端为 $\frac{\mathrm{d}}{\mathrm{d}t}\frac{m\vec{v}}{\sqrt{1 - (v/c)^2}}$）。由于**磁洛伦兹力 $\vec{F}_B = q\vec{v}\times\vec{B}$ 永远垂直于瞬时速度 $\vec{v}$，故磁场力对运动电荷永不做功（$P = \vec{F}_B\cdot\vec{v} = 0$），只改变速度的方向而不改变速率与动能**。当空间仅有匀强磁场 $\vec{B}$ 时，按初速度 $\vec{v}_0$ 与 $\vec{B}$ 的夹角 $\theta$ 分为三种情况：

1. **平行入射（$\theta = 0$ 或 $\pi$，即 $\vec{v}_0\parallel\vec{B}$）**：$\vec{F}_B = \vec{0}$，粒子做**匀速直线运动**。
2. **垂直入射（$\theta = \frac{\pi}{2}$，即 $\vec{v}_0\perp\vec{B}$）**：洛伦兹力 $F = \lvert q\rvert v_0 B$ 恒充当向心力，粒子在垂直于 $\vec{B}$ 的平面内做**匀速圆周运动**，其**回旋半径 $R$**、**回旋周期 $T$** 与**回旋角频率 $\omega_{\mathrm{c}}$** 为：

$$\lvert q\rvert v_0 B = m\frac{v_0^2}{R} \implies R = \frac{m v_0}{\lvert q\rvert B}, \qquad T = \frac{2\pi R}{v_0} = \frac{2\pi m}{\lvert q\rvert B}, \qquad \omega_{\mathrm{c}} = \frac{\lvert q\rvert B}{m}$$

可见在非相对论极限下，**回旋周期 $T$ 与粒子的速率 $v_0$ 及轨道半径 $R$ 均无关**，仅取决于磁感应强度 $B$ 和粒子的荷质比 $\lvert q\rvert / m$——这正是劳伦斯（E. O. Lawrence）发明回旋加速器（Cyclotron）及质谱仪的物理基石。

3. **斜交入射（$0 < \theta < \pi$ 且 $\theta \neq \frac{\pi}{2}$）**：将初速度分解为平行于磁场的分量 $v_{0x} = v_0\cos\theta$ 和垂直于磁场的分量 $v_{0n} = v_0\sin\theta$。粒子一方面绕磁感线做半径为 $R$ 的匀速圆周运动，另一方面沿磁感线方向做速率为 $v_{0x}$ 的匀速直线运动，合运动轨迹为一条**等距螺旋线**，其**螺旋半径 $R$** 与**螺距 $h$**（每回旋一周沿磁场方向前进的距离）分别为：

$$R = \frac{m v_0\sin\theta}{\lvert q\rvert B}, \qquad T = \frac{2\pi m}{\lvert q\rvert B}, \qquad h = v_{0x} T = \frac{2\pi m v_0\cos\theta}{\lvert q\rvert B}$$

### 2. 霍尔效应（Hall Effect）的实验规律与微观机理

1879 年霍尔（E. H. Hall）发现：将宽为 $b$（沿横向电势差方向）、厚为 $d$（沿磁场 $\vec{B}$ 方向）的扁平导电薄板置于垂直磁场 $\vec{B}$ 中并通以稳恒电流 $I$ 时，在与电流和磁场均垂直的上下两个侧面（$1$ 面与 $2$ 面）之间会出现稳定的横向电势差 $U_{\mathrm{H}} = U_1 - U_2$，称为**霍尔电势差（霍尔电压）**。实验表明 $U_{\mathrm{H}}$ 与电流 $I$、磁感应强度 $B$ 成正比，与薄板沿磁场方向的厚度 $d$ 成反比：

$$U_{\mathrm{H}} = U_1 - U_2 = R_{\mathrm{H}}\frac{I B}{d}, \qquad R_{\mathrm{H}} = \frac{1}{n q}$$

{{fig:F12-16}}

- **微观动力学平衡推导**：设导体内载流子浓度为 $n$、电量为 $q$、定向漂移平均速率为 $\bar{v}$。载流子在磁场中受横向洛伦兹力 $F_m = \lvert q\rvert \bar{v} B$ 发生横向漂移，在上下两侧面形成正负电荷积累，进而建立起横向**霍尔静电场 $E_{\mathrm{H}}$**。当霍尔电场力 $F_e = \lvert q\rvert E_{\mathrm{H}}$ 与洛伦兹力 $F_m = \lvert q\rvert \bar{v} B$ 相等时达到动态平衡：
  1. 横向平衡条件：$E_{\mathrm{H}} = \bar{v} B \implies \lvert U_{\mathrm{H}}\rvert = E_{\mathrm{H}} b = \bar{v} B b$；
  2. 微观电流关系：$I = n \lvert q\rvert \bar{v} S = n \lvert q\rvert \bar{v} b d \implies \bar{v} b = \dfrac{I}{n \lvert q\rvert d}$；
  3. 联立消去 $\bar{v} b$（注意宽度 $b$ 自动约去！），计入符号即得 $U_{\mathrm{H}} = U_1 - U_2 = \dfrac{I B}{n q d}$，霍尔系数为 $R_{\mathrm{H}} = \dfrac{1}{n q}$。
- **三大工程与物理应用**：
  1. **判别半导体导电类型（P 型 vs. N 型）**：对 N 型半导体或金属（自由电子导电，$q = -e < 0$），$R_{\mathrm{H}} = -\frac{1}{ne} < 0$；对 P 型半导体（空穴导电，$q = +e > 0$），$R_{\mathrm{H}} = +\frac{1}{ne} > 0$。由于正负载流子漂移方向相反，在同一磁场与同一电流方向下，**电子与空穴受洛伦兹力偏转到同一个侧面**，故测出该侧面的电势正负即可直接判定载流子符号！
  2. **测定载流子浓度 $n$ 与迁移率**：由 $\lvert R_{\mathrm{H}}\rvert = \frac{1}{ne}$ 可精确测出半导体载流子浓度 $n$（金属的 $n$ 极大故霍尔效应微弱，半导体的 $n$ 适中故霍尔效应极为显著）。
  3. **磁强计（特斯拉计）与霍尔电流传感器**：已知 $R_{\mathrm{H}}$ 和 $d$ 时，测量 $U_{\mathrm{H}}$ 即可无接触测量磁场 $B$ 或电流 $I$。
