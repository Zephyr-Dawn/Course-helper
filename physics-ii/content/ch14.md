# 第14章 电磁感应

本章是电磁学从“稳恒场”迈向“时变电磁场”的枢纽章节（对应课件 PDF 第 405–502 页）。通过法拉第电磁感应定律与楞次定律，我们将揭示磁通量变化激发感应电动势的普遍规律，并从微观洛伦兹力与麦克斯韦涡旋电场两条路径深入剖析**动生电动势**与**感生电动势**的物理机制、计算通法与复合叠加，进而掌握**自感、互感、$RL$ 电路暂态过程**以及**磁场能量密度与能量法求电感**的核心方法。

## 14.1 电磁感应现象、法拉第定律与楞次定律 {#s14-1}

### 1. 电源电动势回顾与电磁感应实验现象

在电源内部，把单位正电荷从负极移送到正极的过程中，**非静电力** $\vec{F}_K$ 所做的功定义为电源电动势。引入非静电场强 $\vec{E}_K = \frac{\vec{F}_K}{q}$，则电源电动势的一般定义为：

$$\varepsilon = \frac{A_{-\to+}}{q} = \int_{-}^{+} \vec{E}_K \cdot \mathrm{d}\vec{l}, \qquad \varepsilon_i = \oint_L \vec{E}_K \cdot \mathrm{d}\vec{l}$$

1831 年法拉第总结大量实验发现：**不论出于何种原因（导体切割磁感线运动，或原线圈电流/磁场随时间改变），只要穿过闭合导体回路所围面积的磁通量 $\Phi_B$ 发生变化，闭合回路中就会产生感应电动势 $\varepsilon_i$ 与感应电流 $I_i$。**

{{fig:F14-01}}

### 2. 法拉第电磁感应定律与磁通匝链数（全磁通）

当穿过闭合回路所围面积的磁通量 $\Phi_B = \iint_S \vec{B}\cdot\mathrm{d}\vec{S}$ 随时间变化时，回路中产生的感应电动势 $\varepsilon_i$ 与磁通量的时间变化率成正比：

$$\varepsilon_i = -\frac{\mathrm{d}\Phi_B}{\mathrm{d}t} = -\frac{\mathrm{d}}{\mathrm{d}t}\iint_S \vec{B} \cdot \mathrm{d}\vec{S}$$

若线圈共有 $N$ 匝串联，穿过第 $k$ 匝的磁通量为 $\Phi_{Bk}$，则总磁通匝链数（又称**全磁通**）定义为 $\Psi = \sum_{k=1}^N \Phi_{Bk}$。当各匝磁通量相等时，$\Psi = N\Phi_B$，总感应电动势为：

$$\varepsilon_i = -\frac{\mathrm{d}\Psi}{\mathrm{d}t} = -N\frac{\mathrm{d}\Phi_B}{\mathrm{d}t}$$

:::derive 感应电流与感生电荷量（磁通计原理）
若闭合回路的总电阻为恒定值 $R$，则瞬时感应电流与 $t_1 \to t_2$ 时间内流过导线横截面的总**感生电荷量** $q$ 分别为：

$$I_i = \frac{\varepsilon_i}{R} = -\frac{1}{R}\frac{\mathrm{d}\Psi}{\mathrm{d}t}, \qquad q = \int_{t_1}^{t_2} I_i\,\mathrm{d}t = -\frac{1}{R}\int_{\Psi_1}^{\Psi_2} \mathrm{d}\Psi = \frac{\Psi_1 - \Psi_2}{R} = \frac{N(\Phi_{B1} - \Phi_{B2})}{R}$$

**关键结论**：流过闭合回路截面的感生电荷量 $q$ **仅取决于初末状态的磁通量之差 $\Delta\Psi$，与磁通量变化的快慢无关**（冲击电流计与磁通计测量强磁场的物理基础）。但回路产生的焦耳热 $Q = \int I_i^2 R\,\mathrm{d}t$ 则与变化快慢密切相关（变化越快，$Q$ 越大）。
:::

### 3. 感应电动势方向的严格判定步骤与楞次定律

公式 $\varepsilon_i = -\mathrm{d}\Phi_B/\mathrm{d}t$ 中，$\Phi_B$、$\mathrm{d}\Phi_B/\mathrm{d}t$ 与 $\varepsilon_i$ 均为代数量，负号代表右手螺旋下的方向关系：

1. **选定回路面积法向 $\vec{n}$**：一般选与原磁场 $\vec{B}$ 相同的方向，使 $\Phi_B > 0$；
2. **约定 $\varepsilon_i$ 的参考正方向**：令回路绕行参考正方向与法向 $\vec{n}$ 成**右手螺旋关系**；
3. **计算 $\Phi_B(t)$ 及其导数 $\mathrm{d}\Phi_B/\mathrm{d}t$ 的正负**；
4. **由 $\varepsilon_i = -\mathrm{d}\Phi_B/\mathrm{d}t$ 的正负判定实际方向**：若 $\varepsilon_i > 0$，实际方向与参考正方向一致；若 $\varepsilon_i < 0$，实际方向与参考正方向相反。

{{fig:F14-02}}

**楞次定律（Lenz's Law）**：闭合回路中感应电流的方向，总是使它自己激发的附加磁通量去**阻碍（补偿或反抗）**引起感应电流的原磁通量的变化（“增反减同、来拒去留”）。楞次定律本质上是**电磁感应过程中的能量守恒定律**：例如磁铁插入线圈时，感应电流产生斥力阻碍磁铁靠近，唯有外力克服安培斥力做正功，机械能才能转化为回路中的电能与焦耳热。

{{fig:F14-03}}

### 4. 法拉第定律求非均匀场磁通与体分布涡流

当磁场在空间非均匀分布（如长直载流导线周围 $B = \frac{\mu_0 I}{2\pi x}$）时，必须先取面元 $\mathrm{d}S = l\,\mathrm{d}x$ 积分求出瞬时总磁通量 $\Phi_B(t)$，再对时间求导（见例14.1）；而对于具有一定径向宽度的厚导体环（如例14.2），由于不同半径 $r$ 处的细圆环所围磁通量 $\Phi_B(r,t)$ 与周长电阻 $\mathrm{d}R = \rho\frac{2\pi r}{D\,\mathrm{d}r}$ 均不同，必须取同心细环微元算出 $\mathrm{d}I_i(r) = \varepsilon_i(r)\,\mathrm{d}G$ 再沿径向积分。

## 14.2 动生电动势、非静电力与旋转/平动导体求解 {#s14-2}

### 1. 动生电动势的微观本质与非静电场强

当导体在稳恒磁场 $\vec{B}$ 中以速度 $\vec{v}$ 运动（或回路形状、位置变动）时，导体内的自由电子随导体一起运动，受到洛伦兹力 $\vec{F}_m = -e(\vec{v} \times \vec{B})$ 的推动而向导体一端聚集，从而在导体内部建立起由高电势端（正极）指向低电势端（负极）的静电场 $\vec{E}_e$。当开路达到动态平衡时，静电力与洛伦兹力平衡：$-e\vec{E}_e - e(\vec{v}\times\vec{B}) = 0 \implies \vec{E}_e = -(\vec{v}\times\vec{B})$。

因此，**动生电动势的非静电力就是洛伦兹力**，对应的等效非静电场强为：

$$\vec{E}_K = \frac{\vec{F}_m}{q} = \vec{v} \times \vec{B}$$

对任意形状的运动导体段 $ab$（或闭合运动回路 $L$），取沿选定积分方向（如假设参考正方向 $a \to b$）的切向线元 $\mathrm{d}\vec{l}$，动生电动势的一般微元积分公式为：

$$\mathrm{d}\varepsilon_i = (\vec{v} \times \vec{B}) \cdot \mathrm{d}\vec{l}, \qquad \varepsilon_{ab} = \int_a^b (\vec{v} \times \vec{B}) \cdot \mathrm{d}\vec{l}$$

{{fig:F14-05}}

:::tip 电动势符号与两端电势差 $U_{ab}$ 的对应关系
- 动生电动势是标量，所谓“电动势的方向”是指导体（等效电源）内部非静电力推动正电荷由**负极（低电势）指向正极（高电势）**的方向。
- 先假定参考正方向为 $a \to b$（即积分路径从 $a$ 到 $b$）：若算得 $\varepsilon_{ab} > 0$，则实际非静电力由 $a$ 指向 $b$，**$b$ 端电势高**（在开路情况下，$U_{ab} = U_a - U_b = -\varepsilon_{ab} < 0$）；若算得 $\varepsilon_{ab} < 0$，则实际方向为 $b \to a$，**$a$ 端电势高**（$U_{ab} = U_a - U_b = -\varepsilon_{ab} > 0$）。
- 若 $\vec{v} \parallel \vec{B}$ 或 $(\vec{v}\times\vec{B}) \perp \mathrm{d}\vec{l}$（非静电力垂直于棒身），则该运动不产生沿棒的动生电动势（$\varepsilon_i = 0$）。
:::

### 2. 深度辨析：洛伦兹力为何永不做功却能产生动生电动势？

洛伦兹力恒与电荷运动速度垂直而不做功，为何又能作为非静电力移动电荷产生动生电动势？

当导体棒以牵连速度 $\vec{v}$ 向右切割磁感线且回路闭合时，自由电子除了具有向右的牵连速度 $\vec{v}$ 外，还获得沿棒向下的定向漂移速度 $\vec{u}$，其对地合速度为 $\vec{v}_{\mathrm{tot}} = \vec{v} + \vec{u}$。电子所受的总洛伦兹力可分解为两个正交分力：

$$\vec{F} = -e(\vec{v} + \vec{u}) \times \vec{B} = \underbrace{-e(\vec{v} \times \vec{B})}_{\vec{f}_v} + \underbrace{\left[-e(\vec{u} \times \vec{B})\right]}_{\vec{f}_u}$$

- **沿棒分力 $\vec{f}_v = -e(\vec{v}\times\vec{B})$**：与电子漂移速度 $\vec{u}$ 同向，对电子做**正功**，单位时间做功功率为 $P_1 = \vec{f}_v \cdot \vec{u} = evBu > 0$，这就是产生动生电动势的非静电力！
- **垂直棒分力 $\vec{f}_u = -e(\vec{u}\times\vec{B})$**：方向与导体棒平动速度 $\vec{v}$ 相反（宏观上累积为阻碍导体棒运动的**安培阻力** $\vec{F}_A = I\vec{l}\times\vec{B}$），对电子做**负功**，功率为 $P_2 = \vec{f}_u \cdot \vec{v} = -evBu < 0$。
- **总洛伦兹力功率恒为零**：$P_{\mathrm{tot}} = P_1 + P_2 = 0$。为了维持导体棒匀速运动，外力 $\vec{F}_{\mathrm{ext}} = -\vec{F}_A$ 必须克服安培阻力做正功。因此，**洛伦兹力本身不提供能量，而是通过一个分力做负功、另一个分力做等值正功，起到将外力机械功转化为电路电能的“桥梁”作用！**

{{fig:F14-06}}

### 3. 动生电动势的两类典型模型与辅助线法则

除直接按定义积分 $\int (\vec{v}\times\vec{B})\cdot\mathrm{d}\vec{l}$ 外，对于不闭合的运动导体，还可**添加恰当的假想辅助线构成闭合回路**，再用法拉第定律 $\varepsilon_i = -\mathrm{d}\Phi_B/\mathrm{d}t$ 求解（课件 p440 小结）：

1. **匀强磁场中平动的任意弯曲导线（情形 1：等磁通直线辅助线）**：连接弯曲导线 $abc$ 的首尾端点作随同平动的直导线辅助线 $ac$（如例14.3 的 $3/4$ 圆弧）。因闭合回路 $abca$ 在匀强磁场中平动时磁通量 $\Phi_B = \text{const}$，故 $\varepsilon_{abca} = 0 \implies \varepsilon_{abc} = \varepsilon_{ac} = B v L_{\perp}$，即**匀强磁场中平动曲线导体的动生电动势恒等于连接首尾端点的等效直导线的动生电动势**。
2. **匀强磁场中绕轴旋转的导体棒与法拉第圆盘（情形 2：零电动势静止辅助线）**：长为 $L$ 的导体棒 $OA$ 绕端点 $O$ 以角速度 $\omega$ 在垂直匀强磁场 $B$ 中旋转（例14.4），添加静止半径 $OC$ 与圆弧 $CA$ 构成扇形闭合回路 $OCA$（静止辅助线上 $\vec{v}=0$，动生电动势为零）。扇形面积 $S = \frac{1}{2}L^2\theta$，直接导出：
   $$\varepsilon_{\mathrm{rot}} = \int_0^L B(\omega l)\,\mathrm{d}l = \frac{1}{2}B\omega L^2$$
   若换成同半径的旋转金属圆盘（法拉第圆盘），可视作无数根径向铜棒并联，盘心与盘缘间的动生电动势仍为 $\frac{1}{2}B\omega L^2$。

### 4. 动生电动势与涡电流的机械制动效应（电磁阻尼）

当大块金属导体（如例14.5 中厚度为 $\tau$、电导率为 $\gamma$ 的旋转圆盘）通过离轴 $r$ 处面积为 $a^2$ 的局部强磁场 $B$ 时，磁场覆盖区沿径向切割磁感线产生动生电动势 $\varepsilon_i = Br\omega a$，在盘内驱动闭合涡流 $I = \frac{\varepsilon_i}{1/(\gamma\tau)} = Br\omega a\gamma\tau$，所受安培力对转轴产生与角速度反向的电磁制动转矩 $M = rIaB = B^2 r^2 \omega a^2 \gamma\tau$，广泛用于电磁阻尼器与电度表制动。

## 14.3 感生电动势、涡旋电场及其空间分布与动生+感生复合问题 {#s14-3}

### 1. 麦克斯韦涡旋电场假设与法拉第定律的场形式

当导体回路完全静止、甚至导体位于磁场区域之外（如长直螺线管外部套有的静止导线环）而磁感应强度 $\vec{B}(t)$ 随时间变化时，回路中同样会产生感应电动势——称为**感生电动势**。此时导体静止（$\vec{v}=0$），不存在洛伦兹力，且静电场环流恒为零（$\oint \vec{E}_e\cdot\mathrm{d}\vec{l}=0$），那么推动自由电子定向移动的非静电力究竟是什么？

麦克斯韦（Maxwell）提出革命性假设：**不论空间有无导体存在，随时间变化的磁场总是在其周围空间激发一种电场——称为感生电场或涡旋电场（记作 $\vec{E}_i$）。涡旋电场正是产生感生电动势的非静电场强（$\vec{E}_K = \vec{E}_i$）。**

对于空间任意静止闭合回路 $L$（选定回路绕行方向与曲面 $S$ 的法向 $\mathrm{d}\vec{S}$ 成右手螺旋关系），感生电动势与法拉第定律可写成积分场形式：

$$\varepsilon_i = \oint_L \vec{E}_i \cdot \mathrm{d}\vec{l} = -\frac{\mathrm{d}\Phi_B}{\mathrm{d}t} = -\iint_S \frac{\partial \vec{B}}{\partial t} \cdot \mathrm{d}\vec{S}$$

### 2. 涡旋电场 $\vec{E}_i$ 与静电场 $\vec{E}_e$ 的本质对比

涡旋电场的方向始终与磁感应强度时间变化率 $\frac{\partial\vec{B}}{\partial t}$ 的方向成**左手（反右手）螺旋关系**：当 $\vec{B}$ 随时间增强时，$\vec{E}_i$ 与 $\vec{B}$ 成左手螺旋；当 $\vec{B}$ 随时间减弱时，$\vec{E}_i$ 与 $\vec{B}$ 成右手螺旋。

| 比较维度 | 静电场 $\vec{E}_e$（库仑电场） | 涡旋电场 $\vec{E}_i$（感生电场） |
| :--- | :--- | :--- |
| **激发源** | 由静止电荷激发 | 由随时间变化的磁场 $\partial\vec{B}/\partial t$ 激发 |
| **高斯定理（通量）** | $\oiint_S \vec{E}_e \cdot \mathrm{d}\vec{S} = \frac{Q_{\mathrm{in}}}{\varepsilon_0}$（有源场，电力线起止于电荷） | $\oiint_S \vec{E}_i \cdot \mathrm{d}\vec{S} = 0$（**无源场**，电力线是无头无尾的闭合曲线） |
| **环路定理（环流）** | $\oint_L \vec{E}_e \cdot \mathrm{d}\vec{l} = 0$（保守场/无旋场，可引入单值标量电势 $\varphi$） | $\oint_L \vec{E}_i \cdot \mathrm{d}\vec{l} = -\iint_S \frac{\partial\vec{B}}{\partial t}\cdot\mathrm{d}\vec{S} \neq 0$（**非保守有旋场，不能定义标量电势**） |
| **共同点与导体存在性** | 对电荷施力 $\vec{F} = q\vec{E}$；在真空或介质中客观存在，不依赖于是否有导体 | 对电荷施力 $\vec{F} = q\vec{E}_i$；在变化磁场内外整个空间客观存在，有导体时表现为感生电动势 |

### 3. 圆柱形均匀时变磁场的涡旋电场分布与弦棒感生电动势

设半径为 $R$ 的无限长圆柱形空间内存在均匀时变磁场 $\vec{B}(t)$，变化率为 $\frac{\mathrm{d}B}{\mathrm{d}t}$（例14.6）。由轴对称性，涡旋电场线是以圆柱轴线为圆心的同心圆，取半径为 $r$ 的同心圆环路 $L$ 应用 $\oint \vec{E}_i\cdot\mathrm{d}\vec{l} = 2\pi r E_i = -\frac{\mathrm{d}\Phi_B}{\mathrm{d}t}$，立得圆柱体内外的场强分布：

$$E_i(r) = \begin{cases} \dfrac{r}{2}\left\lvert\dfrac{\mathrm{d}B}{\mathrm{d}t}\right\rvert, & r \le R \quad (\Phi_B = \pi r^2 B) \\[8pt] \dfrac{R^2}{2r}\left\lvert\dfrac{\mathrm{d}B}{\mathrm{d}t}\right\rvert, & r > R \quad (\Phi_B = \pi R^2 B) \end{cases}$$

{{fig:F14-10}}

若在该圆柱形变化磁场内放置一长为 $L$、距圆心 $O$ 垂直距离（弦心距）为 $h$ 的静止导体棒 $ab$（例14.7），求棒上感生电动势有两种标准方法：

1. **按定义沿棒微元积分**：取 $\mathrm{d}y$，利用切向投影 $E_i\cos\theta = \left(\frac{r}{2}\left\lvert\frac{\mathrm{d}B}{\mathrm{d}t}\right\rvert\right)\frac{h}{r} = \frac{h}{2}\left\lvert\frac{\mathrm{d}B}{\mathrm{d}t}\right\rvert$，积分得 $\lvert\varepsilon_{ab}\rvert = \frac{1}{2}hL\left\lvert\frac{\mathrm{d}B}{\mathrm{d}t}\right\rvert$。
2. **径向辅助线法（零感生电动势辅助线）**：连接圆心作两条半径 $Oa$、$Ob$ 构成闭合三角形回路 $OabO$。由于涡旋电场 $\vec{E}_i$ 沿同心圆切向，**过圆心 $O$ 的径向辅助线处处与 $\vec{E}_i$ 垂直（$\vec{E}_i \perp \mathrm{d}\vec{l}$），故径向辅助线上感生电动势恒为零！** 于是棒 $ab$ 的感生电动势直接等于 $\triangle Oab$ 内有磁场区域的面积 $S_{\triangle Oab} = \frac{1}{2}hL$ 与 $\lvert\mathrm{d}B/\mathrm{d}t\rvert$ 的乘积。

### 4. 动生电动势与感生电动势同时存在的复合问题

当导体在随时间变化的磁场 $\vec{B}(\vec{r},t)$ 中同时以速度 $\vec{v}$ 运动时，自由电荷同时受到洛伦兹非静电力与涡旋电场力，总感应电动势为动生与感生两项之和：

$$\varepsilon_{\mathrm{tot}} = \int_L \left(\vec{v} \times \vec{B} + \vec{E}_i\right) \cdot \mathrm{d}\vec{l} = \varepsilon_{\mathrm{mot}} + \varepsilon_{\mathrm{ind}}$$

:::warn 闭合回路合并求导 vs 开路运动棒分解法（例14.8 与 例14.9 对比）
- **情形 A：本身为闭合导体回路（如例14.8 滑动导轨处于 $B = B_0\cos\omega t$ 中）**：既可先写出瞬时磁通量 $\Phi_B(t) = B(t)S(t) = B_0 l x(t)\cos(\omega t)$ 对时间求全导数 $\varepsilon_i = -\frac{\mathrm{d}\Phi_B}{\mathrm{d}t} = -\left(S\frac{\mathrm{d}B}{\mathrm{d}t} + B\frac{\mathrm{d}S}{\mathrm{d}t}\right) = B_0 l(\omega x\sin\omega t - v\cos\omega t)$；也可分别按“导体不动求感生 $\varepsilon_{i1} = -lx\frac{\mathrm{d}B}{\mathrm{d}t}$”与“磁场不变求动生 $\varepsilon_{i2} = -B(t)lv$”再相加，两者完全等价。
- **情形 B：导体不是闭合回路（如例14.9 局域圆柱时变磁场中长 $2R$ 的运动金属棒 $ac$）**：**强烈推荐采用“先固定导体求感生 $\varepsilon_{i1}$，再固定磁场求动生 $\varepsilon_{i2}$”的分解法！**
  - 求感生 $\varepsilon_{i1}$ 时棒视为静止，连接圆心 $O$ 作径向辅助线 $Oa, Oc$（$\vec{E}_i \perp Oa, Oc$），$\triangle Oac$ 落在圆柱内的有磁通面积为等边三角形 $\triangle Oab$ 与 $30^\circ$ 扇形之和 $S_0 = \frac{R^2}{4}\left(\sqrt{3} + \frac{\pi}{3}\right)$，得 $\varepsilon_{i1} = -S_0\frac{\mathrm{d}B}{\mathrm{d}t}$（方向 $a \to c$）；
  - 求动生 $\varepsilon_{i2}$ 时磁场视为恒定，圆外段 $bc$ 无磁场不切割磁感线，仅圆内段 $ab$（长 $R$）切割磁感线，得 $\varepsilon_{i2} = vBR$（方向 $c \to a$），总电动势为 $\varepsilon_i = vBR - \frac{R^2}{4}\left(\sqrt{3} + \frac{\pi}{3}\right)\frac{\mathrm{d}B}{\mathrm{d}t}$（以 $c \to a$ 为正）。
  - **为什么课件 p466–468 的“同时计算法” $\mathrm{d}S/\mathrm{d}t = -Rv$ 存在易错陷阱？** 若将辅助线 $Oa, Oc$ 固定在圆心而随棒摆动，动辅助线自己也会切割磁感线扫过面积；课件写 $\mathrm{d}S/\mathrm{d}t = -Rv$ 实际上是仅提取了圆内棒段 $ab$（长 $R$）向上平动扫过磁通的变化率，而排除了动辅助线切割磁感线的伪贡献。因此分解法物理图像最清晰、最不易出错！
:::

## 14.4 自感与互感系数计算及共轴螺线管耦合分析 {#s14-4}

### 1. 自感现象、自感系数与自感电动势

当闭合回路自身的电流 $I$ 随时间变化时，它所激发的磁场及穿过自身回路的全磁通 $\Psi_B$ 随之变化，从而在回路自身激起感应电动势——称为**自感现象**，所产生的电动势称为**自感电动势** $\varepsilon_L$。

- **静态定义（回路几何形状不变且周围无铁磁质）**：空间各点 $B \propto I$，全磁通 $\Psi_B$ 与电流 $I$ 成正比，比例系数即为**自感系数（简称自感）**：
  $$\Psi_B = L I \implies L = \frac{\Psi_B}{I}$$
- **动态定义与自感电动势**：当回路几何形状不变时，由法拉第定律得：
  $$\varepsilon_L = -\frac{\mathrm{d}\Psi_B}{\mathrm{d}t} = -\frac{\mathrm{d}\Psi_B}{\mathrm{d}I}\frac{\mathrm{d}I}{\mathrm{d}t} = -L\frac{\mathrm{d}I}{\mathrm{d}t} \qquad \left(L = \frac{\mathrm{d}\Psi_B}{\mathrm{d}I}\right)$$

:::note 自感系数 $L$ 的物理意义与单位
1. **电磁惯性**：在 $\varepsilon_L = -L\frac{\mathrm{d}I}{\mathrm{d}t}$ 中，当 $\mathrm{d}I/\mathrm{d}t > 0$（电流增大）时，$\varepsilon_L < 0$（与 $I$ 反向，阻碍电流增大）；当 $\mathrm{d}I/\mathrm{d}t < 0$（电流减小）时，$\varepsilon_L > 0$（与 $I$ 同向，阻碍电流减小）。$L$ 越大，阻碍电流变化的能力越强，故 $L$ 反映了回路保持原有电流不变的**电磁惯性**（类比力学中的质量 $m$）。
2. **几何与介质属性**：在非铁磁线性介质中，$L$ 与电流 $I$ 无关，仅由回路的几何尺寸、形状、匝数 $N$（正比于 $N^2$）和周围磁介质磁导率 $\mu = \mu_0\mu_{\mathrm{r}}$ 决定；若含铁磁质，则 $L$ 随 $I$ 非线性变化。
3. **单位**：亨利（$\mathrm{H}$），$1\,\mathrm{H} = 1\,\mathrm{Wb/A} = 1\,\mathrm{\Omega\cdot s}$。
:::

### 2. 自感系数的标准求法（三步法）与典型结构汇总

求线性介质中导体回路的自感系数 $L$，标准步骤为：**① 设回路通有电流 $I$，由安培环路定理或毕-萨定律求 $B(\vec{r})$ 分布 $\to$ ② 积分求穿过回路的全磁通 $\Psi_B = N\Phi_B$ $\to$ ③ 由 $L = \Psi_B / I$ 消去 $I$ 得自感 $L$。**

| 典型电感结构 | 几何与介质参数 | 磁场分布 $B$ | 自感系数 $L$（及单位长度自感 $L_0 = L/l$） |
| :--- | :--- | :--- | :--- |
| **细长密绕螺线管** | 长 $l \gg R$，截面积 $S=\pi R^2$，总匝数 $N = nl$，磁导率 $\mu$ | 管内均匀 $B = \mu n I = \frac{\mu N I}{l}$ | $L = \frac{\mu N^2 S}{l} = \mu n^2 V$（正比于 $N^2$ 和体积 $V=Sl$） |
| **同轴薄壁圆筒电缆（例14.10）** | 内筒半径 $R_1$、外筒半径 $R_2$，间充磁导率 $\mu$ 介质，长 $l$ | $R_1 < r < R_2$ 内 $B = \frac{\mu I}{2\pi r}$ | $L = \frac{\mu l}{2\pi}\ln\frac{R_2}{R_1}$，单位长度 $L_0 = \frac{\mu}{2\pi}\ln\frac{R_2}{R_1}$ |
| **平行双线传输线（例14.11）** | 两导线半径 $a$，轴间距 $d \gg a$，忽略内磁通，空气 $\mu_0$ | 两线间同向叠加 $B = \frac{\mu_0 I}{2\pi r} + \frac{\mu_0 I}{2\pi(d-r)}$ | $L = \frac{\mu_0 l}{\pi}\ln\frac{d-a}{a}$，单位长度 $L_0 \approx \frac{\mu_0}{\pi}\ln\frac{d}{a}$ |

### 3. 互感现象、互易定理与共轴螺线管耦合分析

当回路 $C_1$ 中的电流 $I_1$ 随时间变化时，它激发的磁通有一部分穿过邻近回路 $C_2$（全磁通 $\Psi_{21}$），从而在 $C_2$ 中激起**互感电动势** $\varepsilon_{21}$；反之亦然。在线性磁介质中，定义**互感系数** $M$：

$$M_{21} = \frac{\Psi_{21}}{I_1}, \quad M_{12} = \frac{\Psi_{12}}{I_2}, \quad M_{21} = M_{12} = M$$

两耦合回路中的互感电动势分别为：

$$\varepsilon_{21} = -\frac{\mathrm{d}\Psi_{21}}{\mathrm{d}t} = -M\frac{\mathrm{d}I_1}{\mathrm{d}t}, \qquad \varepsilon_{12} = -\frac{\mathrm{d}\Psi_{12}}{\mathrm{d}t} = -M\frac{\mathrm{d}I_2}{\mathrm{d}t}$$

互感系数 $M$ 仅由两个线圈的几何形状、尺寸、匝数、**相对位置（取向与距离）**及周围线性介质磁导率 $\mu$ 决定，与电流无关。一般地，两线圈的互感系数与各自自感 $L_1, L_2$ 的关系为：

$$M = K\sqrt{L_1 L_2} \qquad (0 \le K \le 1)$$

其中 $K$ 称为**耦合系数**：当两线圈完全重合共轴且理想无漏磁时，$K = 1$（全耦合，$M = \sqrt{L_1 L_2}$）；当存在漏磁或两线圈截面积不等时，$K < 1$；当两线圈磁通完全正交无交链时，$K = 0$（$M = 0$）。

:::warn 不等半径共轴长直螺线管的互感陷阱（例14.12 精要）
设共轴细长直螺线管长度均为 $l$，外管半径 $R_1$、匝数 $N_1$、自感 $L_1 = \frac{\mu_0 N_1^2}{l}\pi R_1^2$；内管半径 $R_2 < R_1$、匝数 $N_2$、自感 $L_2 = \frac{\mu_0 N_2^2}{l}\pi R_2^2$：
- **无论设外管通电 $I_1$ 还是设内管通电 $I_2$**，两管磁场共同交链的**有效横截面积永远是较小内管的截面积 $S_2 = \pi R_2^2$**（因为内管通电时，$R_2 < r < R_1$ 环形间隙内磁场为零！）。
- 因此互感系数唯一确定为：
  $$M = M_{21} = M_{12} = \frac{\mu_0 N_1 N_2}{l}\pi R_2^2 = \frac{R_2}{R_1}\sqrt{L_1 L_2} \implies K = \frac{R_2}{R_1} < 1$$
- 课件 p491 设问中的 $M_{12} = \frac{R_1}{R_2}\sqrt{L_1 L_2}$ 是故意设置的反例：它错把外管总面积 $\pi R_1^2$ 当成内管磁场穿过的面积，会导致 $K = R_1/R_2 > 1$，违背物理定律！
:::

## 14.5 RL 暂态过程、磁场的能量与能量密度 {#s14-5}

### 1. RL 电路中电流的增长与衰减暂态过程

由于自感线圈具有阻碍电流突变的“电磁惯性”，含有电感 $L$ 与电阻 $R$ 的电路在接通或断开电源时，电流不能发生跃变，而是经历一段指数弛豫的**暂态过程**：

1. **接通电源（电流增长过程，$t=0$ 时 $i(0)=0$）**：由闭合电路欧姆定律 $\varepsilon + \varepsilon_L = \varepsilon - L\frac{\mathrm{d}i}{\mathrm{d}t} = iR$，分离变量积分得：
   $$i(t) = \frac{\varepsilon}{R}\left(1 - e^{-\frac{R}{L}t}\right) = I_m\left(1 - e^{-t/\tau}\right), \qquad I_m = \frac{\varepsilon}{R},\; \tau = \frac{L}{R}$$
2. **撤去电源短接放电（电流衰减过程，$t=0$ 时 $i(0)=I_0$）**：电路方程为 $-L\frac{\mathrm{d}i}{\mathrm{d}t} = iR$，积分得：
   $$i(t) = I_0 e^{-\frac{R}{L}t} = I_0 e^{-t/\tau}$$

其中 $\tau = \frac{L}{R}$ 具有时间量纲（$1\,\mathrm{H/\Omega} = 1\,\mathrm{s}$），称为 **$RL$ 电路的时间常数（弛豫时间）**：
- 在增长过程中，$t = \tau$ 时电流达到稳态值的 $1 - e^{-1} \approx 63.2\%$；$t = 5\tau$ 时达到 $1 - e^{-5} \approx 99.3\%$（工程上视为已达稳态）。
- 在衰减过程中，$t = \tau$ 时电流衰减至初始值的 $e^{-1} \approx 36.8\%$；$t = 5\tau$ 时降至 $0.7\%$。$\tau = L/R$ 越小，电流增长或衰减得越快。

### 2. 自感磁能（线圈储能）的功-能推导

在 $RL$ 电路电流从 $0$ 增长到稳态值 $I_0$ 的过程中，对电路方程 $\varepsilon = L\frac{\mathrm{d}i}{\mathrm{d}t} + iR$ 两边同乘以 $\mathrm{d}q = i\,\mathrm{d}t$ 并对全过程积分：

$$\int_0^t \varepsilon i\,\mathrm{d}t = \int_0^{I_0} L i\,\mathrm{d}i + \int_0^t i^2 R\,\mathrm{d}t = \frac{1}{2}L I_0^2 + \int_0^t i^2 R\,\mathrm{d}t$$

方程左端为电源输出的全部电能，右端第二项为电阻上耗散的焦耳热，第一项 $\frac{1}{2}LI_0^2$ 则是电源克服自感电动势所做的功——按功能原理，这部分功转化为储存在自感线圈中的**自感磁能**：

$$W_m = \frac{1}{2}L I^2$$

同理，在断电衰减过程中，电阻上释放的全部焦耳热 $\int_0^\infty I_0^2 e^{-2Rt/L}R\,\mathrm{d}t = \frac{1}{2}LI_0^2$ 恰等于自感线圈通过自感电动势做正功释放出的全部磁能。这表明自感系数 $L$ 还表征了线圈储存磁场能量的本领（与静电场中电容储能 $W_e = \frac{1}{2}CU^2$ 地位对偶）。

### 3. 磁场的能量密度与能量法求自感（含内自感）

从场的观点看，自感磁能并非局限于导线本身，而是分布式地储存在磁场所在的整个空间中。以体积为 $V = Sl$ 的细长直螺线管为例，将 $L = \mu n^2 V$ 与 $I = \frac{H}{n} = \frac{B}{\mu n}$ 代入 $W_m = \frac{1}{2}LI^2$：

$$W_m = \frac{1}{2}(\mu n^2 V)\left(\frac{B}{\mu n}\right)^2 = \frac{1}{2}\frac{B^2}{\mu}V = \frac{1}{2}BH V$$

由此定义单位体积内的磁场能量为**磁能密度** $w_m$，并对任意非均匀磁场空间 $V$ 积分求总磁能：

$$w_m = \frac{\mathrm{d}W_m}{\mathrm{d}V} = \frac{1}{2}\vec{B}\cdot\vec{H} = \frac{1}{2}\mu H^2 = \frac{B^2}{2\mu}, \qquad W_m = \iiint_V w_m\,\mathrm{d}V = \iiint_V \frac{B^2}{2\mu}\,\mathrm{d}V$$

:::tip 自感系数的两种计算路径与实心铜芯内自感（例14.13 精要）
1. **按全磁通定义求自感**：$L = \frac{\Psi_B}{I}$，适合细导线或薄壁圆筒（磁场与全部电流 $I$ 完全交链）。
2. **按磁场能量求自感**：先积分求全空间总磁能 $W_m = \iiint_V \frac{B^2}{2\mu}\,\mathrm{d}V$，再由 $L = \frac{2W_m}{I^2}$ 求自感。
3. **为什么实心导线内部自感（内自感）必须优先用能量法？**
   在例14.13 中，半径为 $R_1$ 的实心圆柱铜芯（磁导率 $\mu_1$）内电流均匀分布，芯内磁场 $B_1(r) = \frac{\mu_1 I r}{2\pi R_1^2}$ 产生的磁感线只包围了半径 $r$ 以内的部分电流 $\frac{r^2}{R_1^2}I$（不与全部电流 $I$ 匝链）。若用能量法积分芯内磁能：
   $$W_{m,\mathrm{in}} = \int_0^{R_1} \frac{B_1^2}{2\mu_1}\cdot 2\pi r l\,\mathrm{d}r = \frac{\mu_1 I^2 l}{16\pi} \implies L_{\mathrm{in}} = \frac{2W_{m,\mathrm{in}}}{I^2} = \frac{\mu_1 l}{8\pi}$$
   即可一步得出单位长度实心圆导线的内自感恒为 $\frac{\mu_1}{8\pi}$（与导线半径 $R_1$ 无关！），加上内外导体间介质（$R_1 < r < R_2$）的外自感 $\frac{\mu l}{2\pi}\ln\frac{R_2}{R_1}$，便得到同轴电缆的完整自感 $L = \frac{\mu l}{2\pi}\ln\frac{R_2}{R_1} + \frac{\mu_1 l}{8\pi}$。
:::
